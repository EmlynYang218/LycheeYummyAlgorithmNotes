[76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)

提示

给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 s 中的 **最短窗口 子串**，使得该子串包含 `t` 中的每一个字符（**包括重复字符**）。如果没有这样的子串，返回空字符串 `""`。

测试用例保证答案唯一。

**示例 1：**

**输入：**s = "ADOBECODEBANC", t = "ABC"
**输出：**"BANC"
**解释：**最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

**示例 2：**

**输入：**s = "a", t = "a"
**输出：**"a"
**解释：**整个字符串 s 是最小覆盖子串。

**示例 3:**

**输入:** s = "a", t = "aa"
**输出:** ""
**解释:** t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。

**提示：**

- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 105`
- `s` 和 `t` 由英文字母组成

**进阶：**你能设计一个在 `O(m + n)` 时间内解决此问题的算法吗？

```cpp
class Solution {
public:
    string minWindow(string s, string t) {
        // 滑动窗口，用哈希表统计窗口中每个字符的出现次数，并与t比对
        // 维护一个satisfied变量表示出现次数已经满足条件的字符种类数
        int target[CHAR_MAX] = {0};
        int window[CHAR_MAX] = {0};
        int satisfied = 0;
        int required = 0; // t中字符种类数

        for (char c : t) {
            target[c]++;
        }
        for (int i = 0; i < CHAR_MAX; i++) {
            if (target[i] > 0) {
                required++;
            }
        }

        // 闭区间滑动窗口[l,r],由于要输出所求字串，跟踪所求字串的起点和长度。
        int l = 0, r = 0;
        int start = 0, min_len = INT_MAX;
        int n = s.size();

        while (r < n) {
            // 右端字符进入窗口
            char c = s[r];
            // 只有这个字符在t中存在才需要计数
            if (target[c] > 0) {
                window[c]++;
                // 对应字符在窗口中出现次数>=在t中出现次数
                if (window[c] == target[c]) {
                    satisfied++;
                }
            }

            // 子串已经符合条件判断它是否最短，同时左指针右移收缩窗口，得到尽量短的窗口
            while (satisfied == required) {
                int window_len = r - l + 1;
                if (window_len < min_len) {
                    min_len = window_len;
                    start = l;
                }

                // 左端字符离开窗口
                c = s[l];
                if (target[c] > 0) {
                    // 这里是先判断是否要更新satisfied再减小计数，与上面的过程相反
                    if (window[c] == target[c]) {
                        satisfied--;
                    }
                    window[c]--;
                }
                l++;
            }

            r++;
        }

        return (min_len == INT_MAX) ? "":s.substr(start,min_len);
    }
};
```
