# [1064 滑雪](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/a888308f5fb94e8386dd66bac917fe55/)

#### 题目描述

Michael喜欢滑雪这并不奇怪， 因为滑雪的确很刺激。可是为了获得速度，滑的区域必须向下倾斜，而且当你滑到坡底，你不得不再次走上坡或者等待升降机来载你。Michael想知道载一个区域中最长的滑坡。区域由一个二维数组给出。数组的每个数字代表点的高度。下面是一个例子

1 2 3 4 5  
16 17 18 19 6  
15 24 25 20 7  
14 23 22 21 8  
13 12 11 10 9

一个人可以从某个点滑向上下左右相邻四个点之一，当且仅当高度减小。在上面的例子中，一条可滑行的滑坡为24-17-16-1。当然25-24-23-...-3-2-1更长。事实上，这是最长的一条。

#### 关于输入

输入的第一行表示区域的行数R和列数C(1 <= R,C <= 100)。下面是R行，每行有C个整数，代表高度h，0<=h<=10000。

#### 关于输出

输出最长区域的长度。

#### 例子输入

5 5
1 2 3 4 5
16 17 18 19 6
15 24 25 20 7
14 23 22 21 8
13 12 11 10 9

#### 例子输出

25

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_R = 104;
static constexpr int MAX_C = 104;
static constexpr int moves[4][2] = {
    {1, 0}, {0, 1}, {-1, 0}, {0, -1}};


static int matrix[MAX_R][MAX_C];
static int R, C;

static int memo[MAX_R][MAX_C] = {0};

int dfs(int i, int j)
{
    //未计算约定为0
    if (memo[i][j] != 0)
    {
        return memo[i][j];
    }

    int ans = 1;
    // 访问四个邻居
    for (int d = 0; d < 4; d++)
    {
        int ni = i + moves[d][0];
        int nj = j + moves[d][1];
        if (ni >= 0 && ni < R && nj >= 0 && nj < C && matrix[ni][nj] < matrix[i][j])
        {
            ans = max(ans, 1 + dfs(ni, nj));
        }
    }

    memo[i][j] = ans;
    return ans;
}

int main()
{
    cin.tie(nullptr);
    cout.tie(nullptr);
    ios::sync_with_stdio(false);

    /*
    状态设计：
    memo[i][j] 表示从(i,j)出发的最长路线长

    状态转移：
    memo[i][j] = （存在邻居比它矮）？1 + max(四个邻居中比它矮的) ： 1

    边界处理：
    不存在邻居比它矮，memo[i][j] = 1;

    代码实现：自底向上递推困难，改为自顶向下记忆化搜索

    */

    cin >> R>>C;

    for(int i = 0; i < R; i++){
        for(int j = 0; j < C; j++){
            cin >>matrix[i][j];
        }
    }

    int ans = 0;

    for(int i = 0; i < R; i++){
        for(int j = 0; j < C; j++){
            ans = max(ans,dfs(i,j));
        }
    }

    cout<< ans;

    return 0;
}
```
