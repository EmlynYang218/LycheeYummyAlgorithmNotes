# 01 背包

按照动态规划的标准过程思考：

## 1. 划分阶段

**阶段 $k$**：处理第 $k$ 个物品（$k = 1, 2, \dots, n$）。

以物品为阶段：每个物品只做一次决策，决策后不再回头，阶段顺序推进、不可回退。

## 2. 设计状态

**状态**：$dp[k][w]$ = 前 $k$ 个物品、容量为 $w$ 时的最大价值。

**合法性（无后效性）**：给定“处理到第 $k$ 个物品、剩余容量 $w$”，后续物品 $k+1,\dots,n$ 的最优决策只依赖 $(k, w)$，与前 $k$ 个物品具体怎么拿无关。

**决策集**：第 $k$ 个物品拿或不拿（0/1，这正是“01”背包名字来源）。

$$
A_k(w) = \{0\} \cup \{\,1 \mid w \ge w_k\,\}
$$

其中：

- $a = 0$：不拿，恒可行；
- $a = 1$：拿，仅当 $w \ge w_k$ 时可行。

## 3. 状态转移

记 $w_k$ 为第 $k$ 个物品的体积，$v_k$ 为第 $k$ 个物品的价值。

$$
dp[k][w] =
\begin{cases}
dp[k-1][w], & w < w_k \quad(\text{装不下，只能不拿}) \\[6pt]
\max\bigl(dp[k-1][w],\ dp[k-1][w-w_k] + v_k\bigr), & w \ge w_k
\end{cases}
$$

## 4. 边界条件

$$
dp[0][w] = 0 \quad \forall w \quad(\text{没有物品，价值为 } 0)
$$

$$
dp[k][0] = 0 \quad \forall k \quad(\text{容量为 } 0\text{，装不了，价值为 } 0)
$$

代码中通常将 $dp$ 全初始化为 $0$，即可同时覆盖以上两条边界。

## 代码实现

二维数组基础版：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005, MAXV = 10005;
int w[MAXN], v[MAXN];          // w[k] 体积，v[k] 价值
int dp[MAXN][MAXV];            // dp[k][w]：前 k 个物品、容量 w 的最大价值

int main() {
    int n, V;
    cin >> n >> V;
    for (int k = 1; k <= n; k++) cin >> w[k] >> v[k];

    // 边界：dp[0][w] = 0（没物品），dp[k][0] = 0（没容量）
    // 全局数组默认 0，已覆盖

    for (int k = 1; k <= n; k++) {          // 阶段 k：处理第 k 个物品
        for (int c = 0; c <= V; c++) {      // 枚举所有容量 c
            // 分类讨论：当前容量 c 装不装得下第 k 个物品
            if (c < w[k]) {
                // 情况 1：装不下，只能不拿，继承前 k-1 个物品的最优
                dp[k][c] = dp[k - 1][c];
            } else {
                // 情况 2：装得下，拿或不拿，取较大者
                int not_take = dp[k - 1][c];                    // 不拿第 k 个
                int take   = dp[k - 1][c - w[k]] + v[k];      // 拿第 k 个
                dp[k][c] = max(not_take,take);
            }
        }
    }

    cout << dp[n][V] << endl;
    return 0;
}
```

# 5. 优化过程

### （1） 二维拆成两段循环，明确分类

```cpp
for (int k = 1; k <= n; k++) {
    // 段 A：c < w[k]，装不下，只能继承（不拿）
    for (int c = 0; c < w[k] && c <= V; c++)
        dp[k][c] = dp[k-1][c];

    // 段 B：c >= w[k]，装得下，拿/不拿取 max
    for (int c = w[k]; c <= V; c++)
        dp[k][c] = max(dp[k-1][c], dp[k-1][c - w[k]] + v[k]);
}
```

### （2） 一维滚动，分类仍显式

```cpp
int dp[MAXV];   // dp[c]：容量 c 下的最大价值（滚动）

for (int k = 1; k <= n; k++) {
    for (int c = V; c >= 0; c--) {          // 倒序！见下方说明
        if (c >= w[k]) {                     // 分类仍然显式
            int not_take = dp[c];                // 不拿：旧值
            int take   = dp[c - w[k]] + v[k];  // 拿
            dp[c] = max(not_take, take);
        }
        // c < w[k]：不拿，dp[c] 保持旧值（什么都不做）
    }
}
```

#### 为什么倒序 c

正序时，`dp[c - w[k]]` 可能**已经被本轮（第 k 个物品）更新过**，相当于第 k 个物品被拿了多次 → 变成"完全背包"。  
倒序时，`dp[c - w[k]]` 还是**上一轮（k-1）的旧值**，保证第 k 个物品只用一次。

> 一句话：**倒序保证"读到的 `dp[c-w[k]]` 是上一轮的"，即 01 背包每个物品只用一次。**

#### `c < w[k]` 时发生了什么

`if (c >= w[k])` 不成立 → 循环体不执行 → `dp[c]` **保持旧值**。  
而"保持旧值"语义上**正好等于"不拿"**（不拿就不改变当前容量下的最优值）。

> 记住这句：**`c < w[k]` 时，循环体是空操作，`dp[c]` 不变 = 不拿。**

### (3) 一维滚动，下界吸收

```cpp
int dp[MAXV];
for (int k = 1; k <= n; k++) {
 for (int c = V; c >= w[k]; c--) { // 下界 = w[k]
 dp[c] = max(dp[c], dp[c - w[k]] + v[k]);
 }
}
```

- `c >= w[k]`：和上一版 `if` 成立的分支完全一样（`max(dp[c], dp[c-w[k]]+v[k])`）。

- `c < w[k]`：上一版是"空操作"（`dp[c]` 不变），这版**根本不进循环**，`dp[c]` 也不变 → **等价**。

- `dp[c - w[k]]`：`c >= w[k]` 保证 `c - w[k] >= 0`，**不会负下标越界**。

**所以"下界 `w[k]`"不是新规则，是"空操作不必写"的等价压缩。**



| 步骤    | 空间  | 分类           | "不拿"写在哪               | 新引入的概念    |
| ----- | --- | ------------ | --------------------- | --------- |
| 第 0 步 | 二维  | `if/else` 显式 | `dp[k][c]=dp[k-1][c]` | 无（最直白）    |
| 第 1 步 | 二维  | 两段循环         | 段 A 显式继承              | 拆循环       |
| 第 2 步 | 一维  | `if` 显式      | `c<w[k]` 时 `dp[c]` 不变 | **倒序**    |
| 第 3 步 | 一维  | 下界吸收         | 不进循环 = 不变             | **空操作可省** |
