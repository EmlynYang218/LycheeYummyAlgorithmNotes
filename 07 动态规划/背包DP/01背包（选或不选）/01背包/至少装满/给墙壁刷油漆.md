[2742. 给墙壁刷油漆](https://leetcode.cn/problems/painting-the-walls/)



给你两个长度为 `n` 下标从 **0** 开始的整数数组 `cost` 和 `time` ，分别表示给 `n` 堵不同的墙刷油漆需要的开销和时间。你有两名油漆匠：

- 一位需要 **付费** 的油漆匠，刷第 `i` 堵墙需要花费 `time[i]` 单位的时间，开销为 `cost[i]` 单位的钱。
- 一位 **免费** 的油漆匠，刷 **任意** 一堵墙的时间为 `1` 单位，开销为 `0` 。但是必须在付费油漆匠 **工作** 时，免费油漆匠才会工作。

请你返回刷完 `n` 堵墙最少开销为多少。

**示例 1：**

**输入：**cost = [1,2,3,2], time = [1,2,3,2]
**输出：**3
**解释：**下标为 0 和 1 的墙由付费油漆匠来刷，需要 3 单位时间。同时，免费油漆匠刷下标为 2 和 3 的墙，需要 2 单位时间，开销为 0 。总开销为 1 + 2 = 3 。

**示例 2：**

**输入：**cost = [2,3,4,2], time = [1,1,1,1]
**输出：**4
**解释：**下标为 0 和 3 的墙由付费油漆匠来刷，需要 2 单位时间。同时，免费油漆匠刷下标为 1 和 2 的墙，需要 2 单位时间，开销为 0 。总开销为 2 + 2 = 4 。

**提示：**

- `1 <= cost.length <= 500`
- `cost.length == time.length`
- `1 <= cost[i] <= 106`
- `1 <= time[i] <= 500`

```cpp
class Solution {
public:
    int paintWalls(vector<int>& cost, vector<int>& time) {
        /*
        设付费刷墙个数为p，免费刷墙个数为q，总墙数为n,
        p+q = n
        设付费时间之和为t，它是p个数的加和，设为time[i_1]...time[i_p]
        因为免费刷每堵墙用1单位时间，得免费刷墙时间之和=免费刷前个数q
        由于只有付费刷墙时才能免费刷墙，
        t>=q = n-p
        故t+p>=n
        即(time[i_1]+1)+...+time[i_p]+1)>=n
        问题转化为在(time[i_1]+1)+...+time[i_p]+1)>=n的情况下求最小的
        cost[i_1]+...+cost[i_p]
        抽象出第i个物体“体积”v[i] = time[i-1]+1
        状态设计：
            设dp[a][b] 表示前a个物体体积最少达到b的最小花费
            b最大截断到n
            答案：dp[n][n]
        状态转移：
            if(v[a]<b){
                //选上v[a]体积仍不足b，需要在前a-1个物体中选若干个，让它们的体积达到b-v[a]
                dp[a][b] = min(dp[a-1][b-v[a]]]+cost[a-1],dp[a-1][b]);
                               //选                         //不选
            }else{
                //选上v[a]体积就能达到b，由于多选一定导致价格更高，前a-1个物体中一个都不选
                dp[a][b] = min(cost[a-1],dp[a-1][b]);
                            //选            //不选
            }
            这等价于dp[a][b] = min(dp[a-1][max(0,b-v[a])]]+cost[a-1],dp[a-1][b]);
            这是因为dp[a-1][0]是参与合法的递推，必然为0
        边界处理：
            由于状态转移中a每次增大1，而b依赖于0...b-1的所有情况，所以必须处理
            dp[0][b]的边界
            dp[0][0] = 0
            dp[0][b] = INF 这是由于前0个物体不可能选出比b更多的体积，是不可达状态，通过INF在min中淘汰
        空间优化：
            dp[a]仅依赖于dp[a-1]可以优化为两个一维滚动数组
        */

        int n = cost.size();
        const int INF = 0x3f3f3f3f;
        vector<int> pre(n+1,INF);
        pre[0] = 0;
        vector<int> cur(n+1,0);

        for(int a = 1; a<=n; a++){
            for(int b = 1; b<=n; b++){
                cur[b] = min(pre[max(0,b-(time[a-1]+1))]+cost[a-1],pre[b]);
            }
            pre = cur;
        }

        return cur[n];
    }
};
```
