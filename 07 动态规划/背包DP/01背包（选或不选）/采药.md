# [题目: 采药](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/f001260fd2cb44a59d850f0f925e417f/)

#### 题目描述

辰辰是个天资聪颖的孩子，他的梦想是成为世界上最伟大的医师。为此，他想拜附近最有威望的医师为师。医师为了判断他的资质，给他出了一个难题。医师把他带到一个到处都是草药的山洞里对他说： “孩子，这个山洞里有一些不同的草药，采每一株都需要一些时间，每一株也有它自身的价值。我会给你一段时间，在这段时间里，你可以采到一些草药。如果你是一个聪明的孩子，你应该可以让采到的草药的总价值最大。” 如果你是辰辰，你能完成这个任务吗？

#### 关于输入

输入第一行有两个整数T（1 ≤ T ≤ 1000）和M（1 ≤ M ≤ 100），用一个空格隔开，T代表总共能够用来采药的时间，M代表山洞里的草药的数目。接下来的M行每行包括两个在1到100之间（包括1和100）的整数，分别表示采摘某株草药的时间和这株草药的价值。

#### 关于输出

输出包括一行，这一行只包含一个整数，表示在规定的时间内，可以采到的草药的最大总价值。

#### 例子输入

70 3
71 100
69 1
1 2

#### 例子输出

3

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_M = 104; // 1 ≤ M ≤ 100
static constexpr int MAX_T = 1004;  //1 ≤ T ≤ 1000
static int times[MAX_M];
static int prices[MAX_M];
static int dp[MAX_M][MAX_T];

int main()
{
    int T, M;
    cin >>T>>M;
    for(int i = 0; i < M; i++){
        cin >> times[i] >> prices[i];
    }

    /*
    状态设计：
    dp[i][j] 表示 前i个草药在j时间能达到的最大价值，目标求出dp[M][T]
    决策：第i颗草药选不选
    转移方程：
       //第i颗时间<时间限制j才能选         不选                 选                 第i颗时间>时间限制j，不选
    dp[i][j] = (times[i-1] <= j) ? max(dp[i-1][j],dp[i-1][j-times[i-1]]+prices[i-1]) : dp[i-1][j]
    边界条件
    dp[i][0] = 0 没时间不能选
    dp[0][j] = 0 没草药没价值
    */
    memset(dp,0,sizeof(dp));

    for(int i = 1; i <= M; i++){
        for(int j = 0; j <= T;j++){
            //访问times，prices的时候1-base转换0-base
            dp[i][j] = (times[i-1] <= j) ? max(dp[i-1][j],dp[i-1][j-times[i-1]]+prices[i-1]) : dp[i-1][j];
        }
    }
    cout<<dp[M][T];

    return 0;
}
