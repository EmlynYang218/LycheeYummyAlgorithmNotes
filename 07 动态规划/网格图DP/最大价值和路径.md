# [题目: 最优路径](https://programming.pku.edu.cn/probset/6145fa4759d340339126b3fa75d7da7e/50b7d02ac2f549a7b061dca7e6d5f459/)

#### 题目描述

给定一个n*m的方格棋盘，第i行第j列的方格价值为W(i, j)。现在你从第一行的任选方格出发，可以选择向南、向西或者向东走，但是不能重复经过相同的格子（即不能走回头路），一直到第n行的任意一个方格为止。

请你设计一条路径，使得从开始到结束所经过的所有方格的价值和最大。  

#### 关于输入

输入包含多组数据。

每组数据第一行为两个整数n和m（1<=n, m<=200），表示棋盘大小。下接一个n*m的整数矩阵，描述价值矩阵，W(i,j)在[-1000, 1000]之内。  

#### 关于输出

对于每一组数据，输出一个整数，表示最大的价值。

#### 例子输入

2 1
100
-101
4 4
1 -5 20 3
3 2 -50 20
3 3 3 3
9 -100 0 17

#### 例子输出

-1
66

#### 提示信息

样例第二组数据最优路径是(1,3)-(1,4)-(2,4)-(3,4)-(3,3)-(4,3)-(4,4

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> matrix;
vector<int> pre, cur,temp;

//rolling array 2D dp
int max_value_sum(const vector<vector<int>>& matrix){
    int n = matrix.size(), m = matrix[0].size();

    for(int i = 0; i < n; i++){
        //seperately calculate max of every position in the row
        for(int j = 0; j < m; j++){
            temp.assign(m,INT_MIN);
            temp[j]=matrix[i][j]+pre[j];
            cur[j]=max(temp[j],cur[j]);
            for(int k = j-1; k >= 0; k--){
                temp[k]=matrix[i][k]+temp[k+1];
                cur[k] = max(temp[k],cur[k]);
            }
            for(int k = j+1; k <m;k++){
                temp[k]=matrix[i][k]+temp[k-1];
                cur[k] = max(temp[k],cur[k]);
            }
            temp.clear();
        }
        /*
        for(int i = 0 ; i < m; i++){
            cout << cur[i] << ' ';
        }
        cout << "\n";
        */
        pre = cur;
        cur.assign(m,INT_MIN);
    }

    int ans = INT_MIN;
    for(int j = 0 ; j < m; j++){
        ans = max(ans,pre[j]);
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int n = 0, m = 0;

    while(cin >> n >> m){

    matrix.assign(n,vector<int>(m,0));
    pre.assign(m,0);
    cur.assign(m,INT_MIN);
    for(int i = 0; i < n; i++){
        for(int j = 0; j < m; j++){
            cin >> matrix[i][j];
        }
    }
    cout<<max_value_sum(matrix)<<"\n";

    }
    return 0;
}
```
