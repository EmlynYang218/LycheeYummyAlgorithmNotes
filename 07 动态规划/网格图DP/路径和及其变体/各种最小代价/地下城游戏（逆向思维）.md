# [174. 地下城游戏](https://leetcode.cn/problems/dungeon-game/)

恶魔们抓住了公主并将她关在了地下城 `dungeon` 的 **右下角** 。地下城是由 `m x n` 个房间组成的二维网格。我们英勇的骑士最初被安置在 **左上角** 的房间里，他必须穿过地下城并通过对抗恶魔来拯救公主。

骑士的初始健康点数为一个正整数。如果他的健康点数在某一时刻降至 0 或以下，他会立即死亡。

有些房间由恶魔守卫，因此骑士在进入这些房间时会失去健康点数（若房间里的值为*负整数*，则表示骑士将损失健康点数）；其他房间要么是空的（房间里的值为 *0*），要么包含增加骑士健康点数的魔法球（若房间里的值为*正整数*，则表示骑士将增加健康点数）。

为了尽快解救公主，骑士决定每次只 **向右** 或 **向下** 移动一步。

返回确保骑士能够拯救到公主所需的最低初始健康点数。

**注意：**任何房间都可能对骑士的健康点数造成威胁，也可能增加骑士的健康点数，包括骑士进入的左上角房间以及公主被监禁的右下角房间。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/03/13/dungeon-grid-1.jpg)

**输入：**dungeon = [[-2,-3,3],[-5,-10,1],[10,30,-5]]
**输出：**7
**解释：**如果骑士遵循最佳路径：右 -> 右 -> 下 -> 下 ，则骑士的初始健康点数至少为 7 。

**示例 2：**

**输入：**dungeon = [[0]]
**输出：**1

**提示：**

- `m == dungeon.length`
- `n == dungeon[i].length`
- `1 <= m, n <= 200`
- `-1000 <= dungeon[i][j] <= 1000`

```cpp
class Solution {

public:

    int calculateMinimumHP(vector<vector<int>>& dungeon) {

        /*

        思路：逆推 DP

        为什么正推不行：

          常见想法是 dp[i][j] = 起点到 (i,j) 的最小血量。

          但初始血量是待求量，dp 值依赖这个未知量，无法从已知边界出发递推；

          而且"血量不能 <= 0"的约束在正推时无法用单一数值刻画。

        为什么逆推可行：

          定义 dp[i][j] = 从 (i,j) 出发、活着到达终点所需的最低血量（进入 (i,j) 之前的血量）。

          这个量只依赖 (i,j) 之后的格子，与怎么来到 (i,j) 无关，

          因此可以自底向上（从右下到左上）填表。

        状态转移：

          从 (i,j) 出发，下一步只能往下 (i+1,j) 或往右 (i,j+1)。

          1) 选更省血的那条路：min(dp[i+1][j], dp[i][j+1])，即"下一格出发所需最低血量"。

          2) 扣掉本格净收益 dungeon[i][j]：

             设进入 (i,j) 前有 x 点血，经过本格后剩 x + dungeon[i][j]，

             要求 x + dungeon[i][j] >= min(下, 右)，

             移项得 x >= min(下, 右) - dungeon[i][j]。

             （dungeon[i][j] 为负表示扣血，减去负数等于加，即本格补血可少带血进来。）

          3) 任何时刻血量至少为 1：

             dp[i][j] = max( min(dp[i+1][j], dp[i][j+1]) - dungeon[i][j], 1 )

        边界条件（终点外侧设 1，公式统一，无需特判终点）：

          1) dp 全部初始化为 INT_MAX，表示越界不可走，会在 min(下, 右) 中被淘汰。

          2) 仅把终点右侧和下方两个虚拟格设为 1：

            dp[n-1][m] = 1;   // 终点右侧，到终点后只需 1 点血

            dp[n][m-1] = 1;   // 终点下方，同上

            这样终点 (n-1,m-1) 取 min(1,1)=1，套公式得 max(1-dungeon, 1)，正确。

          3) 其余越界格保持 INT_MAX，不参与实际计算。

             填表范围 i = n-1..0, j = m-1..0。

        答案：dp[0][0]，即从起点出发活着到终点所需的最低初始血量。

        注意：这并不是直觉上的“逆向顺推”，而是从右下到左上填表，但每次填表时向前看一步。

        此题有哲学意味，不问过去，方得始终。

        */

        int n = dungeon.size();

        int m = dungeon[0].size();

        vector<vector<int>> dp(n+1,vector<int>(m+1,INT_MAX));

        dp[n][m-1] = 1;

        dp[n-1][m] = 1;

        for(int i = n-1; i>=0;i--){

            for(int j = m-1; j>=0; j--){

                dp[i][j] = max( min(dp[i+1][j], dp[i][j+1]) - dungeon[i][j], 1 );

            }

        }

        return dp[0][0];

    }

};
```
