# [题目: 受限时间内的最小通行费](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/574b21da7ad64bd6bd7c8d9c99d1051e/)

#### 题目描述

一个商人穿过一个 N*N 的正方形的网格，去参加一个非常重要的商务活动。从一个角进，相对的另一个角出。每穿越中间1个小方格，都要花费1个单位时间。商人必须在(2N-1)个单位时间穿越出去。在经过中间的每个小方格时，都需要缴纳一定的费用。这个商人期望在规定时间内用最少费用穿越出去。**假定从左上角进，右下角出**，至少需要多少费用？

注意：**不能对角穿越各个小方格（即，只能行号或列号之一增减1）**。

#### 关于输入

第一行是一个整数，表示正方形的宽度N (N <100),  
后面 N 行 N 列为网格上每个小方格的费用。

如：  
5  
1  4  6  8  10  
2  5  7  15 17  
6  8  9  18 20  
10 11 12 19 21  
20 23 25 29 33  

#### 关于输出

最小费用

上述例子中，最小值为109=1+2+5+7+9+12+19+21+33

#### 例子输入

5
1  4  6  8  10 
2  5  7  15 17 
6  8  9  18 20 
10 11 12 19 21 
20 23 25 29 33 

#### 例子输出

109

#### 提示信息

**注意控制超时(Time out)**

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_N = 104;
static int matrix[MAX_N][MAX_N];
static int dp[MAX_N][MAX_N];

int main()
{
    cin.tie(nullptr);
    cout.tie(nullptr);
    ios::sync_with_stdio(false);

    int N;
    cin>>N;
    for (int i = 0; i < N; i++){
        for(int j = 0; j <N; j++){
            cin >> matrix[i][j];
        }
    }
    //非常直观的网格图二维dp
    //dp[i][j]表示左上角到[i][j]最小费用
    dp[0][0] = matrix[0][0];
    for(int i = 1; i <N;i++){
        dp[i][0] = matrix[i][0]+dp[i-1][0];
    }
    for(int j = 1; j < N; j++){
        dp[0][j] = matrix[0][j]+dp[0][j-1];
    }

    for(int i = 1; i < N; i++){
        for(int j = 1; j < N; j++){
            dp[i][j] = min(dp[i-1][j],dp[i][j-1])+matrix[i][j];
        }
    }
    cout<<dp[N-1][N-1];
    return 0;
}
```
