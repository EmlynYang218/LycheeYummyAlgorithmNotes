[741. 摘樱桃](https://leetcode.cn/problems/cherry-pickup/)

给你一个 `n x n` 的网格 `grid` ，代表一块樱桃地，每个格子由以下三种数字的一种来表示：

- `0` 表示这个格子是空的，所以你可以穿过它。
- `1` 表示这个格子里装着一个樱桃，你可以摘到樱桃然后穿过它。
- `-1` 表示这个格子里有荆棘，挡着你的路。

请你统计并返回：在遵守下列规则的情况下，能摘到的最多樱桃数：

- 从位置 `(0, 0)` 出发，最后到达 `(n - 1, n - 1)` ，只能向下或向右走，并且只能穿越有效的格子（即只可以穿过值为 `0` 或者 `1` 的格子）；
- 当到达 `(n - 1, n - 1)` 后，你要继续走，直到返回到 `(0, 0)` ，只能向上或向左走，并且只能穿越有效的格子；
- 当你经过一个格子且这个格子包含一个樱桃时，你将摘到樱桃并且这个格子会变成空的（值变为 `0` ）；
- 如果在 `(0, 0)` 和 `(n - 1, n - 1)` 之间不存在一条可经过的路径，则无法摘到任何一个樱桃。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/12/14/grid.jpg)

**输入：**grid = [[0,1,-1],[1,0,-1],[1,1,1]]
**输出：**5
**解释：**玩家从 (0, 0) 出发：向下、向下、向右、向右移动至 (2, 2) 。
在这一次行程中捡到 4 个樱桃，矩阵变成 [[0,1,-1],[0,0,-1],[0,0,0]] 。
然后，玩家向左、向上、向上、向左返回起点，再捡到 1 个樱桃。
总共捡到 5 个樱桃，这是最大可能值。

**示例 2：**

**输入：**grid = [[1,1,-1],[1,-1,1],[-1,1,1]]
**输出：**0

**提示：**

- `n == grid.length`
- `n == grid[i].length`
- `1 <= n <= 50`
- `grid[i][j]` 为 `-1`、`0` 或 `1`
- `grid[0][0] != -1`
- `grid[n - 1][n - 1] != -1`

```cpp
static constexpr int INF = 0x3f3f3f3f;
static constexpr int MAX_N = 54;
static int dp[2 * MAX_N][MAX_N][MAX_N];

class Solution {
public:
    int cherryPickup(vector<vector<int>>& grid) {
        /*
        正向路线和反向路线的并集是总的覆盖情况，因此可以等效为
        两个人同时从位置 (0, 0) 出发，最后到达 (n - 1, n - 1)
        观察1）每个樱桃只能被采摘一次，所以“一个樱桃被到达两次”需要去重
        观察2）因为只能向右或者向下，最终两人到达终点向下次数和向右次数相等
        巧妙转化：令两人“速度”相同，也即k单位时间内两人均只走k步，
        设甲的行号为a，乙的行号为b 则y1=k-a, y2=k-b
        从而位置相同等价于a=b

        状态设计：dp[k][a][b]
        表示两人均走k步甲的行号为a，乙的行号为b时摘到最多樱桃数
                 答案：dp[2n-2][n-1][n-1]

        状态转移：
        先分析最后一步怎么走到这里
        1)甲右乙下
        dp[k][a][b] = dp[k-1][a][b-1]
        2）甲下乙右
        dp[k][a][b] = dp[k-1][a-1][b]
        3）甲右乙右
        dp[k][a][b] = dp[k-1][a][b]
        4）甲下乙下
        dp[k][a][b] = dp[k-1][a-1][b-1]
        上述四种情况取max
        再分析樱桃的增加量
        甲所在格子的樱桃：int add = grid[a][k - a];
        如果甲和乙不在同一个格子： if (a != b) add += grid[b][k - b];
        dp[k][a][b] = max(前驱) + add

        边界处理：
        1）参数范围：
        0<=k<=2n-2
        0<=a<=n-1
        0<=k-a<=n-1从而
        k+1-n<=a<=k
        故max(0,k+1-n)<=a<=min(k,n-1)
        同理max(0,k+1-n)<=b<=min(k,n-1)
        2）边界状态：
        dp[0][0][0] = grid[0][0]
        不可达状态设置为-INF，从而在状态转移中的max(前驱)被淘汰
        实现上，先将整个dp数组初始化为-INF，然后还原dp[0][0][0] = grid[0][0]
        对于荆棘的情况，转移时先判断这一格是否是荆棘，只要是，就continue，让它保持-INF
        */

        int n = grid.size();
        for (int k = 0; k <= 2 * n - 2; k++) {
            for (int a = 0; a <= n - 1; a++) {
                for (int b = 0; b <= n - 1; b++) {
                    dp[k][a][b] = -INF;
                }
            }
        }
        dp[0][0][0] = grid[0][0];

        for (int k = 1; k <= 2 * n - 2; k++) {
            for (int a = 0; a <= n - 1; a++) {
                // a超过范围或者是荆棘，状态不可达
                if (a < max(0, k + 1 - n) || a > min(k, n - 1) ||
                    grid[a][k - a] == -1) {
                    continue;
                }
                for (int b = 0; b <= n - 1; b++) {
                    // b超过范围，状态不可达
                    if (b < max(0, k + 1 - n) || b > min(k, n - 1) ||
                        grid[b][k - b] == -1) {
                        continue;
                    }

                    // 递推求值
                    int best_pre = dp[k - 1][a][b];
                    if (a >= 1) {
                        best_pre = max(best_pre, dp[k - 1][a - 1][b]);
                    }
                    if (b >= 1) {
                        best_pre = max(best_pre, dp[k - 1][a][b - 1]);
                    }
                    if (a >= 1 && b >= 1) {
                        best_pre = max(best_pre, dp[k - 1][a - 1][b - 1]);
                    }
                    int add = grid[a][k - a];
                    // 去重判断
                    if (a != b) {
                        add += grid[b][k - b];
                    }
                    dp[k][a][b] = best_pre + add;
                }
            }
        }
        // 如果是负数，就说明没有到终点的可达状态
        return max(0, dp[2 * n - 2][n - 1][n - 1]);
    }
};
```
