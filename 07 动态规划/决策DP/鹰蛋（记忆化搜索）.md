[887. 鸡蛋掉落](https://leetcode.cn/problems/super-egg-drop/)

给你 `k` 枚相同的鸡蛋，并可以使用一栋从第 `1` 层到第 `n` 层共有 `n` 层楼的建筑。

已知存在楼层 `f` ，满足 `0 <= f <= n` ，任何从 **高于** `f` 的楼层落下的鸡蛋都会碎，从 `f` 楼层或比它低的楼层落下的鸡蛋都不会破。

每次操作，你可以取一枚没有碎的鸡蛋并把它从任一楼层 `x` 扔下（满足 `1 <= x <= n`）。如果鸡蛋碎了，你就不能再次使用它。如果某枚鸡蛋扔下后没有摔碎，则可以在之后的操作中 **重复使用** 这枚鸡蛋。

请你计算并返回要确定 `f` **确切的值** 的 **最小操作次数** 是多少？

 

**示例 1：**

**输入：**k = 1, n = 2
**输出：**2
**解释：**
鸡蛋从 1 楼掉落。如果它碎了，肯定能得出 f = 0 。 
否则，鸡蛋从 2 楼掉落。如果它碎了，肯定能得出 f = 1 。 
如果它没碎，那么肯定能得出 f = 2 。 
因此，在最坏的情况下我们需要操作 2 次以确定 f 是多少。 

**示例 2：**

**输入：**k = 2, n = 6
**输出：**3

**示例 3：**

**输入：**k = 3, n = 14
**输出：**4

**提示：**

- `1 <= k <= 100`
- `1 <= n <= 104`

```cpp
class Solution {
    /*
    决策DP / 换维：dp[k][t] = k 个蛋、t 次试验，最多能确定的"楼层数"

    为什么用记忆化搜索：
        正向 dp[m][n] = min_k max(dp[m-1][k-1], dp[m][n-k]) + 1 要枚举 k，O(N²M) 太慢
        换维成 dp[k][t] = 最多确认楼层数，转移无枚举，O(KT)
        递归自顶向下写起来直观，加 memo 避免重复计算

    状态设计：
        dfs(k, t) = k 个蛋、t 次试验，最多能确定的楼层数

    状态转移：
        第 t 次从某一层扔：
            碎了 → 剩 k-1 个蛋、t-1 次，能确定下面 dfs(k-1, t-1) 层
            没碎 → 剩 k 个蛋、  t-1 次，能确定上面 dfs(k, t-1) 层
        加上"扔的这一层"本身，共：
            dfs(k, t) = dfs(k-1, t-1) + dfs(k, t-1) + 1
        +1 就是扔的那一层（它把上下两段分开，本身也是能确定的一层）

    边界处理：
        dfs(1, t) = t          // 1 个蛋只能逐层扫，t 次确定 t 层
        dfs(k, 0) = 0          // 0 次试验，一层都确定不了
        dfs(0, t) = 0          // 0 个蛋，一层都确定不了

    代码实现：
        1) 递归 + 记忆化 memo[k][t]，每个状态算一次，O(KT)
        2) k 封顶：k > ceil(log2(n+1)) 后答案不变，k = min(k, 20)
        3) t 上界：k=1 时 t=n；k=2 时 t≈sqrt(2n)；n=4e5 时 t≤n，但 k=1 特判后
           k≥2 时 t≤sqrt(2n)≈895，memo 第二维开 1000 足够

    答案：
        t 从 1 递增，第一个 dfs(k, t) >= n 的 t 即最少试验次数
    */

    static constexpr int MAXK = 25;
    static constexpr int MAXT = 1005;
    int memo[MAXK][MAXT];

    int dfs(int k, int t) {
        // 边界：0 个蛋 或 0 次试验，都确定不了任何楼层
        if (k == 0 || t == 0) {
            return 0;
        }
        // 边界：1 个蛋，只能逐层扫，t 次确定 t 层
        if (k == 1) {
            return t;
        }
        // 记忆化：算过直接返回（0 表示未算，合法值 >= 1 或 0，用 -1 更稳？）
        // 注意：合法值可能是 0（k=0 或 t=0），但那些在边界已返回，不进 memo
        // 所以 memo 里 0 可以安全表示"未计算"
        if (memo[k][t] != 0) {
            return memo[k][t];
        }
        // 转移：下面 + 上面 + 扔的这层
        memo[k][t] = dfs(k - 1, t - 1) + dfs(k, t - 1) + 1;
        return memo[k][t];
    }

public:
    int superEggDrop(int k, int n) {
        // k 封顶：蛋足够多后答案就是二分次数，不再减少
        k = min(k, 20);

        int t = 1;
        // 找最小的 t 使 dfs(k, t) >= n（n 层楼，要能确定 n 层）
        while (dfs(k, t) < n) {
            t++;
        }
        return t;
    }
};
```
