# [题目: 鹰蛋](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/908f859f1be5473881c41ed68ba4d3f1/)

#### 题目描述

有一个教授有一批一模一样的鹰蛋。有一天他来到了一栋楼的脚下，他突然想知道自己的鹰蛋从这栋楼的多少层扔下时恰好不碎。  
一颗鹰蛋如果从i层摔下没有碎，那么从小于j层摔下也不会碎，如果从j层摔下碎了，从大于j层摔下也会摔碎。如果恰好存在一层n，从n层摔下鹰蛋未碎，而从n+1层摔下碎了，那么这批鹰蛋恰好从n层摔下未碎。如果从第一层摔下碎了，那么称恰好从0层摔下未碎；另一方面，如果从最高层（N层）摔下未碎，那么称恰好从N层摔下未碎  
这个教授想知道从第多少层恰好摔下不碎，但是这个教授想使用最少的试验次数来得到这个值。  
现已知鹰蛋的个数M和楼层高度N，试问在最坏情况下，这个教授最少需要试验多少次来得到他想要的结果？  
比如：M为1，N为3。那么这个教授为了得到结果，就必须从一层一层测试，在最坏情况下，最少需要3次试验。但是如果M=2,N=3，那么他就可以第一次从二层扔下，不管碎了还是没碎，他都只需再扔一次即可得到结果，即需要做2次试验即可。

#### 关于输入

有多组输入，每一组输入单独一行。  
分别为两个如题所述的正整数N（大于0小于400001），M （大于0小于N+1）中间用空格隔开。  
如果得到的N和M都为0，表示输入结束。

#### 关于输出

每组输出单独一行，输出需要试验的次数K。

#### 例子输入

100 1
100 2
0 0

#### 例子输出

100
14

#### 提示信息

动态规划，由于输入量比较大，最好尽量优化算法。

#### 核心直觉：蛋多了，能"跳着扔"

- **1 个蛋**：只能线性扫，`N` 层最坏 `N` 次。

- **2 个蛋**：可以先跳着扔（比如从 `√N` 层开始），碎了就用第 2 个蛋在小区间里线性扫。这就是经典的"**鸡蛋掉落**"优化，`M=2` 时约 `2√N` 次。

- **蛋越多**，越能"二分"式跳跃，次数越少。蛋足够多（`M ≥ log₂N`）时，就是**二分查找**，`⌈log₂(N+1)⌉` 次。

#### $O(MN^2)$朴素写法：Time out

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_M = 1e3;
static constexpr int MAX_N = 1e3;
static constexpr int INF = 0x3f3f3f3f;
static int dp[MAX_M][MAX_N] = {INF};
static int N, M;

int main()
{
    cin.tie(nullptr);
    cout.tie(nullptr);
    ios::sync_with_stdio(false);
    /*
    决策DP：更换状态设计实现降维
    一般想法：dp[m][n]：m蛋n层最少层数
                        从第k层扔，碎了，检查下面k-1层
    状态转移：dp[m][n] = min (max(dp[m-1][k-1],
                        从第k层扔，没碎，检查上面n-k层，由于无法确定碎不碎，取碎/不碎 的max，再去对所有k的min
                                dp[m][n-k])) + 1 对所有k查找
    代码实现：能做到从小到大正向递推，比较直观
    */
    int N, M;
    while (cin >> N >> M && (N || M))
    {
        // 1) 先按本次 N, M 重置整个用到的范围
        for (int m = 0; m <= M; m++)
        {
            for (int n = 0; n <= N; n++)
            {
                dp[m][n] = INF;
            }
        }

        // 2) 边界
        for (int m = 0; m <= M; m++)
        {
            dp[m][0] = 0; // 0 层：0 次
        }

        // dp[0][0] 已被上面设 0；dp[0][n] (n≥1) 保持 INF（0 蛋测不了）

        // 3) 递推
        for (int m = 1; m <= M; m++)
        {
            for (int n = 1; n <= N; n++)
            {
                for (int k = 1; k <= n; k++)
                {
                    dp[m][n] = min(dp[m][n],
                                   max(dp[m - 1][k - 1], dp[m][n - k]) + 1);
                }
            }
        }
         cout << dp[M][N] << '\n';
    }



    return 0;
}
```
