# [题目: 插入乘号](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/c470ae98adb84c4a94885711e1a770b1/)

#### 题目描述

给定一个非负整数，用k个乘号将其分割，使得乘积最大。  
例如：在整数12345中插入两个乘号，有以下插入法：  
1*2*345 1*23*45 1*234*5  
12*3*45 12*34*5  
123*4*5  
其中最大值是123*4*5 = 2460

#### 关于输入

一行两个非负整数，非负整数s（s ≦ 10^9）和乘号的个数k（0 ≦ k < s的位数）。  
输入保证，如果按题目要求的乘法操作，不会使int发生溢出。

#### 关于输出

一行一个整数，即乘积的最大值

#### 例子输入

12345 2

#### 例子输出

2460

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_N = 11;
static constexpr int MAX_K = 10;
static int dp[MAX_N][MAX_K];
static int num[MAX_N][MAX_N];
int main()
{
    /*
    决策DP：

    状态设计：

    dp[i][j] 表示 前i位插入j个乘号的最大乘积       答案：dp[n][k]

    状态转移：（类似于石子归并）

    设最后一个乘号把s[0...i-1](前i位)切分成s[0...t-1]（前t位）与s[t...i-1]
    由s[0...t-1]中有j-1个乘号，s[t...i-1]中没有乘号，作为一个数
    j-1个乘号至少需要j个数字，故j<=t，t<=i-1 则t的范围是j<=t<=i-1

    dp[i][j] = max(dp[t][j-1]*num(s[t...i-1]))
    j<=t<=i-1

    边界处理：dp[0][j] = 0  0位乘积为0
             dp[i][0] = 0  num(s[0...i-1])
    */

    string s;
    int k;
    cin >> s >> k;
    int n = s.size();

    // num[l][r] = s[l..r] 组成的整数（下标闭区间）

    for (int l = 0; l < n; l++)
    {
        int v = 0;
        for (int r = l; r < n; r++)
        {
            v = v * 10 + (s[r] - '0');
            num[l][r] = v;
        }
    }

    // 边界：0 个乘号，前 i 位整体一个数
    for (int i = 1; i <= n; i++)
    {
        dp[i][0] = num[0][i - 1];
    }

    // 递推：j 从 1 到 k，i 从 j+1 到 n
    for (int j = 1; j <= k; j++)
    {
        for (int i = j + 1; i <= n; i++)
        {
            for (int t = j; t <= i - 1; t++)
            {
                dp[i][j] = max(dp[i][j], dp[t][j - 1] * num[t][i - 1]);
            }
        }
    }

    cout << dp[n][k] << '\n';

    return 0;
}
```
