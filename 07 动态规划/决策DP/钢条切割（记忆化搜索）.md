#### 题目描述

Serling公司购买长钢条，将其切割为短钢条出售。切割工序本身没有成本支出。公司管理层希望知道最佳的切割方案。假定我们知道Serling公司出售一段长为i英寸的钢条的价格为pi(i=1,2,…，单位为美元)。钢条的长度均为整英寸。

给定一段长度为n英寸的钢条和一个价格表pi(i=1,2,…n)，求切割钢条方案，使得销售收益rn最大。

#### 关于输入

第一行：n，表示购买的长钢条的长度。  
接下来一行包含 n 个数字，第 i 个数字出售长为 i 的钢条的价格，即 pi。

其中 0 < n <= 3000，0 < pi <= 10000。

#### 关于输出

输出仅一行，为最大的销售收益值 rn。  

#### 例子输入

7
1 5 8 9 10 17 17

#### 例子输出

18

#### 提示信息

注意，如果长度为n英寸的钢条的价格pn足够大，最优解可能就是完全不需要切割。

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_N = 3005;
static int p[MAX_N];      // p[i] = 长度 i 的价格，1-base
static int memo[MAX_N];   // memo[len] = 长度 len 的最大收益，-1 表示未算

int dfs(int len) {
    if (len == 0) {
        return 0;
    }
    if (memo[len] != -1) {
        return memo[len];
    }

    int best = 0;
    // 第一段切长度 i 直接卖 p[i]，剩下 len-i 继续最优切
    for (int i = 1; i <= len; i++) {
        best = max(best, p[i] + dfs(len - i));
    }

    memo[len] = best;
    return best;
}

int main() {
    cin.tie(nullptr);
    cout.tie(nullptr);
    ios::sync_with_stdio(false);

    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> p[i];
    }

    // 初始化 memo 为 -1（未计算）
    for (int i = 0; i <= n; i++) {
        memo[i] = -1;
    }

    cout << dfs(n) << '\n';
    return 0;
}
```
