这批题确实"丰富到吓人"——它和上一批（递归/回溯）**主题完全不同**，这是一整套**动态规划（DP）**的经典题型汇编，而且覆盖面非常完整，从线性 DP 到区间 DP、背包、LCS、记忆化搜索、DP 优化都有。我按 DP 类型给你分类梳理，每道题点出状态定义和转移核心：

## 一、线性 DP（一维/二维递推）（2026.11.11）

| 题目                 | 状态与转移核心                                                     |
| ------------------ | ----------------------------------------------------------- |
| **爬梯子**            | `dp[i] = dp[i-1] + dp[i-2]`（走 1/2 步），最基础入门                  |
| **求数组不相邻元素之和的最大值** | `dp[i] = max(dp[i-1], dp[i-2] + a[i])`，打家劫舍原型               |
| **拦截导弹**           | 最长不上升子序列（LIS 变体）：`dp[i] = max(dp[j]) + 1, j<i 且 a[j]>=a[i]` |
| **合唱队形**           | 正反两遍 LIS：`ans = max(LIS_left[i] + LIS_right[i] - 1)`        |
| **最长等差数列子集**       | `dp[i][d]` = 以 i 结尾、公差 d 的最长长度，用哈希/数组存公差                    |

## 二、序列 DP（双串）

| 题目                 | 状态与转移核心                                                                     |
| ------------------ | --------------------------------------------------------------------------- |
| **(15-9) 最长公共子序列** | `dp[i][j]`：`a[i]==b[j]` 时 `dp[i-1][j-1]+1`，否则 `max(dp[i-1][j], dp[i][j-1])` |
| **单词拼写检查**         | 编辑距离：`dp[i][j]` = 插入/删除/替换三选一取 min，LCS 的近亲                                  |
| **碱基的忧伤**          | 基因序列比对，本质是带权编辑距离/最长公共子串类                                                    |

## 三、背包 DP

| 题目              | 状态与转移核心                                        |
| --------------- | ---------------------------------------------- |
| **采药**          | 经典 0/1 背包：`dp[j] = max(dp[j], dp[j-w]+v)`，j 倒序 |
| **最佳凑单**        | 0/1 背包/子集和，凑到不超过预算的最大值                         |
| **受限时间内的最小通行费** | 带约束的背包/最短路 DP，状态多一维"时间"                        |

## 四、区间 DP

| 题目                  | 状态与转移核心                                                   |
| ------------------- | --------------------------------------------------------- |
| **(15.7) 石子归并**     | `dp[i][j] = min(dp[i][k] + dp[k+1][j]) + sum(i,j)`，枚举断点 k |
| **矩阵取数游戏**          | 区间取数，`dp[i][j]` 表示区间剩余，按题意取两端转移                           |
| **最长等差数列子集**（也可归此类） | 区间/双指针 + DP                                               |

## 五、路径/网格 DP

| 题目                 | 状态与转移核心                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------- |
| **(15-9) 三角形最佳路径** | `dp[i][j] = a[i][j] + max(dp[i-1][j-1], dp[i-1][j])`，自底向上                                   |
| **元素和最大的子矩阵**      | 枚举行区间压缩成一维，再跑最大子段和（Kadane）                                                                  |
| **滑雪（1064）**       | 记忆化搜索：`dp[x][y] = 1 + max(四个更低邻居的 dp)`，DAG 上最长路                                             |
| **鹰蛋**             | `dp[k][m]` = k 个蛋 m 层最少试验次数，`dp[k][m] = 1 + min over x max(dp[k-1][x-1], dp[k][m-x])`，可二分优化 |

## 六、决策/划分 DP

| 题目        | 状态与转移核心                                            |
| --------- | -------------------------------------------------- |
| **钢条切割**  | `dp[n] = max(p[i] + dp[n-i])`，完全背包思想               |
| **插入乘号**  | `dp[i][k]` = 前 i 位插 k 个乘号的最大值，枚举最后一段               |
| **山区建小学** | 区间划分 DP：`dp[i][j]` = 前 i 村建 j 所小学最小距离，预处理代价 + 枚举断点 |

## 七、其他/综合

| 题目             | 核心                  |
| -------------- | ------------------- |
| **小游戏**（上批）    | 博弈/状态搜索，可能配合 DP     |
| **最佳凑单**（重复出现） | 背包                  |
| **矩阵取数游戏**     | 区间 DP + 高精度（取数可能很大） |

## 这批题的 DP 知识地图

它其实是一条**DP 能力进阶链**，和上批递归形成"递归 → 记忆化 → 递推 DP"的完整闭环：

```
线性 DP（爬梯子、不相邻和、LIS）
   ↓ 加一维
双串 DP（LCS、编辑距离、碱基）
   ↓ 加容量维
背包 DP（采药、凑单、通行费）
   ↓ 加区间维
区间 DP（石子归并、矩阵取数）
   ↓ 网格/图上的 DP
路径 DP + 记忆化搜索（三角形、子矩阵、滑雪、鹰蛋）
   ↓ 加决策维
划分 DP（钢条、乘号、建小学）
```

**几个贯穿全批的关键技巧**：

1. **记忆化搜索 = 递归 + 缓存**：滑雪是典型，`dp[x][y]` 记住后不重算，这就是上批"DFS 不必然回溯"的延伸——这里 DFS 加了 memo，本质是 DAG 上求最长路。
2. **LIS 的两遍法**：合唱队形 = 正反 LIS 拼起来减 1。
3. **子矩阵 = 行压缩 + 最大子段和**：二维降一维的经典套路。
4. **区间 DP 三要素**：区间长度从小到大枚举、枚举断点、前缀和加速合并代价。
5. **鹰蛋的二分优化**：`dp[k][m]` 关于 m 单调，内层枚举 x 可二分，O(k·m·log m)。
