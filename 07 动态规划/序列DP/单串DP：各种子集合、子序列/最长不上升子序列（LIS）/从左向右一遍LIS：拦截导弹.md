# [题目: 拦截导弹](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/672d5830caa64421b68e73d02e3bab27/)

#### 题目描述

某国为了防御敌国的导弹袭击，开发出一种导弹拦截系统。但是这种导弹拦截系统有一个缺陷：虽然它的第一发炮弹能够到达任意的高度，但是以后每一发炮弹都不能高于前一发的高度。某天，雷达捕捉到敌国的导弹来袭，并观测到导弹依次飞来的高度，请计算这套系统最多能拦截多少导弹。拦截来袭导弹时，必须按来袭导弹袭击的时间顺序，不允许先拦截后面的导弹，再拦截前面的导弹。  

#### 关于输入

输入有两行：  
  第一行，输入雷达捕捉到的敌国导弹的数量k（k<=25），  
  第二行，输入k个正整数，表示k枚导弹的高度，按来袭导弹的袭击时间顺序给出，以空格分隔。  

#### 关于输出

输出只有一行，包含一个整数，表示最多能拦截多少枚导弹。  

#### 例子输入

8
300 207 155 300 299 170 158 65

#### 例子输出

6

```cpp
#include <bits/stdc++.h>
using namespace std;

static int nums[30];
static int dp[30];

int main()
{
    /*
    i:    0   1   2   3   4   5   6   7
    num: 300 207 155 300 299 170 158  65
    dp:   1   2   3   2   3   4   5   6
    （最长不上升子序列）
    dp[i]表示以nums[i]结尾的最长不上升子序列长度
    自然想到：这个不上升子序列中倒数第二个元素可能是谁？→ 前面任意 >= nums[i] 的 nums[j]，选其中 dp[j] 最大的接上
    只比较nums[i]与nums[i-1]是不够的，需要考虑nums[i]前面所有比它大的数

    得到：
    dp[0] = 1
    dp[i] = max(dp[j])+1 ,0≤j＜i且nums[j]>=nums[i]

    */

    int n;
    cin >> n;
    for(int i = 0; i < n; i++){
        cin >> nums[i];
    }

    memset(dp,0,sizeof(dp));
    dp[0]=1;

    for(int i =1; i< n; i++){
        for(int j = 0; j < i; j++){
            if(nums[j]>=nums[i]){
                dp[i] = max(dp[i],dp[j]);
            }
        }
        dp[i]+=1;
    }
    //注意最长非上升子序列不一定以最后一个元素结尾。
    int ans =1;
    for(int i = 0; i <= n-1; i++){
        ans = max(ans,dp[i]);
    }
    cout<<ans;
    return 0;
}
```
