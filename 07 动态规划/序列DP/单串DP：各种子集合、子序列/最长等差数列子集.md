# [题目: 最长等差数列子集](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/038f770f39524f9683344fc93b32f9f3/)

#### 题目描述

一个等差数列是指以增序排列后，相邻的两个数后一个与前一个数之差值恒定。规定一个等差数列中的数不应少于3个。任给 n ( 2 < n < 5000)个正整数，请判断可否从中选择子集构成等差数列。若能，则选出满足条件的最大子集合（即，元素个数最多），并按从小到大输出子集中的元素，逗号间隔。若有多个子集同时满足最大，则取差值最大的子集；若同时有多个子集满足集合大小最大，且差值也相等，则取起始元素最大的子集。如果没有满足条件的子集合，则输出 NO.

例如，有10个元素：20,14,6,15,22,7,23,8,18,25

从6开始的最长等差数列是：6,7,8 和 6,14,22  
从7开始的最长等差数列是：7,15,23  
从8开始的最长等差数列是：8,14,20 和 8,15,22  
从14开始的最长等差数列是：14,18,22  
从15开始的最长等差数列是：15,20,25  
从18开始的最长等差数列是：18,20,22  
**  
上述7个最长序列中，长度都为3。按差值看，6,14,22 和 7,15,23 同时最大，但 7 > 6，因此，结果应该选 7,15,23**

#### 关于输入

2行：  
第1行，n，表示整数个数；  
第2行，n 个正整数，空格间隔；  

#### 关于输出

按增序输出最长等差数列子集，逗号间隔。

#### 例子输入

10
20 14 6 15 22 7 23 8 18 25

#### 例子输出

7,15,23

# Insight1 关于DP状态设计

dp状态设计不是凭空想到的，而是从**题意**和**转移**中得到的。

#### 第一步：从"答案长什么样"提取信息

题目要输出一个具体的等差数列，还规定了三层平局规则。你把答案的形态摊开看，一个等差数列由三样东西唯一确定：

1. **起点**（首项）——平局规则第三优先级要用

2. **公差**——平局规则第二优先级要用

3. **长度**——优化目标，第一优先级

所以"答案三信息"不是随便列的，是**题目输出要求直接规定的**：它要你按 `长度 → 公差 → 起点` 比较，那这三样就必须在你的算法里可获取。这是**从输出反推状态必须携带的信息**。

#### 第二步：区分"索引"和"值"——哪个信息决定转移？

三信息里，只有**公差**具备"决定下一个元素是谁"的能力：

- 知道起点 i 和公差 d → 下一个元素是 `a[i]+d`，再下一个 `a[i]+2d`……**路径唯一确定**

- 知道起点 i 和长度 L → 不知道公差，下一个元素**无法确定**，状态不封闭

所以公差**必须是索引**（放进状态维度），否则转移写不出来。这是"状态封闭性"要求逼出来的。

那起点和长度呢？

- **起点 i**：它是序列位置，天然是索引（所有序列 DP 都有位置维），而且平局规则要用"起点最大"，放索引后直接可比较，**顺理成章做索引**。

- **长度**：它是被优化的目标。DP 的铁律是"**要优化的量放值，不放索引**"——如果长度做索引，你需要 `dp[i][L]` 再额外存公差，维度爆炸且转移不封闭。所以长度**只能做值**。

这一步的推理是：**"决定转移的结构信息"和"序列位置"做索引，"被优化的目标"做值**。三信息里，公差和起点进索引，长度进值。

#### 第三步：为什么是"以 i 为起点"而不是"以 i 为结尾"

这是你这个设计里最有价值的一个选择，也是从平局规则反推的：

- 若定义"**以 i 结尾**"，`dp[i][d]` 往前找 `a[i]-d`，递推自然（从小到大），但**起点信息藏在路径深处**，要额外记录才能比较"起点最大"。

- 若定义"**以 i 为起点**"，`dp[i][d]` 往后找 `a[i]+d`，起点**直接就是 i**，"起点最大"这条平局规则**天然可比较**，不用额外存信息。

题目第三优先级是"起点最大"，所以选"以 i 为起点"让三个信息全部显式在手：**i 是起点、d 是公差、dp 值是长度**。这是**从平局规则反推方向**——不是随便选的。

#### 第四步：为什么不是"双串"也不是"线性 DP"

回到你之前的疑问，现在能说清了：

- **不是双串**：只有一个序列，公差不是"第二个串"，而是**参数化的约束维**。

- **不是线性 DP**：状态二维 `(i, d)`，且 d 不是位置的自然延伸，是**公差参数维**。

- **本质是 LIS 推广**：LIS 的 `dp[i]`（以 i 结尾的最长上升子序列）把"上升"换成"公差固定为 d"，就多出公差维。你这题是 LIS 骨架 + 公差参数维 + 起点方向。

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_N = 5004; // 题意2 < n < 5000
static constexpr int MAX_D = 5004; // 题意没给出每个数的取值范围，经过实测，5004能AC
static int nums[MAX_N];
static int dp[MAX_N][MAX_D];

int main()
{
    /*
    排序后化归为最长等差子序列问题
    观察题意可知答案含有三个信息：
    1）最长等差子序列的起始元素nums[i] （第三优先级）
    2）最长等差序列的公差d           （第二优先级）
    3）最长等差序列的大小（元素个数） ( 第一优先级)
    设计dp[i][d]表示从nums[i]起始的，公差为d的最长等差子序列大小
    这种状态设计虽然能转移，但是需要逆推，改成能正推的形式，也就是LIS变体：

    dp[i][d]表示从nums[i]结束的，公差为d的最长等差子序列大小，
    设dp[i][d]=L，起点满足s=nums[i]-(L-1)d

    状态转移方程：
    dp[i][d] = max(dp[i][d],dp[j][d]+1) j<i, d = nums[i]-nums[j]

    从而dp数组中的每一个元素，都存储了排序三个优先级所需的数据，一次遍历即可得出答案。
    */

    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> nums[i];
    }

    sort(nums, nums + n); // 排序

    for (int i = 0; i < n; i++)
    {
        dp[i][0] = 1; // d=0 单元素初值
        for (int j = 0; j < i; j++)
        {
            int d = nums[i] - nums[j]; // d >= 0
            // 上一个元素
            int prev = dp[j][d];
            int cur = (prev == 0 ? 2 : prev + 1); // 不存在视为 2,因为i和j构成长度为2的序列
            // 取max
            if (cur > dp[i][d])
            {
                dp[i][d] = cur;
            }
        }
    }

    // 收尾：L>=3，按 (L, d, s) 三级降序
    long long resL = 0, resD = -1, resS = -1;
    for (int i = 0; i < n; i++)
    {
        for (int d = 0; d < MAX_D; d++)
        {
            int L = dp[i][d];
            if (L < 3)
                continue; // 至少 3 个
            long long s = (long long)nums[i] - (long long)(L - 1) * d;
            if (L > resL ||
                (L == resL && d > resD) ||
                (L == resL && d == resD && s > resS))
            {
                resL = L;
                resD = d;
                resS = s;
            }
        }
    }

    if (resL < 3)
    {
        cout << "NO" << endl;
        return 0;
    } // 无解

    // 输出用 resD，不是残留的d
    for (int k = 0; k < resL; k++)
    {
        if (k)
            cout << ",";
        cout << resS + (long long)k * resD;
    }
    cout << endl;
    return 0;
}
```
