# [10. 正则表达式匹配](https://leetcode.cn/problems/regular-expression-matching/)

给你一个字符串 `s` 和一个字符规律 `p`，请你来实现一个支持 `'.'` 和 `'*'` 的正则表达式匹配。

- `'.'` 匹配任意单个字符
- `'*'` 匹配零个或多个前面的那一个元素

返回一个布尔值，表示匹配是否覆盖整个输入字符串（而非部分）。

 

**示例 1：**

**输入：**s = "aa", p = "a"
**输出：**false
**解释：**"a" 无法匹配 "aa" 整个字符串。

**示例 2:**

**输入：**s = "aa", p = "a*"
**输出：**true
**解释：**因为 '*' 代表可以匹配零个或多个前面的那一个元素, 在这里前面的元素就是 'a'。因此，字符串 "aa" 可被视为 'a' 重复了一次。

**示例 3：**

**输入：**s = "ab", p = ".*"
**输出：**true
**解释：**".*" 表示可匹配零个或多个（'*'）任意字符（'.'）。

**提示：**

- `1 <= s.length <= 20`
- `1 <= p.length <= 20`
- `s` 只包含从 `a-z` 的小写字母。
- `p` 只包含从 `a-z` 的小写字母，以及字符 `.` 和 `*`。
- 保证每次出现字符 `*` 时，前面都匹配到有效的字符

```cpp
static constexpr int MAX_SLEN =22;
static constexpr int MAX_PLEN =22;
static bool dp[MAX_SLEN][MAX_PLEN];

class Solution {
public:
    /*字符串dp
    状态设计：
        设dp[i][j]表示s的前i个字符s[1...i]和p的前j个字符p[1...j]匹配 
    逆推法得到状态转移方程：
        辅助函数 match_char()
        讨论s的第i个字符和p的第j个字符
        根据题意. * 只会出现在j中，那么据此讨论
        1）p[j]!='*' 等价于 二者均为小写字母或.
        （这里将.视为一个小写字母，因为它能和任何一个小写字母匹配）
        dp[i][j] = match_char(s[i],p[j])? dp[i-1][j-1] : false;
        2)p[j]=='*' 等价于 二者中存在一个* 
        研究这个*和它前面的那个字母 也就是p[j-1]
            2.1)如果前面这个字母和p末尾匹配，它可以匹配0个或若干个p末尾的字母
                注：即使能匹配，也可能因为数量问题不需要匹配，比如：
                s为aaa
                p为aaaa*
                所以需要or上dp[i][j-2]
            2.2)如果前面这个字母和p末尾不匹配，只能匹配0个该字母
                dp[i][j] = match_char(s[i],p[j-1])? (dp[i-1][j] || dp[i][j-2]) : dp[i][j-2]
    边界处理：
        dp[0][0] = true; 两个空串可以匹配
        对于dp[0][j] 这里要有一个一维dp，按p的第j个字符是不是*分类讨论
        如果是，那么*前面的字符匹配0次，dp[0][j] = dp[0][j-2]
        如果不是，无法匹配，dp[0][j]=false
        dp[i][0] = false;非空串和空串不匹配 i = 1...slen
    */
    //这里a是s中的字符，只有小写字母，b为s中的字符，是小写字母或.
    bool match_char(char a, char b){
        return b == '.' || a == b;
    }

    bool isMatch(string s, string p) {
        int slen = s.size(), plen = p.size();

        dp[0][0] = true;
        for(int i = 1; i <= slen; i++) dp[i][0] = false;

        // dp[0][j]: p 的前 j 个字符能否匹配空串
        for(int j = 1; j <= plen; j++){
            if(j >= 2 && p[j-1] == '*')
                dp[0][j] = dp[0][j-2];
            else
                dp[0][j] = false;
        }

        for(int i = 1; i <= slen; i++){
            for(int j = 1; j <= plen; j++){
                if(p[j-1] != '*'){
                    dp[i][j] = match_char(s[i-1], p[j-1]) ? dp[i-1][j-1] : false;
                }else{
                    // 匹配 0 个 p[j-2]
                    bool zero = dp[i][j-2];
                    // 匹配 1 个及以上 p[j-2]
                    bool more = match_char(s[i-1], p[j-2]) && dp[i-1][j];
                    dp[i][j] = zero || more;
                }
            }
        }
        return dp[slen][plen];
    }

};
```
