# [44. 通配符匹配](https://leetcode.cn/problems/wildcard-matching/)

给你一个输入字符串 (`s`) 和一个字符模式 (`p`) ，请你实现一个支持 `'?'` 和 `'*'` 匹配规则的通配符匹配：

- `'?'` 可以匹配任何单个字符。
- `'*'` 可以匹配任意字符序列（包括空字符序列）。

判定匹配成功的充要条件是：字符模式必须能够 **完全匹配** 输入字符串（而不是部分匹配）。

 

**示例 1：**

**输入：**s = "aa", p = "a"
**输出：**false
**解释：**"a" 无法匹配 "aa" 整个字符串。

**示例 2：**

**输入：**s = "aa", p = "*"
**输出：**true
**解释：**'*' 可以匹配任意字符串。

**示例 3：**

**输入：**s = "cb", p = "?a"
**输出：**false
**解释：**'?' 可以匹配 'c', 但第二个 'a' 无法匹配 'b'。

**提示：**

- `0 <= s.length, p.length <= 2000`
- `s` 仅由小写英文字母组成
- `p` 仅由小写英文字母、`'?'` 或 `'*'` 组成

```cpp
static bool dp[2004][2004] = {false};

class Solution {
public:
    /*字符串dp
    注意本题s和p均可为空串

    dp[i][j]表示s的前i个字符和j的前j个字符能完全匹配
    状态转移：
    讨论p的第j个字符
    1)如果是'?'，匹配掉s的一个字符
    dp[i][j]=dp[i-1][j-1]
    2)如果是'*'，
        2.1)“吃掉”s的末尾，p继续参与匹配
        2.2)*匹配空串，跳过这个
    dp[i][j]=dp[i-1][j]|| dp[i][j-1]
    3)如果是一个字符
    dp[i][j]=(s[i-1]==p[j-1])? dp[i-1][j-1] : false;
    边界处理：
    dp[0][0] = true
    dp[i][0] = false i = 1...slen 因为此时p为空串
    //这里需要一个一维dp
    dp[0][j] = p[j-1]=='*' && dp[0][j-1]
    (WA case s="aab" p ="c*a*b" 因为没考虑&& dp[0][j-1])
    */
    bool isMatch(string s, string p) {
        int slen = s.size();
        int plen = p.size();
        dp[0][0] = true;
        for(int i = 1;i<=slen;i++){
            dp[i][0]=false;
        }
        for(int j = 1; j<= plen;j++){
            dp[0][j]=(p[j-1]=='*'&& dp[0][j-1]);
        }
        for(int i = 1; i <=slen;i++){
            for(int j = 1; j <=plen;j++){
                if(p[j-1]=='?'){
                    dp[i][j]=dp[i-1][j-1];
                }else if(p[j-1]=='*'){
                    dp[i][j]=dp[i-1][j] || dp[i][j-1];
                }else{
                    dp[i][j]=(s[i-1]==p[j-1])? dp[i-1][j-1] : false;
                }
            }
        }
        return dp[slen][plen];
    }
};
```
