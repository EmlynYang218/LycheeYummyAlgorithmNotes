# [题目: 单词拼写检查](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/782cfb44c6224de09ddfc6e3026b50c8/)

#### 题目描述

编辑距离是针对二个字符串的差异程度的量化量测，量测方式是看至少需要多少次的处理才能将一个字符串变成另一个字符串。  
本题要求写一个单词拼写检查器，具体做法是，根据一个含有正确单词的字典，检查某些单词是否正确，如果不正确，则找出字典中与其编辑距离为1的单词。  
使一个单词与其编辑距离为1，修改方法可以是：  

1. 删除词中的一个字母  
2. 用任意其他字母替换词中的一个字母  
3. 在词的任意位置插入一个字母  

#### 关于输入

字典最多有10000个单词，输入时每个单词占一行，以“#”结尾，无重复单词。  
字典后为要检查的单词，每个单词占一行，以“#”结尾，最多30个待检查。

#### 关于输出

对于每一个单词x，  
如果在字典中，则输出"x is correct"，占一行；  
若不在字典中，则输出"x:"+字典中所有编辑距离为1的词；  
如果无法找到相应的词，则输出"x:"

#### 例子输入

```
i
is
has
have
be
my
more
contest
me
too
if
award
#
me

m

```

#### 例子输出

```
me is correct
aware: award
m: i my me
contest is correct
hav: has have
oo: too
or:
i is correct
fi: i
mre: more me
```

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_WORD_LEN = 104;    // 我猜每个单词不超过100字符
static constexpr int MAX_DICT_SIZE = 10004; // 字典最多有10000个单词
static constexpr int MAX_QUERY_SIZE = 34;   // 最多30个待检查

static int dp[MAX_WORD_LEN][MAX_WORD_LEN];
static string dict[MAX_DICT_SIZE];
static string queries[MAX_QUERY_SIZE];

int edit_distance(const string &a, const string &b)
{
    int as = a.size(), bs = b.size();
    // 走到这里说明a与b等长或者长度最多差1
    // dp[i][j]表示a的前i个字符与j的前j个字符的编辑距离
    //                                    相等                  替换              插入         删除
    // 转移方程：dp[i][j] = (a[i]==b[j])? dp[i-1][j-1] : min(dp[i-1][j-1]+1 , dp[i][j-1]+1,dp[i-1][j]+1)
    // 边界条件：dp[0][0] = 0 空串==空串 dp[i][0] = i 添加i个相应字符 dp[0][j] = j 删除j个字符
    dp[0][0] = 0;
    for (int i = 1; i <= as; i++)
    {
        dp[i][0] = i;
    }
    for (int j = 1; j <= bs; j++)
    {
        dp[0][j] = j;
    }
    for (int i = 1; i <= as; i++)
    {
        for (int j = 1; j <= bs; j++)
        {
            // 1-base转0-base
            dp[i][j] = (a[i - 1] == b[j - 1]) ? dp[i - 1][j - 1] : min(dp[i - 1][j - 1], min(dp[i][j - 1], dp[i - 1][j])) + 1;
        }
    }
    return dp[as][bs];
}
int main()
{
    string s;
    int n = 0; // 字典中词汇数量
    while (cin >> s && s != "#")
    {
        dict[n] = s;
        n++;
    }
    int q = 0; // 待查询数量
    while (cin >> s && s != "#")
    {
        queries[q] = s;
        q++;
    }

    vector<string> ans;
    bool is_correct;

    for (int i = 0; i < q; i++)
    {
        cout << queries[i];
        is_correct = false;
        ans.clear();

        for (int j = 0; j < n; j++)
        {
            int d = edit_distance(queries[i], dict[j]);
            if (d == 0)
            {
                is_correct = true;
                break;
            }else if(d==1){
                ans.push_back(dict[j]);
            }
        }

        if(is_correct){
            cout<<" is correct\n";
        }else{
            cout<<':';
            for(auto w : ans){
                cout<<' '<<w;
            }
            cout<<'\n';
        }
    }
}
