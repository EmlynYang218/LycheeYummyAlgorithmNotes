#### 题目描述

一张 1×1 的实心正方形贴纸，是 xx 拼图案的起点。每轮把上一轮的图案复制 8 份，按 3 行 3 列排列，中心位置留一个同样大小的空白正方形，其余位置各放一份；各份图案不旋转，相邻位置紧贴。

求 n 轮后图案的边界总长度，包括外轮廓和所有孔洞的边界，不计实心部分相贴的边。最小正方形的边长始终为 1，答案对 10007 取模。

当 n=2 时，图案如下。深色部分为贴纸，图案内部的白色部分为孔洞，红线表示计入周长的边界；灰色细线仅用于划分单位格。

![](https://programming.pku.edu.cn/probset/d381b7479a464a3c98b71bde9d5aff70/9ef5d76c3c094463900c2b9d8e3f742b/sticker-n2.png)

外轮廓长 4×9=36，中心孔洞的边界长 4×3=12，另有 8 个单位孔洞，故总长为 36+12+8×4=80。

数据范围：0≤n≤1,000,000。

#### 关于输入

第一行包含一个整数 n，表示复制的轮数。

#### 关于输出

输出一行，包含一个 0 至 10006 的整数，表示答案对 10007 取模的结果，不补前导零。

#### 例子输入

样例 1 输入：
2
样例 2 输入：
0

#### 例子输出

样例 1 输出：
80
样例 2 输出：
4

#### 提示信息

数据范围：0≤n≤1,000,000。

进行加法、减法或乘法计算时，可以每算一步就对 10007 取模，再用取模后的值继续计算。这样最终得到的结果，与先算出完整答案再对 10007 取模相同。

样例 1 说明：外轮廓长 36，中心孔长 12，八个单位孔共长 32。

样例 2 说明：尚未复制，单位正方形周长为 4。

```cpp
#include<bits/stdc++.h>
using namespace std;

static constexpr int MOD = 10007;

/*dp+模运算
a0 = 4
a1 = 16 = 8a0 - 16*(1)
a2 = 8a1 - 16*(3) 

an = 8a_n-1 - 16(bn-1)
bn = 3*b_n-1

a0 = 0, b0 = 1
a1 = 16 b1 = 3
a2 = 08 b2 = 9

进行加法、减法或乘法计算时，可以每算一步就对 10007 取模，
再用取模后的值继续计算。这样最终得到的结果，
与先算出完整答案再对 10007 取模相同。
*/

int main(){
    //一维数组滚动dp
    int pre_a=4,pre_b=1,cur_a=0,cur_b=0;
    int n;
    cin >> n;
    if(n==0){
        cout<<4;
    }else{
        for(int i = 1; i <= n; i++){
            //防止负数取模出错需要写(x%MOD-b%MOD + MOD)%MOD
            cur_a = ((8*pre_a% MOD) - (16*pre_b % MOD) + MOD) % MOD;
            cur_b = 3*pre_b % MOD;
            pre_a = cur_a;
            pre_b = cur_b;
        }
        cout<<pre_a;
    }
    return 0;
}
```
