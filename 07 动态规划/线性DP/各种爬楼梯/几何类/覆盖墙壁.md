# [题目: 覆盖墙壁](https://programming.pku.edu.cn/probset/7d229bb5254143a9a8287a90a8950281/fefb854e1e6943df93878b907a59031e/)

#### 题目描述

你有一个长为 N 宽为 2 的墙壁，给你两种砖头：一种是 L 型覆盖 3 个单元的砖头，另一种长 2 宽 1。如下：

<img src="https://programming.pku.edu.cn/probset/7d229bb5254143a9a8287a90a8950281/fefb854e1e6943df93878b907a59031e/1.png" title="" alt="" width="237">

砖头可以旋转，两种砖头可以无限制提供。你的任务是计算用这两种来覆盖 2×N 的墙壁的覆盖方案数。

例如一个 2×3 的墙可以有 5 种覆盖方法，如下：

<img src="https://programming.pku.edu.cn/probset/7d229bb5254143a9a8287a90a8950281/fefb854e1e6943df93878b907a59031e/2.png" title="" alt="" width="299">

注意可以使用两种砖头混合起来覆盖，如 2×4 的墙可以这样覆盖：

<img src="https://programming.pku.edu.cn/probset/7d229bb5254143a9a8287a90a8950281/fefb854e1e6943df93878b907a59031e/3.png" title="" alt="" width="294">

数据范围：1≤N≤1,000,000。

由于结果很大，你只需要输出答案对 10000 取模后的值（即不加前导零的后四位数）。为了实现这一点，你可以不断地将结果 %10000。例如可以通过如下方式求出斐波那契数列第 n 项对 10000 取模后的值：

f[1] = f[2] = 1;  
for (int i = 3; i <= n; i++)  
    f[n] = (f[n-1] + f[n-2]) % 10000;

#### 关于输入

一行一个整数 N，表示墙壁的长。

#### 关于输出

一行一个整数，表示答案对 10000 取模后的值。

#### 例子输入

样例 1 输入：
3
样例 2 输入：
13

#### 例子输出

样例 1 输出：
5
样例 2 输出：
3465

#### 提示信息

数据范围：1≤N≤1,000,000。

```cpp
#include <iostream>
using namespace std;

const int MOD = 10000;
int f[1000001];

/*
a1 = 1
a2 = 2
a3 = 5
a4 = 12
观察an = 2*a(n-1)+a(n-3)
*/


int main() {
    int n;
    cin >> n;

    f[0] = 1;
    f[1] = 1;
    f[2] = 2;

    for (int i = 3; i <= n; i++) {
        f[i] = (2 * f[i - 1] + f[i - 3]) % MOD;
    }

    cout << f[n] << '\n';
    return 0;
}
```
