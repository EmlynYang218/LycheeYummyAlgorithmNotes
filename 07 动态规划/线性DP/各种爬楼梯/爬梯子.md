# [题目: 爬梯子](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/86546792957e40acbe6866c8a8ec822c/)

#### 题目描述

小明正在爬楼梯，到楼顶一共有N级台阶（1<=N<=1000）。小明每一步可以跨1级，2级或3级台阶。请问小明有多少种方法可以正好到达楼顶呢？  
由于所有可能的方法数比较大，所以只要输出所有可能方法数除以10000的余数。  

#### 关于输入

输入共一行，一个正整数N，表示台阶数。  

#### 关于输出

一行，一个整数。表示所有可能方法数除以10000的余数。

#### 例子输入

3

#### 例子输出

4

#### 提示信息

1）3级台阶有4种走法：  
（1）每次跨1级，共跨3次；  
（2）先跨1级再跨2级；  
（3）先跨2级再跨1级；  
（4）直接跨3级。

2）递归可能会超时

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MOD = 10000;
int main()
{
    //dp[i]=dp[i-1]+dp[i-2]+dp[i-3]
    //      走1级    走2级    走3级
    //1 2 4 
    //实际上只需要保存四个状态。
    int dp[4] = {1, 2, 4,0};

    int N;
    cin >> N;
    switch (N)
    {
    case 1:
        cout<<1;
        break;
    case 2:
        cout<<2;
        break;
    case 3:
        cout<<4;
        break;
    default:
        //1-base转 0 base；
        for(int i = 3; i<N;i++){
            dp[3] = (dp[2]+dp[1]+dp[0])%MOD;
            dp[0] = dp[1];
            dp[1] = dp[2];
            dp[2] = dp[3];
        }
        cout<<dp[3];
        break;
    }
    return 0;
}
```
