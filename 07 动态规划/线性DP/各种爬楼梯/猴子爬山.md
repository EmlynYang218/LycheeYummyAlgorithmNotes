# [题目: 猴子爬山](https://programming.pku.edu.cn/probset/7854ebcf1a8e4dbb98b3c87b684492a2/455a22b7bb33465ba96a821d5013f94c/)

#### 题目描述

一个小猴子蹦蹦跳跳去爬山。从山下到山顶共有m个台阶（1 ≤ m ≤ 3000）。小猴子很顽皮，有时候一次跳1个台阶，有时候一次跳3个台阶，还有时候一次跳5个台阶。请问，小猴子上山有多少种不同的跳法。  
例如，当m = 6时，小猴子有下面8种跳法：  

1. 1 1 1 1 1 1  
2. 1 1 1 3  
3. 1 1 3 1  
4. 1 3 1 1  
5. 3 1 1 1  
6. 3 3  
7. 1 5  
8. 5 1  

#### 关于输入

输入只有1行。其中包含一个数字 m ，表示从山下到山顶的台阶数。

#### 关于输出

输出只有1行。其中包含一个数字，表示小猴子上山有多少种跳法，由于数据很大，需对结果模106。

#### 例子输入

6

#### 例子输出

8


```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int m;
    cin >> m;

    const int MOD = 1000000; // 10^6
    vector<int> dp(m + 1, 0);
    dp[0] = 1;

    for (int i = 1; i <= m; i++) {
        dp[i] = dp[i - 1];
        if (i >= 3) dp[i] = (dp[i] + dp[i - 3]) % MOD;
        if (i >= 5) dp[i] = (dp[i] + dp[i - 5]) % MOD;
        // 注意 dp[i-1] 也要取模
        dp[i] %= MOD;
    }

    cout << dp[m] % MOD << endl;
    return 0;
}
```
