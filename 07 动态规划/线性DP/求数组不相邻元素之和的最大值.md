# #[题目: 求数组不相邻元素之和的最大值](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/17a9d50cada748a5b78edf957748e76b/)

#### 题目描述

给定一个长度为n的数组，从其中任意选择不相邻的m个元素形成子数组，求这个子数组所有元素之和的最大值。

#### 关于输入

输入包括两行。  
第一行为一个正整数n(0<=n<=10000)。  
第二行为n个整数，表示整个数组。

#### 关于输出

输出一个数字，代表数组所有不相邻元素之和的最大值。

#### 例子输入

5
1 2 3 4 5

#### 例子输出

9

```cpp
#include <bits/stdc++.h>

using namespace std;

static int nums[10005];

int main()

{

    /*dp[i] = max(dp[i-2]+nums[i],dp[i-1]);

    1 2 3 4 5

    1 2 4 6 9

    */

    int n;

    cin >> n;

    for (int i = 0; i < n; i++)

    {

        cin >> nums[i];

    }

    switch (n)

    {

    case 0:

        cout << 0;

        ;

        break;

    case 1:

        cout << nums[0];

        break;

    case 2:

        cout << max(nums[0], nums[1]);

        break;

    default:

        int dp[3] = {nums[0], max(nums[0], nums[1]), 0};

        for (int i = 2; i < n; i++)

        {

            dp[2] = max(dp[0] + nums[i], dp[1]);

            dp[0] = dp[1];

            dp[1] = dp[2];

        }

        cout << dp[2];

    }

    return 0;

}
```
