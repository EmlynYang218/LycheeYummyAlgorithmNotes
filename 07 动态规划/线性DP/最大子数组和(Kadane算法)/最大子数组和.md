# [53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)



给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组**是数组中的一个连续部分。

**示例 1：**

**输入：**nums = [-2,1,-3,4,-1,2,1,-5,4]
**输出：**6
**解释：**连续子数组 [4,-1,2,1] 的和最大，为 6 。

**示例 2：**

**输入：**nums = [1]
**输出：**1

**示例 3：**

**输入：**nums = [5,4,-1,7,8]
**输出：**23

**提示：**

- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        /*//第一版：前缀和 4ms
        int n = nums.size();
        int ans = INT_MIN;
        int p[n+1];
        int q[n+1];
        //加哨兵
        p[0]=0;
        for(int i = 0; i < n; i++){
            p[i+1] = p[i]+nums[i];
        }
        //哨兵
        q[0]=0;
        for(int i = 0; i < n; i++ ){
            q[i+1] = min(q[i],p[i+1]);
        }
        for(int i = 1; i <n+1; i++){
            ans = max(ans,p[i]-q[i-1]);
        }
        return ans;
        */


        /*前缀和优化版：避免数组访问和三次遍历带来的复杂性 0ms
        int ans = INT_MIN;
        int prefix = 0;
        int minPrefix = 0;

        for (int num : nums) {
            prefix += num;
            ans = max(ans, prefix - minPrefix);
            minPrefix = min(minPrefix, prefix);
        }
        return ans;
        */


        /*从前缀和到动态规划：注意到不需要存储全部前缀，可以在O(n)内优化  Kadane 算法 0ms
        状态设计:dp[i]表示以第i个数结尾的连续子数组的最大和，那么ans = max(dp[0]...dp[n-1])
        状态转移:dp[i] = max(dp[i-1]+nums[i],nums[i])
        边界处理:dp[0] = nums[0]
        优化成滚动数组
        */
        int pre = 0, ans = nums[0];
        for(auto x : nums){
            pre = max(pre+x,x);
            ans = max(ans,pre);
        }
        return ans;

    }
};
```
