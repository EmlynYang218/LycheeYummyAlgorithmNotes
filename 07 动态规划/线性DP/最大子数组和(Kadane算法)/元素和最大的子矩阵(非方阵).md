# [最大子矩阵](https://leetcode.cn/problems/max-submatrix-lcci/description/)

给定一个正整数、负整数和 0 组成的 N × M 矩阵，编写代码找出元素总和最大的子矩阵。

返回一个数组 `[r1, c1, r2, c2]`，其中 `r1`, `c1` 分别代表子矩阵左上角的行号和列号，`r2`, `c2` 分别代表右下角的行号和列号。若有多个满足条件的子矩阵，返回任意一个均可。

**注意：**本题相对书上原题稍作改动

**示例：**

**输入：**
`[    [-1,0],    [0,-1] ]`
**输出：**[0,1,0,1]
**解释：**输入中标粗的元素即为输出所表示的矩阵

**说明：**

- `1 <= matrix.length, matrix[0].length <= 200`

```cpp
class Solution {
public:
    vector<int> getMaxMatrix(vector<vector<int>>& matrix) {
        int rows = matrix.size();
        int cols = matrix[0].size();
        int maxSum = INT_MIN;
        vector<int> result(4);

        // 固定左边界
        for (int left = 0; left < cols; left++) {
            // rowAccum[i] 表示从 left 到当前 right 的第 i 行的和
            vector<int> rowAccum(rows, 0);

            // 扩展右边界
            for (int right = left; right < cols; right++) {
                // 更新累加器：将当前列的每一行加到 rowAccum 中
                for (int i = 0; i < rows; i++) {
                    rowAccum[i] += matrix[i][right];
                }

                // 在 rowAccum 上运行一维最大子数组逻辑（带坐标追踪）
                int prefix = 0;
                int minPrefix = 0;
                int top = 0;

                for (int bottom = 0; bottom < rows; bottom++) {
                    prefix += rowAccum[bottom];

                    // 如果当前和更大，更新全局答案
                    if (prefix - minPrefix > maxSum) {
                        maxSum = prefix - minPrefix;
                        result = {top, left, bottom, right};
                    }

                    // 更新最小前缀和
                    if (prefix < minPrefix) {
                        minPrefix = prefix;
                        top = bottom + 1;
                    }
                }
            }
        }

        return result;
    }
};
```
