# [题目: 例题(15.7) 石子归并](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/be84f369c7a344d79386690bdaaad780/)

#### 题目描述

现摆一排 N 堆石子（N ≤ 100），要将石子有次序地合并成一堆。规定每次只能选取相邻的两堆合并成新的一堆，并将新的一堆的石子数，记为该次合并的得分。编一程序，由文件读入堆数 N 及每堆的石子数（ ≤ 20）。选择一种合并石子的方案，使所做 N－1 次合并，得分的总和最小。

#### 关于输入

第一行为石子堆数 N；第二行为每堆石子数，数字之间用一个空格分隔。

#### 关于输出

最小的得分总和。

#### 例子输入

21
17 2 9 20 9 5 2 15 14 20 19 19 1 9 8 8 9 14 9 4 8

#### 例子输出

936

#### 提示信息

求解不当，可能超时。

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_N = 104;
static int stones[MAX_N];
static int pre[MAX_N]; // 前缀和数组
static int dp[MAX_N][MAX_N];

int main()
{
    cin.tie(nullptr);
    cout.tie(nullptr);
    ios::sync_with_stdio(false);
    /*
    设石子的编号为0 1, ... n-1
    区间dp,设dp[i][j]表示区间[i,j]合并所得的最小总和
    考虑[i][j]中的最后一次合并，它合并了[i,k]与[k+1,j]  0<=i<k<j<=n-1

    状态转移：dp[i][j] = min(dp[i][k]+dp[k+1][j]) + sum[i,j]
            其中枚举所有k，0<=i<=k<j<=n-1，合并时两堆石子相加，sum[i,k]+sum[k+1][j] = sum[i,j]

    边界条件：dp[i][i] = 0; i = 0,1,...n-1 因为一堆石子不用合并

    实现细节：

    由于大区间依赖于小区间，必须从最小的区间开始算，才能完成状态转移。
    从2开始枚举区间长度l，对于每个区间长度l，计算dp[i][j]的值，由于[i,j]闭区间，其中j=i+l-1
    计算dp[i][j]的值时需要枚举k，从而三重循环，复杂度O(n^3)

    这里的sum[i][j]可以用前缀和简化计算
    */

    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> stones[i];
    }
    // 前缀和数组 pre[0] = 0, pre[m] = stones[0]+...+stones[m-1];
    // sum[i,j] = pre[j+1]-[i]
    pre[0] = 0;
    for (int i = 1; i <= n; i++)
    {
        pre[i] = stones[i - 1] + pre[i - 1];
    }

    // 求最小值，全都初始化为最大
    // 边界
    const int INF = 0x3f3f3f3f;
    for (int i = 0; i < n; i++){
        for (int j = 0; j < n; j++){
            dp[i][j] = (i == j) ? 0 : INF;
        }
    }

    // 递推
    for (int l = 2; l <= n; l++)
    {
        // i+l<=n等价于i+l-1<=n-1
        // j是可以到n-1的
        for (int i = 0; i + l <= n; i++)
        {
            int j = i + l - 1;
            // 重要：i<=k<j 这是由于k>=i,k+1<=j
            for (int k = i; k < j; k++)
            {
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k + 1][j] + pre[j + 1] - pre[i]);
            }
        }
    }

    cout << dp[0][n - 1];

    return 0;
}
```

## Insight1  区间DP的妙处：

对子问题的拆解比较巧妙，但是按照动态规划的一般思想，这是自然的。

- **最优子结构**：大区间最优 ⟸ 子区间最优（`dp[i][k]`、`dp[k+1][j]` 都是各自最优）。

- **子问题独立（无后效性）**：选"最后一次合并"作为切分点，切完后左右两段互不影响。

"巧妙"的部分其实是**选对了阶段和切分点**，让子问题恰好独立。这不是区间 DP 独有，是所有 DP 的共同要求，只是区间 DP 里"切分点 = 最后一步"这个视角转换比较隐蔽。



**划分阶段：**小区间合并成大区间。

**切分点的合法性由"子问题非空"决定**



决策集：**分割点 `k` 的所有取值** `k ∈ [i, j-1]`。

状态设计与状态转移：见上

技术实现：根据划分阶段，需要从小到大枚举长度。



### Insight2 区间DP vs 贪心

**贪心**：每一步**局部**选当前最优，**不回溯、不考虑子问题之间组合**，选完就定，靠"贪心选择性质"保证全局最优。

**区间 DP**：`min` 是在**枚举所有分割点后，比较完整子问题的最优值**，取其中最小的**全局组合**。它必须**先知道所有子区间的最优解**才能决策。



## Insight3   debug得到的经验

| #   | 问题                  | 根因                         | 教训                              |
| --- | ------------------- | -------------------------- | ------------------------------- |
| 1   | `k = i+1` 起点错       | 漏掉"左半只有一堆"的切法              | 分割点范围 `i ≤ k < j`，由"两半都非空"推出    |
| 2   | `i + l < n` 边界错     | 漏掉最右区间，`l=n` 时整个数组都没算      | `j = i+l-1 ≤ n-1` → `i + l ≤ n` |
| 3   | `memset(INT_MAX/2)` | 按字节填充，低字节 `0xFF` → 全变 `-1` | `memset` 只适合填 0；填其他值用手写循环       |
| 4   | `INT_MAX` 当 INF     | `INF + INF` 溢出成负数          | 用 `0x3f3f3f3f`，两个相加不溢出          |

3 4用"手写循环 + `0x3f3f3f3f`"，稳定不出错。

## 区间 DP 的通用模板（背下来）

```c
const int INF = 0x3f3f3f3f;

// 1. 初始化：单元素区间 + 大值
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        dp[i][j] = (i == j) ? 0 : INF;   // 求最大则用 -INF

// 2. 按长度从小到大
for (int len = 2; len <= n; len++)
    for (int i = 0; i + len <= n; i++) {   // i 上界 = n - len
        int j = i + len - 1;
        // 3. 枚举分割点 k ∈ [i, j-1]
        for (int k = i; k < j; k++)
            dp[i][j] = min(dp[i][j],
                           dp[i][k] + dp[k+1][j] + cost(i, j, k));
    }

// 4. 答案
cout << dp[0][n-1];
```
