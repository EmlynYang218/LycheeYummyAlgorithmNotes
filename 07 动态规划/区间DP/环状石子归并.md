# [[NOI1995] 石子合并 - 洛谷](https://www.luogu.com.cn/problem/P1880)

## 题目描述

在一个圆形操场的四周摆放 $N$ 堆石子，现要将石子有次序地合并成一堆，规定每次只能选相邻的 $2$ 堆合并成新的一堆，并将新的一堆的石子数，记为该次合并的得分。

试设计出一个算法，计算出将 $N$ 堆石子合并成 $1$ 堆的最小得分和最大得分。

## 输入格式

数据的第 $1$ 行是正整数 $N$，表示有 $N$ 堆石子。

第 $2$ 行有 $N$ 个整数，第 $i$ 个整数 $a_i$ 表示第 $i$ 堆石子的个数。

## 输出格式

输出共 $2$ 行，第 $1$ 行为最小得分，第 $2$ 行为最大得分。

## 输入输出样例 #1

### 输入 #1

```
4
4 5 9 4
```

### 输出 #1

```
43
54
```

## 说明/提示

$1\leq N\leq 100$，$0\leq a_i\leq 20$。

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_N = 104;
static constexpr int INF = 0x3f3f3f3f;
static int stones[MAX_N*2];
static int pre[MAX_N*2]; // 前缀和数组
static int dp[MAX_N*2][MAX_N*2];

int main()
{
    cin.tie(nullptr);
    cout.tie(nullptr);
    ios::sync_with_stdio(false);
    /*
    设石子的编号为0 1, ... n-1
    区间dp,设dp[i][j]表示区间[i,j]合并所得的最小(最大)总和
    考虑[i][j]中的最后一次合并，它合并了[i,k]与[k+1,j]  0<=i<k<j<=n-1

    求最小：初始化为inf
    状态转移：dp[i][j] = min(dp[i][k]+dp[k+1][j]) + sum[i,j]
            其中枚举所有k，0<=i<=k<j<=n-1，合并时两堆石子相加，sum[i,k]+sum[k+1][j] = sum[i,j]

    求最大：初始化为-1
    状态转移：dp[i][j] = max(dp[i][k]+dp[k+1][j]) + sum[i,j]
            其中枚举所有k，0<=i<=k<j<=n-1，合并时两堆石子相加，sum[i,k]+sum[k+1][j] = sum[i,j]

    边界条件：dp[i][i] = 0; i = 0,1,...n-1 因为一堆石子不用合并

    实现细节：

    1)由于大区间依赖于小区间，必须从最小的区间开始算，才能完成状态转移。
    从2开始枚举区间长度l，对于每个区间长度l，计算dp[i][j]的值，由于[i,j]闭区间，其中j=i+l-1
    计算dp[i][j]的值时需要枚举k，从而三重循环，复杂度O(n^3)

    2)这里的sum[i][j]可以用前缀和简化计算

    3)环状转线性的套路：复制两份，枚举所有长度为n的区间，取最大/最小值
    */

    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> stones[i];
    }
    for(int i = n; i< 2*n; i++){
        stones[i] = stones[i-n];
    }

    // 前缀和数组 pre[0] = 0, pre[m] = stones[0]+...+stones[m-1];
    // sum[i,j] = pre[j+1]-[i]
    pre[0] = 0;
    for (int i = 1; i <= 2*n; i++)
    {
        pre[i] = stones[i - 1] + pre[i - 1];
    }

    // 求最小值，全都初始化为最大
    // 边界
    for (int i = 0; i < 2*n; i++){
        for (int j = 0; j < 2*n; j++){
            dp[i][j] = (i == j) ? 0 : INF;
        }
    }

    // 递推
    for (int l = 2; l <= 2*n; l++)
    {
        // i+l<=n等价于i+l-1<=n-1
        // j是可以到n-1的
        for (int i = 0; i + l <= 2*n; i++)
        {
            int j = i + l - 1;
            // 重要：i<=k<j 这是由于k>=i,k+1<=j
            for (int k = i; k < j; k++)
            {
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k + 1][j] + pre[j + 1] - pre[i]);
            }
        }
    }

    int ans = INF;
    //枚举长度为n的区间起点
    for(int i = 0; i <= n;i++){
        ans = min(ans,dp[i][i+n-1]);
    }
    cout<< ans <<'\n';

    // 求最大值，全都初始化为-1
    // 边界
    for (int i = 0; i < 2*n; i++){
        for (int j = 0; j < 2*n; j++){
            dp[i][j] = (i == j) ? 0 : -1;
        }
    }
        // 递推
    for (int l = 2; l <= 2*n; l++)
    {
        // i+l<=n等价于i+l-1<=n-1
        // j是可以到n-1的
        for (int i = 0; i + l <= 2*n; i++)
        {
            int j = i + l - 1;
            // 重要：i<=k<j 这是由于k>=i,k+1<=j
            for (int k = i; k < j; k++)
            {
                dp[i][j] = max(dp[i][j], dp[i][k] + dp[k + 1][j] + pre[j + 1] - pre[i]);
            }
        }
    }
    ans = -1;
    //枚举长度为n的区间起点
    for(int i = 0; i <= n;i++){
        ans = max(ans,dp[i][i+n-1]);
    }
    cout<< ans;
    return 0;
}
