# 区间 DP 笔记

## 一、识别信号

遇到以下特征，基本就是区间 DP：

1. 操作对象是**一段连续区间**（数组、序列、一排村庄）。
2. 每一步操作**切/合并/消除**，使区间**变短或分段**。
3. **大区间答案 = 两个更小区间的组合**（"最后一步"一分为二）。
4. 问的是**整个区间 `[1,n]` 的最优值**。

典型题：石子归并、戳气球、插入乘号、山区建小学、括号匹配、最长回文子序列、矩阵链乘。

---

## 二、核心思想

区间 DP 的本质是：**用"最后一步"把区间切成两个独立子问题，再由子区间推出大区间。**

### 1. 状态：区间上的最优值

`dp[l][r]` = 区间 `[l,r]` 上的最优值（最小代价 / 最大收益 / 最少次数……）。

**可加一维**：`dp[i][j]`，`j` 是个数/段数（如 `j` 个乘号、`k` 所小学），本质是**前缀区间**。

### 2. 为什么是"最后一步"

**不想第一步，想最后一步。**

- **从第一步想**：操作会改变后续的相邻关系，子问题纠缠在一起，无法拆。
- **从最后一步倒着想**：最后一步做完后，两边彻底分开，**子问题独立**，可以组合。

**"最后一步"是消除耦合的关键**——它把"动态变化的相邻关系"固定成"两个互不影响的子区间"。

### 3. 切分点范围由"子问题非空"决定

最后一步把区间切成两半，切分点 `k` 的合法范围来自**两半都必须非空**：

```
k ∈ [l, r-1]
  左半 [l,k] 非空 → k >= l
  右半 [k+1,r] 非空 → k+1 <= r
```

### 4. 按规模从小到大递推

**大区间依赖更小区间**，所以必须**小区间先算**。这是"依赖决定顺序"，不是习惯。

```c
// 纯区间 DP
for (int len = 2; len <= n; len++)          // 规模：长度
    for (int l = 1; l + len - 1 <= n; l++)  // 左端点
    {
        int r = l + len - 1;                 // 右端点
        dp[l][r] = INF;                      // 求最小先设 INF
        for (int k = l; k < r; k++)          // 枚举切分点
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + cost);
    }

// 带"个数"维（分段型）
for (int j = 1; j <= K; j++)                 // 规模：段数
    for (int i = j; i <= n; i++)             // 前 i 个
    {
        dp[i][j] = INF;
        for (int t = ...; t <= i - 1; t++)   // 枚举最后一段起点
            dp[i][j] = min(dp[i][j], dp[t][j-1] + value(t, i));
    }
```

## 三、两种右半形态（关键区分）

| 形态         | 转移                                               | 右半              | 例子         |
| ---------- | ------------------------------------------------ | --------------- | ---------- |
| **A. 纯区间** | `dp[l][r] = opt_k(dp[l][k] + dp[k+1][r] + cost)` | 仍是子区间           | 石子归并、戳气球   |
| **B. 分段型** | `dp[i][j] = opt_t(dp[t][j-1] + value(t,i))`      | 一个整体（一个数/一段建1所） | 插入乘号、山区建小学 |

**判断法**：最后一段是否还需内部切分？需要 → A；不需要（整体处理）→ B。

## 四、各题对照速查

| 题目    | 状态                    | 切分点         | 右半                  | cost                   |
| ----- | --------------------- | ----------- | ------------------- | ---------------------- |
| 石子归并  | `dp[l][r]` 合并成1堆      | 缝隙 `k`      | 子区间 `[k+1,r]`       | `sum(l,r)`             |
| 戳气球   | `dp[l][r]` 戳破 `(l,r)` | 最后戳 `k`     | 子区间                 | `arr[l]*arr[k]*arr[r]` |
| 插入乘号  | `dp[i][j]` 前 i 位 j 乘号 | 最后乘号 `t`    | 一个数 `num(t,i-1)`    | 乘积                     |
| 山区建小学 | `dp[i][k]` 前 i 村 k 所  | 最后段起点 `j+1` | 一段1所 `cost[j+1][i]` | 距离和                    |

**骨架一样，变的是"右半是子区间还是整体"和"cost 怎么算"。**

## 五、常见变体与坑

1. **环形区间**：数组复制一倍成 `2n`，答案取所有长度 `n` 的区间最优值。
2. **求最大 vs 最小**：求最小先设 `INF`，求最大先设 `-INF`，别默认 0。
3. **边界 `dp[i][i]`**：单元素区间单独设好（如 0）。
4. **枚举顺序**：必须按规模（长度/个数），不能随意双循环。
5. **切分点漏边界**：`k` 从 `l` 开始，不是 `l+1`（`k=l` 合法，左半单元素）。
6. **下标语义统一**：位数 / 下标别混，注释写清 1-base 还是 0-base。
7. **优化**：石子归并等满足四边形不等式，可用平行四边形优化 `O(n³)→O(n²)`，入门不需要。

---

## 六、一句话总结

> **区间 DP = 区间上定义 `dp[l][r]`（可加"个数"维）+ 用"最后一步"把区间切成两个独立子问题 + 按规模从小到大由子区间推出大区间。** 右半是**子区间(A)** 还是**整体(B)** 决定转移形态；切分点范围由"子问题非空"给出；求最小先设 `INF`。

---

## 七、与"决策型 DP"的关系

- **区间 DP**：状态是区间，切分点是区间内部点，规模是区间长度。
- **决策型 DP**：状态任意（一维长度、二维蛋/层），决策是枚举动作（扔哪层、取左/右），不一定有"区间"。

**交集**：插入乘号、山区建小学既是决策型（枚举最后一段）又是区间 DP（前缀区间 + 分段）。

**核心相通**：**枚举最后一步 → 子问题 + 整体 → 按规模递推**。
