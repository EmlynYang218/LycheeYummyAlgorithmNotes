[312. 戳气球](https://leetcode.cn/problems/burst-balloons/)

相关标签

![premium lock icon](https://static.leetcode.cn/cn-frontendx-assets/production/_next/static/media/lock.30spdgxy-h-4s.svg)相关企业

有 `n` 个气球，编号为`0` 到 `n - 1`，每个气球上都标有一个数字，这些数字存在数组 `nums` 中。

现在要求你戳破所有的气球。戳破第 `i` 个气球，你可以获得 `nums[i - 1] * nums[i] * nums[i + 1]` 枚硬币。 这里的 `i - 1` 和 `i + 1` 代表和 `i` 相邻的两个气球的序号。如果 `i - 1`或 `i + 1` 超出了数组的边界，那么就当它是一个数字为 `1` 的气球。

求所能获得硬币的最大数量。

**示例 1：**

**输入：**nums = [3,1,5,8]
**输出：**167
**解释：**
nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []
coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 167

**示例 2：**

**输入：**nums = [1,5]
**输出：**10

**提示：**

- `n == nums.length`
- `1 <= n <= 300`
- `0 <= nums[i] <= 100`

```cpp
static constexpr int MAX_N = 304;
static int dp[MAX_N][MAX_N];
static int b[MAX_N];
class Solution {
public:
    int maxCoins(vector<int>& nums) {
        /*
            区间dp
            状态设计：
            设dp[i][j]表示开区间(i,j)中的气球所能获得硬币的最大数量
            这里使用开区间，是因为“如果 i - 1或 i + 1 超出了数组的边界，那么就当它是一个数字为 1 的气球”，
            从而我们增加哨兵节点b[0] = b[n+1] = 1 且 b[1] = nums[0]...b[n]=nums[n-1]
            答案：c
            状态转移：
            枚举“分界点”——(i,j)中所剩的最后一个气球k，戳破它后得到的价值是b[i]*b[j]*b[k] + dp[i][k]+dp[k][j]
            dp[i][j] = max(b[i]*b[j]*b[k] + dp[i][k]+dp[k][j]) i<k<j
            由于大区间依赖于更小的区间，最外层循环枚举区间长度
            边界处理：
            所有长度为2或更小的开区间值为0
            将dp初始化为0即可解决这个问题


        */

        int n = nums.size();
        //初始化气球数组
        b[0] = b[n+1] = 1;
        for(int i = 1; i <= n; i++){
            b[i] = nums[i-1];
        }
        //初始化dp数组
        memset(dp,0,sizeof(dp));
        for(int l = 3; l <= n+2; l++){
            for(int i = 0; i+l-1<n+2; i++){
                int j = i+l-1;
                for(int k = i+1; k < j; k++){
                    dp[i][j] = max(dp[i][j],b[i]*b[j]*b[k] + dp[i][k]+dp[k][j]);
                }
            }
        }

        return dp[0][n+1];
    }
};
```
