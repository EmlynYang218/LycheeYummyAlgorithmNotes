# [题目: 矩阵取数游戏](https://programming.pku.edu.cn/probset/ef7f07829a4440508b840298e125d1de/59cbc920bb77424cb193f80b2be01462/)

#### 题目描述

帅帅经常跟同学玩一个矩阵取数游戏：对于一个给定的n行*m列的矩阵，矩阵中的每个元素aij均为非负整数。游戏规则如下：  

1. 每次取数时须从每行各取走一个元素，共n个。m次后取完矩阵所有的元素；  
2. 每次取走的各个元素只能是该元素所在行的行首或行尾；  
3. 每次取数都有一个得分值，为每行取数的得分之和；每行取数的得分 = 被取走的元素值*i，其中i表示第i次取数（从1开始编号）；  
4. 游戏结束总得分为m次取数得分之和。  
   帅帅想请你帮忙写一个程序，对于任意矩阵，可以求出取数后的最大得分。

#### 关于输入

包括n+1行；  
第一行为两个用空格隔开的整数n和m。  
第2~n+1行为n*m矩阵，其中每行有m个用单个空格隔开

l<=n，m<=80，1<=aij<=1000

#### 关于输出

仅包含1行，为一个整数，即输入矩阵取数后的最大的分。

#### 例子输入

2 3
1 2 3
3 4 2

#### 例子输出

34

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_N = 84;
static constexpr int MAX_M = 84;
static constexpr int INF = 0x3f3f3f3f;
static int matrix[MAX_N][MAX_M];
static int dp[MAX_N][MAX_M];

int max_value(int *nums, int m)
{
    int ans = INT_MIN;

    for (int l = 0; l < m; l++)
    {
        dp[l][l] = m * nums[l];
    }

    // 按区间长度从 2 到 m
    for (int len = 2; len <= m; len++)
    {
        int k = m - len + 1; // 等价于 m + l - r
        for (int l = 0; l + len - 1 < m; l++)
        {
            int r = l + len - 1;
            dp[l][r] = max(dp[l + 1][r] + k * nums[l],
                           dp[l][r - 1] + k * nums[r]);
        }
    }

    return dp[0][m-1];
}

int main()
{
    cin.tie(nullptr);
    cout.tie(nullptr);
    ios::sync_with_stdio(false);
    /*
    矩阵的每一行互相独立，对每行单独区间dp，取每行最大得分之和
    状态设计：设dp[l][r]表示区间[l,r]取完的最大得分，闭区间长度r-l+1
    则本次取数计算dp[l][r]时是第k= m-(r-1+1)+1 = m-r+l 次 (注意取数次数是1-base）
                        取左侧，依赖于右侧子区间       取右侧，依赖于左侧子区间
    状态转移：dp[l][r] = max(dp[l+1][r]+k*nums[l],dp[l][r-1]+k*nums[r]), k = m+l-r, 0<=l<=r<m
    边界处理：dp[l][l] = m*nums[i] 0<=l<=m-1 只剩一个的时候它是第m次取
    技术实现：由于递推依赖于更小的子区间，还是需要先按长度枚举
    */

    int n, m;
    cin >> n >> m;

    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            cin >> matrix[i][j];
        }
    }
    int ans = 0;
    for (int i = 0; i < n; i++)
    {
        ans += max_value(matrix[i], m);
    }
    cout << ans;
    return 0;
}


```



### Insight1：

每行的独立性是重要的观察，这允许我们对每一行区间DP后，对所有最大值加和。



### Insight2:

区间DP最外层一般都是枚举区间长度，这是由于状态转移中，更长的区间必然依赖于更小的区间，先计算更小的区间才能满足这种关系。
