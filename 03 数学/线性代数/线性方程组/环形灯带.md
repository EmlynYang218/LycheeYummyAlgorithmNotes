#### 题目描述

夜深了，xx 准备熄灯。

n 盏灯围成一圈，按顺时针编号为 1 至 n。每次可选择一盏灯，将它和相邻的两盏灯同时翻转：亮变灭，灭变亮。求使全部灯熄灭的最少操作次数，无法做到则输出 -1。

数据范围：3≤n≤100,000；输入的 01 字符串长度为 n。

#### 关于输入

第一行包含一个整数 n。

第二行包含一个长度为 n 的 01 字符串，1 表示亮，0 表示灭。第 n 盏灯与第 1 盏灯相邻。

#### 关于输出

输出一行，包含一个整数，表示最少操作次数；无法全部熄灭则输出 -1。

#### 例子输入

样例 1 输入：
4
1100
样例 2 输入：
3
100
样例 3 输入：
6
110001

#### 例子输出

样例 1 输出：
2
样例 2 输出：
-1
样例 3 输出：
1

#### 提示信息

数据范围：3≤n≤100,000；输入的 01 字符串长度为 n。

样例 1 说明：例如分别操作第 3 盏和第 4 盏灯，可以全部熄灭；一次操作不能完成。

样例 2 说明：三盏灯时，每次操作都翻转全部三盏，因此无法从 100 到达 000。

样例 3 说明：操作第 1 盏灯会同时翻转第 6、1、2 盏灯，恰好使全部灯熄灭。依次操作第 2、4、5 盏灯也能完成，但要用 3 次，因此答案仍为 1。

#include <bits/stdc++.h>
using namespace std;

/*

* 题解：环形灯带（异或版）

* 

* 关键观察：

* 每盏灯最优解中最多操作一次 → x_i ∈ {0,1}。

* 第 i 盏灯被翻转次数 = x_{i-1} + x_i + x_{i+1}（循环）。

* 要熄灭，翻转次数奇偶性必须等于 a_i：

*  x_{i-1} + x_i + x_{i+1} ≡ a_i  (mod 2)

* 模 2 下加法即异或，所以方程写成：

*  x_{i-1} ^ x_i ^ x_{i+1} = a_i

* 

* 解法：

* 枚举 x_0, x_1 ∈ {0,1}（4 种）。

* 由方程递推：

*  x_{i+1} = a_i ^ x_{i-1} ^ x_i

* 递推 x_2..x_{n-1}，然后验证 i=0 和 i=n-1 两个方程。

* 取所有可行解中 sum(x_i) 的最小值。

* 

* 复杂度 O(n)。
  */

int main() {
    int n;
    string s;
    cin >> n >> s;

    vector<int> a(n);
    for (int i = 0; i < n; i++) a[i] = s[i] - '0';

    int ans = INT_MAX;

    // 枚举前两盏灯的操作情况
    for (int x0 = 0; x0 <= 1; x0++) {
        for (int x1 = 0; x1 <= 1; x1++) {
            vector<int> x(n);
            x[0] = x0;
            x[1] = x1;

            // 递推：x_{i+1} = a_i ^ x_{i-1} ^ x_i
            for (int i = 1; i < n - 1; i++) {
                x[i + 1] = a[i] ^ x[i - 1] ^ x[i];
            }

            // 验证首尾两个方程
            bool ok = true;
            if ((x[n - 1] ^ x[0] ^ x[1]) != a[0]) ok = false;       // i = 0
            if ((x[n - 2] ^ x[n - 1] ^ x[0]) != a[n - 1]) ok = false; // i = n-1

            if (ok) {
                int sum = 0;
                for (int v : x) sum += v;
                ans = min(ans, sum);
            }
        }
    }

    cout << (ans == INT_MAX ? -1 : ans) << endl;
    return 0;

}
