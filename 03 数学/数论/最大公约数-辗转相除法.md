# 最大公约数：辗转相除法

利用 `gcd(a, b) = gcd(b, a % b)`，不断用余数缩小问题，直到余数为 0。

```cpp
long long gcd(long long a, long long b) {
    while (b != 0) {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

时间复杂度为 `O(log min(a,b))`。若输入可能为负数，可先取绝对值；`lcm(a,b)` 可用 `a / gcd(a,b) * b`，并注意乘法溢出。
