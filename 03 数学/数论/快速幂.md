# 快速幂

把指数写成二进制。当前位为 1 时将对应幂乘入答案，每轮将底数平方并右移指数，因此只需 `O(log n)` 次迭代。

```cpp
long long modPow(long long a, long long n, long long mod) {
    long long result = 1 % mod;
    a %= mod;
    while (n > 0) {
        if (n & 1) result = result * a % mod;
        a = a * a % mod;
        n >>= 1;
    }
    return result;
}
```

前提是 `n >= 0`、`mod > 0`。当 `a` 和 `mod` 很大时，乘法本身可能溢出，需要更宽整数类型或安全乘法。
