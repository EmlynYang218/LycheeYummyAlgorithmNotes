# 约瑟夫环

## 问题与递推

`n` 个人围圈，每报到 `k` 出列。令 `J(n,k)` 表示从 0 开始编号时最终幸存者的位置：

```text
J(1,k) = 0
J(n,k) = (J(n-1,k) + k) % n
```

递推的关键是：删除一人后，把下一位重新视作新圈的 0 号，再将幸存者下标映射回旧圈。

## 实现

```cpp
int josephus(int n, int k) {
    int answer = 0;
    for (int i = 2; i <= n; ++i)
        answer = (answer + k) % i;
    return answer + 1; // 转为 1-based 编号
}
```

时间 `O(n)`，额外空间 `O(1)`。若需输出完整出列顺序，应使用模拟或支持动态次序统计的数据结构。
