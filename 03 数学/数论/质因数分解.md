# [题目: 按从大到小输出正整数的所有不同质因子](https://programming.pku.edu.cn/probset/6145fa4759d340339126b3fa75d7da7e/8d89602bcf514e7bb17ab1fe8c249565/)

#### 题目描述

任意给定一个正整数，计算其所有不同质因数，并按大到小输出。其间以逗号间隔。

#### 关于输入

输入一个正整数（可以用int类型表示）

#### 关于输出

按从大到小输出所有质因数，其间用逗号间隔。

#### 例子输入

60

#### 例子输出

5,3,2

```cpp
#include<stdio.h>
//定义法判断是否是质数
int isPrime(int x){

    for(int i = 2; i < x; i ++){
        if(x%i==0){
            return 0;
        }
    }

    return 1;

}
int main() {
    int n = 0;
    scanf("%d",&n);

    //处理正确的逗号分隔
    int first = 1;
    //坑点：排除输入自身是质数的情况
    if(isPrime(n)){
        printf("%d",n);
    }else{
        for(int i = n-1; i >=2 ; i --){

        if(n%i==0&&isPrime(i)){
            if(first){
                printf("%d",i);
                first =0;
            }else{
                printf("\,%d",i);
            }
        }
        }
    }


    return 0;

}
```
