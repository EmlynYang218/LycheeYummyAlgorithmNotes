# [题目: 输出二进制补码](https://programming.pku.edu.cn/probset/5c26f2630c724b359120a8452eb4cbf8/42bd3c642fc64d0ba5e9c18e0fef5e29/)

#### 题目描述

输入若干int型整数，输出每个整数的二进制补码。

#### 关于输入

输入有若干行，除最后一行外，每行包含一个int型整数。最后一行仅包含一个不定的字母，标志着输入结束。我们保证输入的整数不超出int型变量的表示范围

#### 关于输出

对于每个输入的整数，输出一行，即该整数的补码表示。

#### 例子输入

1
7
200
-45
h

#### 例子输出

00000000000000000000000000000001
00000000000000000000000000000111
00000000000000000000000011001000
11111111111111111111111111010011

```cpp
#include <bits/stdc++.h>
using namespace std;

void int_to_binary_str(int x,char f, char t){
    if(x<0){
        int_to_binary_str(-x-1,t,f);
        return;
    }
    string ans(32,f);
    for(int i = 31; i >=0; i--){
        if(x%2==0){
            ans[i]=f;
        }else{
            ans[i]=t;
        }
        x/=2;
        if(x==0){
            break;
        }
    }
    cout<<ans<<'\n';

}

int main() {
    vector<int> cases;
    int n = 0;
    while(cin>>n){

        cases.push_back(n);
    }
    for(auto c:cases){
        int_to_binary_str(c,'0','1');
    }
    return 0;
}
```
