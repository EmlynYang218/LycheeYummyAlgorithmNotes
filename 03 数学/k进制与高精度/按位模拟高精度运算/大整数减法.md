# 大整数减法

#### 题目描述

求2个大的正整数相减的差

#### 关于输入

第1行是测试数据的组数n，每组测试数据占2行，第1行是被减数a，第2行是减数b(a > b)。每组测试数据之间有一个空行，每行数据不超过100位

#### 关于输出

n行，每组测试数据有一行输出是相应的整数差

#### 例子输入

```
2  
9999999999999999999999999999999999999  
9999999999999  
5409656775097850895687056798068970934546546575676768678435435345  
1
```

#### 例子输出

```
9999999999999999999999990000000000000  
540965677509785089568705679806897093454654657567676867843543534
```

```cpp
#include <iostream>
#include <string>
#include <algorithm>

using namespace std;

char int_to_char(int x){
    return (char)(x+'0');
}

string a_minus_b(const string& a, const string& b){
    int as = a.size(), bs = b.size();

    int i = as-1, j = bs -1, borrow = 0;
    string ans;
    while(i>=0||j>=0){
        int x = a[i]-'0'-borrow;
        i--;
        if(j>=0){
            x-=b[j]-'0';
            j--;
        }

        if(x>=0){
            ans += int_to_char(x);
            borrow = 0;
        }else{
            ans += int_to_char(x+10);
            borrow = 1;
        }
    }
    reverse(ans.begin(),ans.end());
    return ans;
}

int main() {
    int n = 0;
    cin >> n;

    while(n--){
        string x , y;
        cin >> x >> y;
        cout<<a_minus_b(x,y)<<'\n';
    }



    return 0;
}
```
