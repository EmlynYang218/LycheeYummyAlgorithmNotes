#### 题目描述

xx 为 DeepSeek Harness 编写缓存命中率的显示功能。给定缓存访问总次数 y 和命中次数 x，命中率为 (100×x/y)%。

除非实际命中率为 100%，否则不应显示成 100%，以免产生误解。实际命中率等于 100% 时，直接输出 100%。

其余情况，首先对原始命中率四舍五入到整数。如果得到 100%，就改为四舍五入到一位小数；如果得到 100.0%，则再多保留一位小数，如此继续，直到显示结果不再是 100.0...0%。输出首次满足要求的结果，末尾紧接 %。每次四舍五入都以原始命中率为准。

数据范围：1≤T≤10，1≤x≤y≤1,000,000。

#### 关于输入

第一行包含一个正整数 T，表示数据组数。

接下来 T 行，每行包含两个正整数 x,y，分别表示该组的缓存命中次数和访问总次数。

#### 关于输出

输出 T 行，每行包含对应组按上述规则表示的百分比，末尾紧接 %。

#### 例子输入

样例 1 输入：
3
997 1000
100 100
999998 999999

#### 例子输出

样例 1 输出：
99.7%
100%
99.9999%

#### 提示信息

数据范围：1≤T≤10，1≤x≤y≤1,000,000。

样例 1 的第一组，四舍五入到整数得到 100%，改为保留一位小数得到 99.7%。

第二组的实际命中率恰为 100%，直接输出。

第三组的实际命中率是循环小数，约为 99.9998999999%。保留到三位小数时仍显示 100.000%，保留四位小数后得到 99.9999%。

设命中率：

$$
r = \frac{100x}{y}
$$

题目要求：从 $k=0$ 开始，找**最小的 $k$**，使得 $r$ 四舍五入到 $k$ 位小数后**不是** $100.0\ldots0\%$，输出这个结果。若 $x=y$，直接输出 `100%`。

### 1. 四舍五入到 $k$ 位小数的整数表达

$$
r \cdot 10^k = \frac{100x \cdot 10^k}{y}
$$

四舍五入到整数：

$$
Q_k = \left\lfloor \frac{100x \cdot 10^k}{y} + \frac{1}{2} \right\rfloor
$$

用整数写：

$$
Q_k = \left\lfloor \frac{2 \cdot 100x \cdot 10^k + y}{2y} \right\rfloor
$$

即：

$$
Q_k = \frac{200x \cdot 10^k + y}{2y} \quad \text{（整数除法，向下取整）}
$$

### 2. 判断“四舍五入后是否为 $100.0\ldots0\%$”

$$
Q_k = 100 \cdot 10^k
$$

时，显示为 $100.0\ldots0\%$（$k$ 个 0）。

由 $Q_k = \lfloor A + 1/2 \rfloor$，其中

$$
A = \frac{100x \cdot 10^k}{y}
$$

有：

$$
Q_k = 100 \cdot 10^k \iff 100 \cdot 10^k - \frac{1}{2} \le A < 100 \cdot 10^k + \frac{1}{2}
$$

左边不等式：

$$
\frac{100x \cdot 10^k}{y} \ge 100 \cdot 10^k - \frac{1}{2}
$$

两边乘以 $2y$（正数）：

$$
200x \cdot 10^k \ge (200 \cdot 10^k - 1) \cdot y
$$

化简：

$$
y \ge 200 \cdot 10^k \cdot (y - x)
$$

**这是判断“四舍五入到 $k$ 位小数仍为 $100.0\ldots0\%$”的充要条件（整数形式）。**

### 3. 为什么 $k$ 有上界

因为 $x < y$，所以 $y - x \ge 1$。当：

$$
200 \cdot 10^k > y
$$

时，右边

$$
200 \cdot 10^k \cdot (y-x) \ge 200 \cdot 10^k > y
$$

不等式不成立。所以 $k$ 最大满足：

$$
200 \cdot 10^k \le y \le 10^6 \implies 10^k \le 5000 \implies k \le 3
$$

实际上考虑 $y - x$ 可能大于 1，上界更小；但保险起见循环到 $k = 10$ 足够。

### 4. 输出格式

找到最小的 $k$ 使条件**不成立**后，计算：

$$
Q_k = \frac{200x \cdot 10^k + y}{2y}
$$

- 整数部分：

$$
\frac{Q_k}{10^k}
$$

- 小数部分：

$$
Q_k \bmod 10^k
$$

补前导零到 $k$ 位，去末尾 0。

注意：如果 $k = 0$，直接输出

$$
Q_0\%
$$

```cpp
#include <bits/stdc++.h>
using namespace std;

// x <= y
string cache_hit_rate(int x, int y)
{
    if (x == y)
    {
        return "100%";
    }

    /*
     * 整数写法核心：
     * 四舍五入到 k 位小数后仍为 100.0...0%  <=>  y >= 200 * 10^k * (y - x)
     * 找最小的 k 使该不等式不成立，然后输出四舍五入到 k 位小数的结果。
     *
     * Q_k = round(100*x*10^k / y) = (200*x*10^k + y) / (2*y)  （整数除法）
     *
     * k 的上界：因为 y <= 1e6 且 x < y，所以 y - x >= 1，
     * 当 200*10^k > y 时不等式必然不成立，因此 k 最大约 4~5，循环到 10 足够。
     */
    long long diff = y - x;
    int k = 0;
    long long pow10 = 1;

    // 找最小的 k，使得 y < 200 * 10^k * (y - x)
    while (y >= 200LL * pow10 * diff)
    {
        pow10 *= 10;
        k++;
        if (k > 10)
            break; // 安全上限
    }

    // 计算 Q_k = round(100*x*10^k / y)
    long long num = 100LL * x * pow10; // 100*x*10^k
    long long den = y;
    long long Q = (2 * num + den) / (2 * den);

    // 格式化：整数部分 + 小数部分（补前导零，去末尾 0）
    long long int_part = Q / pow10;
    long long frac_part = Q % pow10;

    string res = to_string(int_part);
    if (k > 0 && frac_part > 0)
    {
        string fs = to_string(frac_part);
        while ((int)fs.size() < k)
            fs = "0" + fs;
        while (!fs.empty() && fs.back() == '0')
            fs.pop_back();
        if (!fs.empty())
            res += "." + fs;
    }
    return res + "%";
}

int main()
{
    int T = 0, x, y;
    cin >> T;
    while (T--)
    {
        cin >> x >> y;
        cout << cache_hit_rate(x, y) << '\n';
    }
    return 0;
}
```



### 复盘与反思：

这是期中考试九道题目中的第四题，我认为我的模拟相当自然，但失败原因在于以下两点：
1）误认为整数部分为0还需要继续四舍五入，这个问题最严重，是思维定势问题；且为此加入整数部分特判逻辑，问题多多。
2）浮点数精度有限，产生误差，考试时即使改用高精度，也无法弥补1）带来的重大失误
我做对的：四舍五入模拟相对准确。
