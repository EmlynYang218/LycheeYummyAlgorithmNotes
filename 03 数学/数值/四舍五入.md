#### 题目描述

xx 为 DeepSeek Harness 编写缓存命中率的显示功能。给定缓存访问总次数 y 和命中次数 x，命中率为 (100×x/y)%。

除非实际命中率为 100%，否则不应显示成 100%，以免产生误解。实际命中率等于 100% 时，直接输出 100%。

其余情况，首先对原始命中率四舍五入到整数。如果得到 100%，就改为四舍五入到一位小数；如果得到 100.0%，则再多保留一位小数，如此继续，直到显示结果不再是 100.0...0%。输出首次满足要求的结果，末尾紧接 %。每次四舍五入都以原始命中率为准。

数据范围：1≤T≤10，1≤x≤y≤1,000,000。

#### 关于输入

第一行包含一个正整数 T，表示数据组数。

接下来 T 行，每行包含两个正整数 x,y，分别表示该组的缓存命中次数和访问总次数。

#### 关于输出

输出 T 行，每行包含对应组按上述规则表示的百分比，末尾紧接 %。

#### 例子输入

样例 1 输入：
3
997 1000
100 100
999998 999999

#### 例子输出

样例 1 输出：
99.7%
100%
99.9999%

#### 提示信息

数据范围：1≤T≤10，1≤x≤y≤1,000,000。

样例 1 的第一组，四舍五入到整数得到 100%，改为保留一位小数得到 99.7%。

第二组的实际命中率恰为 100%，直接输出。

第三组的实际命中率是循环小数，约为 99.9998999999%。保留到三位小数时仍显示 100.000%，保留四位小数后得到 99.9999%。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    cin >> T;
    while (T--) {
        long long x, y;
        cin >> x >> y;

        if (x == y) {
            cout << "100%\n";
            continue;
        }

        // 找最小的 k，使得四舍五入到 k 位小数后不再是 100.0...0%
        // 条件：200*(y-x)*10^k > y 时，四舍五入结果不再是 100
        long long p = 1;   // 10^k
        int k = 0;
        while (200LL * (y - x) * p <= y) {
            p *= 10;
            k++;
        }

        // 以原始命中率为准，四舍五入到 k 位小数
        long long N = 100LL * x * p;
        long long rounded = (2 * N + y) / (2 * y);

        long long integer_part = rounded / p;
        long long frac_part = rounded % p;

        if (k == 0) {
            cout << integer_part << "%\n";
        } else {
            cout << integer_part << ".";
            string fs = to_string(frac_part);
            fs = string(k - fs.size(), '0') + fs;
            cout << fs << "%\n";
        }
    }
    return 0;
}
```
