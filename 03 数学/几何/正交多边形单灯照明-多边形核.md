# 正交多边形中的单灯照明：多边形核

## 问题模型

给定一个顶点按顺时针排列、边与坐标轴平行的简单多边形，判断是否存在一个点作为灯的位置，使多边形内的每个位置都能被这盏灯直接照到。

若灯放在点 `p`，要照到多边形内任意点 `q`，线段 `pq` 必须始终位于多边形内部。所有满足此条件的 `p` 构成多边形的**核**（kernel）。所以题目等价于判断多边形核是否为空。

## 关键观察：每条边给出一个半平面约束

简单多边形是顺时针给出的，因此沿边前进时，房间内部位于行进方向的右侧。任何能照亮整个房间的灯点都必须位于每条边的内侧半平面中。对正交边，这些约束分别是 `x` 或 `y` 的上下界：

| 有向边 | 内侧约束 |
| --- | --- |
| 水平向右 | 点在边下方：`y <= 边的 y` |
| 水平向左 | 点在边上方：`y >= 边的 y` |
| 垂直向上 | 点在边右方：`x >= 边的 x` |
| 垂直向下 | 点在边左方：`x <= 边的 x` |

把全部边的约束求交，得到一个轴对齐矩形（也可能退化成线段或点），或者空集。若 `xLow <= xHigh` 且 `yLow <= yHigh`，交集非空，存在可行灯点；否则不存在。

## 正确性

**必要性：** 若点能照亮整个房间，它必须位于每条边的内侧半平面，否则房间中会有一部分位于该边界的另一侧，无法从该点直线照到。因此它必须满足代码收集的所有上下界。

**充分性：** 对简单多边形，可见核等于所有边的内侧半平面的交集。交集中任意点到多边形内任意点的线段都留在多边形内，因此该点可以照亮整个房间。故检查交集是否非空即可。

## 实现过程

1. 初始化 `xLow`、`yLow` 为负无穷，`xHigh`、`yHigh` 为正无穷。
2. 遍历每条边 `(i, j)`，其中 `j = (i + 1) % n`。
3. 根据边的方向收紧对应坐标的上下界。
4. 检查两个区间是否都非空，输出 `Yes` 或 `No`。

时间复杂度 `O(n)`，额外空间复杂度 `O(n)`（存储顶点）。如果边读入后即可处理，也可以将额外空间降到 `O(1)`。

## 代码注意

- `LLONG_MIN`、`LLONG_MAX` 用作宽松初始界限，坐标边界更新时转成 `long long`，避免把 `int` 边界直接参与后续更大范围的比较。
- 使用 `<=` 允许交集退化成线段或点。这与“灯可放在边界上”的通常几何建模一致；若题目明确要求灯必须在严格内部，则还需要严格不等式及相应的可行性判断。
- 此方向判断依赖题目给出的顺时针顶点顺序。若顺序改成逆时针，四种方向对应的内侧约束要反过来。
- 这里依赖输入轮廓为简单多边形；自交轮廓不适用该多边形核结论。

## 原始题面

#### 题目描述

你需要放置一盏灯来照亮房间的每个角落，问这是否能办到？\
[image](https://programming.pku.edu.cn/probset/fb79e9e1d0274ae38442414fb338b0e4/eb393820bf534c1694277ceba1114536/1474_1.jpg)

#### 关于输入

输入包含多组数据。\
每组数据第一行是正整数n(4<=n<=100)，表示房间轮廓所形成的多边形的顶点个数。\
接下来n行，每行表示房间的一个顶点。\
顶点按顺时针的顺序给出，房间轮廓多边形的所有边都平行于坐标轴。\
输入以n=0表示结束。

#### 关于输出

对每组数据输出一行。\
如果能有一种放置方法照亮房间的所有地方，输出"Yes"，否则输出"No"

## 原始代码（保留）

以下代码按用户提供内容保留；上方解析与代码注意为补充说明。

```cpp
#include <iostream>
#include <algorithm>
#include <climits>
using namespace std;

int main()
{
    int n;
    while (cin >> n && n != 0)
    {
        int px[105], py[105];
        for (int i = 0; i < n; i++)
            cin >> px[i] >> py[i];

        long long xLow = LLONG_MIN, xHigh = LLONG_MAX;
        long long yLow = LLONG_MIN, yHigh = LLONG_MAX;

        for (int i = 0; i < n; i++)
        {
            int j = (i + 1) % n;
            if (py[i] == py[j]) // 水平边
            {
                if (px[j] > px[i]) // 向右：内部在下方
                    yHigh = min(yHigh, (long long)py[i]);
                else               // 向左：内部在上方
                    yLow = max(yLow, (long long)py[i]);
            }
            else // 垂直边
            {
                if (py[j] > py[i]) // 向上：内部在右方
                    xLow = max(xLow, (long long)px[i]);
                else               // 向下：内部在左方
                    xHigh = min(xHigh, (long long)px[i]);
            }
        }

        if (xLow <= xHigh && yLow <= yHigh)
            cout << "Yes\n";
        else
            cout << "No\n";
    }
    return 0;
}
```
