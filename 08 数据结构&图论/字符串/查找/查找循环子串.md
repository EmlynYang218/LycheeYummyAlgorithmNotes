# [题目: 循环数](https://programming.pku.edu.cn/probset/8786dce2fe14483f9a5063ded7dcbf13/1e4611f6c2b24bf3ae8305bc9c8a557f/)

题目描述
当一个N位的整数X满足下列条件时，称其为循环数：X与任意一个整数1≤Y ≤ N相乘时，都将产生一个X的“循环”。即：分别将这两个整数的第1位数字与最后1位数字连在一起，可以得到一个相同的数字循环；当然两个整数在该数字循环中的起始位置不同。例如，142857是一个循环数
142857 *1 = 142857
142857 *2 = 285714
142857 *3 = 428571
142857 *4 = 571428
142857 *5 = 714285
142857 *6 = 857142

关于输入
写一个程序判断一个整数是否是循环数。输入文件是一个整数序列，每个整数长度为2~60。注意：每个整数前面的零被看作是该整数的一部分，在计算N时要统计。例如“01”是一个2位的整数，而“1”是一个1位的整数。

关于输出
对每个输入整数，输出一行，说明该整数是否是循环数。

例子输入
142857
142856
142858
01
0588235294117647
例子输出
142857 is cyclic
142856 is not cyclic
142858 is not cyclic
01 is not cyclic
0588235294117647 is cyclic

```cpp
#include <bits/stdc++.h>
using namespace std;
//a b 低位到高位存储
string add_string(const string& a, const string& b){
    int as = a.size(), bs = b.size();
    int i = 0,j=0,carry=0;
    string ans = "";
    while(i<as||j<bs||carry>0){
        int x =carry;
        if(i<as){
            x+=(int)(a[i]-'0');
            i++;
        }
        if(j<bs){
            x+=(int)(b[j]-'0');
            j++;
        }
        ans += (char)(x%10+'0');
        carry = x/10;
    }
    return ans;
}
string multiply_string(const string& a, int b){
    string ans = a;
    for(int i = 1; i < b; i++){
        ans = add_string(ans,a);
    }
    return ans;
}
int main(){
    //寻找重复只需要一段写两次判断是否存在其中
    //核心难度在于实现一个高精度乘法，由于第二个数比较小可以直接循环加法
    string n;
    while(cin >> n){
        bool valid = true;
        int t = n.size();
        string ds = n+n;
        string n1 = n;
        reverse(n1.begin(),n1.end());

        for(int i = 2; i <= t; i++){
            string n2 = multiply_string(n1,i);
            reverse(n2.begin(),n2.end());
            if(ds.find(n2)==string::npos){
                valid = false;
            }
        }
        if(valid){
            cout<<n<<" is cyclic\n";
        }else{
            cout<<n<<" is not cyclic\n";
        }
    }
    return 0;

}
```
