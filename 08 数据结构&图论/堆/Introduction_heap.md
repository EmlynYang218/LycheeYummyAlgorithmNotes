## 堆是什么

算法里的**二叉堆**是一棵完全二叉树，并且满足堆序性质：

- **大顶堆**：每个父节点的值都大于或等于子节点。
- **小顶堆**：每个父节点的值都小于或等于子节点。

例如这是一个大顶堆：

```
        9
      /   \
     7     8
    / \   /
   1   4 3
```

因此根节点 `9` 是全堆最大值。但堆**不是排序好的树**：`7` 和 `8` 谁大，除了它们各自都不超过根节点，没有其他顺序要求。堆很适合快速找到最大值或最小值，却不适合快速查找任意一个值。

二叉堆通常用数组存储。若节点下标是 `i`，采用从 `0` 开始的下标：

- 左孩子：`2*i + 1`
- 右孩子：`2*i + 2`
- 父节点：`(i - 1) / 2`

上面的堆可以存成 `[9, 7, 8, 1, 4, 3]`。

## 堆的增删改查

| 操作     | 作用            | 复杂度           |
| ------ | ------------- | ------------- |
| 查询堆顶   | 查看最大值或最小值，不删除 | \(O(1)\)      |
| 插入     | 添加一个新元素       | \(O(\log n)\) |
| 删除堆顶   | 移除最大值或最小值     | \(O(\log n)\) |
| 修改堆顶   | 修改后重新调整堆      | \(O(\log n)\) |
| 查找任意元素 | 找某个不确定位置的值    | \(O(n)\)      |
| 建堆     | 从已有数组批量建堆     | \(O(n)\)      |

插入时，为了保持完全二叉树的形状，新元素先放到数组末尾，再不断和父节点比较。对大顶堆来说，如果它比父节点大，就交换并继续向上，这叫**上浮**。最多经过树高，所以是 \(O(\log n)\)。

删除堆顶时，先用数组末尾元素补到根，再删除末尾，随后和较大的孩子比较；若父节点比孩子小，就交换并继续向下，这叫**下沉**，复杂度同样是 \(O(\log n)\)。

修改一个元素的值后，需要恢复堆序。大顶堆中，若值变大，可能需要上浮；若值变小，可能需要下沉。修改位置如果是任意元素，还得先知道它在堆里的位置。

这也是 C++ `priority_queue` 的一个限制：它提供查看和删除堆顶、插入元素等操作，但**不能直接删除或修改堆中任意元素**。而且堆不全排序，找任意元素通常要扫描，复杂度是 \(O(n)\)。若需要高效地更新任意元素，可以自己实现带有“元素编号到堆下标”映射的堆；也可以在一些场景中使用延迟删除。
