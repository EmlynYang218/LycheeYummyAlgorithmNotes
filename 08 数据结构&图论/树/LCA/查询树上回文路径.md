# 查询树上回文路径：从奇偶性到动态树路径查询

## 文件与约定

- [完整 C++17 实现](./查询树上回文路径-3841.cpp)，使用 LeetCode 的 `Solution::palindromePath` 接口。
- 本文是本次讲解的整理说明，不改写已有原始笔记。
- 普通无向树，任选节点 `0` 为根，不要求是二叉树。
- 节点编号与 DFS 位置从 `0` 开始；树状数组内部下标从 `1` 开始。
- `tin[u]` 为进入位置，`tout[u]` 为访问完整棵子树后的下一个位置；子树区间为 `[tin[u], tout[u])`。

## 一、各模块解决什么问题

| 模块 | 解决的问题 |
| --- | --- |
| 字符奇偶掩码 | 重排成回文只要求出现奇数次的字符种类不超过一种 |
| 根路径异或 + LCA | 两条根路径抵消公共部分，补回最近公共祖先的字符 |
| DFS 序 | 将一个节点的全部后代排列成连续区间 |
| 异或差分 | 把连续区间异或转化为两个端点的异或修改 |
| 树状数组 | 用 `O(log n)` 支持差分单点修改与前缀异或查询 |

DFS 序只保证子树连续，不保证任意两点的路径连续。找到子树区间只需读取两个端点，是 `O(1)`；逐个修改区间并不是 `O(1)`。快速更新来自后面的差分与树状数组。

## 二、字符掩码与路径公式

```cpp
mask(c) = 1u << (c - 'a');
```

每一位表示一种字符出现次数的奇偶性。相同字符异或两次抵消，所以把路径上各字符掩码异或起来，即可得到奇偶信息。

设 `R[u]` 是当前根到 `u` 的字符掩码，含两端点。`w = lca(u, v)`：

```cpp
pathMask = R[u] ^ R[v] ^ mask(s[w]);
```

两个根路径的公共部分被抵消，但 LCA 也被抵消，因此补回其当前字符一次。`u == v` 时两份 `R[u]` 相消，仍正确留下节点自身的字符。

```cpp
bool valid = (pathMask & (pathMask - 1u)) == 0;
```

这个表达式在掩码为零、或只有一个 `1` 时成立。使用无符号掩码，零减一的运算也有明确定义。

## 三、修改为何作用于子树

将节点 `x` 从旧字符改为 `c`，恰好影响 `x` 及其后代的根路径掩码：

```cpp
delta = mask(s[x]) ^ mask(c);
```

旧字符异或一次用于抵消，新字符异或一次用于加入。只异或新字符会留下旧字符的影响。新旧字符相同时 `delta == 0`，自然无需改变任何值。

因此对 DFS 序数组 `A[tin[u]] = R[u]`，修改区间 `[tin[x], tout[x])` 的所有值：

```cpp
A[p] ^= delta;
```

树的结构不变，所以字符修改不需要重建 DFS 序、深度或倍增祖先表。

## 四、差分与树状数组的衔接

实现采用“完整初始差分”方案：树状数组直接保存 DFS 序根路径掩码的差分，而不只是后续的修改量。

```cpp
d[0] = A[0];
d[p] = A[p] ^ A[p - 1]; // p > 0
```

恢复一个值：`A[p] = d[0] ^ ... ^ d[p]`。

由于 BIT 内部下标加一，初始构建执行 `fw.add(p + 1, d[p])`。对区间 `[l, r)` 异或 `delta`：

```cpp
fw.add(l + 1, delta);
if (r < n) fw.add(r + 1, delta);
```

若 `r == n`，终止影响的端点在有效范围之外，不必保存。

当前节点 `u` 的根路径掩码直接为：

```cpp
fw.prefix(tin[u] + 1);
```

不要再额外异或初始 `initialMask[u]`：初始信息已经包含在 BIT 内，否则会重复抵消。

### BIT 中每个位置的含义

`bit[i]` 汇总内部下标区间 `[i-lowbit(i)+1, i]`，`lowbit(i) = i & -i`。

- 查询前缀：取当前区间后执行 `i -= lowbit(i)`。
- 单点异或：更新所有包含该位置的维护区间，执行 `i += lowbit(i)`。
- 更新下标必须为正数，`lowbit(0) == 0` 会使从零开始的更新无法前进。

## 五、LCA 倍增

`up[j][u]` 表示从节点 `u` 向上走 `2^j` 步到达的祖先。

```cpp
up[j][u] = up[j - 1][up[j - 1][u]];
```

根的父节点设为自身。查询先按深度差的二进制位提升较深节点；若相同则返回。否则从大步到小步，仅在两边跳到的祖先不同的情况下跳跃，最后返回两者的共同父节点。

## 六、为什么实现使用迭代 DFS

题目允许五万节点的长链，递归 DFS 会随链长占用调用栈。实现用显式数组栈保存事件：

```text
(u, false)：进入 u，记录 tin、根路径掩码与祖先信息。
(u, true)：退出 u，记录 tout。
```

栈是后进先出。进入节点时先压退出事件，再压孩子的进入事件，保证整棵子树处理完毕后才退出该节点。树没有环，跳过父节点即可，不需要额外的 visited 数组。

## 七、按顺序处理操作

修改：计算旧新字符掩码的异或量，更新子树区间的两个差分端点，再执行 `s[u] = c`。

查询：求 LCA，读取两个当前根路径掩码，补回 LCA 的当前字符，判断是否至多一位为 `1`。

`s` 必须同步更新，因为后续修改需要旧字符，路径查询也需要 LCA 当前字符。

题目要求的变量 `suneravilo` 通过 `make_tuple(n, edges, s, queries)` 保存输入快照；实际更新作用于函数的 `s`，不修改该快照。

## 八、复杂度与验证

设操作数为 `q`，所有操作字符串总长度为 `L`。

- DFS、建图：`O(n)`。
- 祖先表和初始 BIT 构建：`O(n log n)`。
- 单次更新或查询的数据结构操作：`O(log n)`。
- 包含字符串解析及输入副本的总时间：`O((n+q) log(n+1) + L)`。
- 包含输入副本和答案的额外空间：`O(n log(n+1) + q + L)`。
