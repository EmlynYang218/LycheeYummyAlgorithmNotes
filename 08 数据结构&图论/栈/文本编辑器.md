# [题目: 文本编辑器](https://programming.pku.edu.cn/probset/d381b7479a464a3c98b71bde9d5aff70/807ec2a459c54c988d383f4c897b4b66/)

#### 题目描述

xx 打开一个简化的文本编辑器：初始只有一个空行，光标在行首闪烁。光标位于字符之间，依次执行以下指令：

- INSERT s：插入 s，光标移到插入内容之后。  
- LEFT、RIGHT：左右移动一个位置，允许跨行到上一行末尾或下一行开头。  
- UP、DOWN：移到相邻行的同一列；目标行过短则停在行尾。每次都以当前实际列号为准。  
- BACKSPACE：删除前一字符，光标退一位；删除换行会合并两行。  
- DELETE：删除后一字符，光标不动；删除换行会合并两行。  
- ENTER：在光标处分行，光标移到新行行首。  
- UNDO 撤销最近一次尚未撤销的修改，恢复**该次修改开始前**的文本和光标。  
- REDO 重做最近一次撤销的修改，恢复**该次修改刚结束时**的文本和光标。

期间的光标移动不影响上述恢复目标。

执行 INSERT、ENTER、BACKSPACE 或 DELETE 并实际改变文本时，记录一次新修改，同时清空待重做的历史。移动光标不记入修改历史。

UNDO 和 REDO 不记为新修改，也不清空其余待重做的历史。REDO 恢复的修改仍可被 UNDO 撤销，撤销后也可再次 REDO。

越界移动、无效删除及没有对应历史的撤销或重做，均忽略。

数据范围：1≤N≤1,000；所有 INSERT 指令插入的总字符数不超过 10,000。

#### 关于输入

第一行包含一个整数 N。

接下来 N 行，每行包含一条指令。INSERT 后恰有一个分隔空格，此后的所有字符组成非空字符串 s；s 只含英文字母和空格，可包含前导或末尾空格。

#### 关于输出

第一行输出三个整数 M,R,C，依次为最终行数、光标行号和列号。行号从 1 开始，列号是该行中光标左侧的字符数，从 0 开始。

随后 M 行分别输出文本，每行放在方括号中，空格改用下划线表示。例如 a b 输出 [a_b]，空行输出 []。

#### 提示信息

数据范围：1≤N≤1,000；所有 INSERT 指令插入的总字符数不超过 10,000。

样例 1 说明：在 ab 和 cd 之间分行并插入 X 后，RIGHT 将光标移到 c 后。随后撤销再重做，恢复插入 X 刚结束时的文本和光标，光标回到 X 后。最终两行分别为 ab、Xcd，光标在第 2 行第 1 列。

样例 2 说明：第三条指令中，分隔空格后的字符串由一个空格、X 和一个空格组成。撤销第二行的插入后，行尾的 DELETE 无效，仍可 REDO 恢复这三个字符。之后 BACKSPACE 删除末尾空格，撤销再重做后，第二行只剩一个前导空格和 X，输出为 [_X]。最终光标在第 2 行第 2 列。

样例 3 说明：第一次 UP 从第 3 行第 5 列移到只有一个字符的第 2 行，实际列号变为 1。第二次 UP 使用当前实际列号，停在第 1 行第 1 列，三行文本均不改变。

样例 4 说明：插入两行后，前两次 LEFT 移到第 2 行行首，第三次 LEFT 跨过换行，停在第 1 行末尾。DELETE 删除光标后的换行，将两行合为 abcd；UNDO 恢复两行文本以及第 1 行末尾的光标。最后 RIGHT 跨过换行，停在第 2 行第 0 列。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Snapshot {
    vector<string> lines;
    int r, c;
};

struct Edit {
    Snapshot before, after;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;
    cin.ignore(numeric_limits<streamsize>::max(), '\n');

    vector<string> lines(1, "");
    int r = 0, c = 0;

    vector<Edit> undoSt, redoSt;

    auto makeSnap = [&]() -> Snapshot {
        return {lines, r, c};
    };

    auto doEdit = [&](function<void()> f) {
        Snapshot before = makeSnap();
        f();
        Snapshot after = makeSnap();
        undoSt.push_back({before, after});
        redoSt.clear();
    };

    for (int i = 0; i < N; ++i) {
        string cmd;
        getline(cin, cmd);

        if (cmd.rfind("INSERT ", 0) == 0) {
            string s = cmd.substr(7);
            doEdit([&]() {
                lines[r].insert(c, s);
                c += (int)s.size();
            });
        } else if (cmd == "LEFT") {
            if (c > 0) --c;
            else if (r > 0) { --r; c = (int)lines[r].size(); }
        } else if (cmd == "RIGHT") {
            if (c < (int)lines[r].size()) ++c;
            else if (r + 1 < (int)lines.size()) { ++r; c = 0; }
        } else if (cmd == "UP") {
            if (r > 0) {
                --r;
                if (c > (int)lines[r].size()) c = (int)lines[r].size();
            }
        } else if (cmd == "DOWN") {
            if (r + 1 < (int)lines.size()) {
                ++r;
                if (c > (int)lines[r].size()) c = (int)lines[r].size();
            }
        } else if (cmd == "BACKSPACE") {
            if (c > 0) {
                doEdit([&]() {
                    lines[r].erase(c - 1, 1);
                    --c;
                });
            } else if (r > 0) {
                doEdit([&]() {
                    int prevLen = (int)lines[r - 1].size();
                    lines[r - 1] += lines[r];
                    lines.erase(lines.begin() + r);
                    --r;
                    c = prevLen;
                });
            }
        } else if (cmd == "DELETE") {
            if (c < (int)lines[r].size()) {
                doEdit([&]() {
                    lines[r].erase(c, 1);
                });
            } else if (r + 1 < (int)lines.size()) {
                doEdit([&]() {
                    lines[r] += lines[r + 1];
                    lines.erase(lines.begin() + r + 1);
                });
            }
        } else if (cmd == "ENTER") {
            doEdit([&]() {
                string right = lines[r].substr(c);
                lines[r] = lines[r].substr(0, c);
                lines.insert(lines.begin() + r + 1, right);
                ++r;
                c = 0;
            });
        } else if (cmd == "UNDO") {
            if (!undoSt.empty()) {
                Edit e = undoSt.back();
                undoSt.pop_back();
                lines = e.before.lines;
                r = e.before.r;
                c = e.before.c;
                redoSt.push_back(e);
            }
        } else if (cmd == "REDO") {
            if (!redoSt.empty()) {
                Edit e = redoSt.back();
                redoSt.pop_back();
                lines = e.after.lines;
                r = e.after.r;
                c = e.after.c;
                undoSt.push_back(e);
            }
        }
    }

    cout << lines.size() << ' ' << r + 1 << ' ' << c << '\n';
    for (auto &s : lines) {
        cout << '[';
        for (char ch : s) cout << (ch == ' ' ? '_' : ch);
        cout << "]\n";
    }
    return 0;
}
```
