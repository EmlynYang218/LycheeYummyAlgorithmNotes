# [题目: 习题(15-6) 走出迷宫](https://programming.pku.edu.cn/probset/5c26f2630c724b359120a8452eb4cbf8/689a3978255e452cb6b614ef60a80e37/)

#### 题目描述

当你站在一个迷宫里的时候，往往会被错综复杂的道路弄得失去方向感，如果你能得到迷宫地图，事情就会变得非常简单。  
假设你已经得到了一个n*m的迷宫的图纸，请你找出从起点到出口的最短路。

#### 关于输入

第一行是两个整数n和m(1<=n,m<=100)，表示迷宫的行数和列数。  
接下来n行，每行一个长为m的字符串，表示整个迷宫的布局。字符'.'表示空地，'#'表示墙，'S'表示起点,'T'表示出口。

#### 关于输出

输出从起点到出口最少需要走的步数。(你不能起出迷宫外)

#### 例子输入

3 3
S#T
.#.
...

#### 例子输出



```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
char maze[110][110];
int dist[110][110];
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

int main() {
    cin >> n >> m;
    int sx, sy, tx, ty;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> maze[i][j];               // 逐字符读，自动跳过空白
            if (maze[i][j] == 'S') { sx = i; sy = j; }
            if (maze[i][j] == 'T') { tx = i; ty = j; }
        }
    }

    memset(dist, -1, sizeof(dist));          // -1 表示未访问

    queue<pair<int,int>> q;
    q.push({sx, sy});
    dist[sx][sy] = 0;                        // 起点步数 0

    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();

        if (x == tx && y == ty) {            // 第一次到达 T 即最短
            cout << dist[x][y] << endl;
            return 0;
        }

        for (int k = 0; k < 4; k++) {
            int nx = x + dx[k];
            int ny = y + dy[k];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;  // 越界
            if (maze[nx][ny] == '#') continue;                     // 墙
            if (dist[nx][ny] != -1) continue;                      // 已访问
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }

    cout << -1 << endl;                      // 无解（题面未明确，按惯例）
    return 0;
}
```
