# [题目: 数据类型转换](https://programming.pku.edu.cn/probset/7d229bb5254143a9a8287a90a8950281/dc8759a7fd384a6688eba9f1cdbe572b/)

#### 题目描述

给出一个仅包含 char、bool、int、long long、float、double 六种数据类型的变量 以及 加法(+)运算、乘法(*)运算、逗号(,)运算 三种运算符的表达式 s。请你写程序求出该表达式运算结果的数据类型。

其中，数据类型转换的规则如下：

当进行 + 或 * 运算时：

1. 所有占用字节数小于 int 字节的操作数的类型（如 char）会自动转换为 int。  
2. 对两个相同类型的变量 a 和 b，表达式 a+b 和 a*b 的返回值的类型同时与 a 和 b 的类型相同。  
3. 对两个整型的运算，会将其转化为 精度更高（占用字节数更多）的数据类型 进行运算。如对于表达式 c+d，若 c 和 d 分别为 int 和 long long 类型，编译器会先将 c 转换为 long long 类型，然后做 long long 类型的加法，运算结果也为 long long 类型。对两个浮点类型的运算，其规则类似。  
4. 当整数类型和浮点类型同时参与运算时，所有整数类型都会转换为其中 精度最高的浮点类型。如对于表达式 e*f，若 e 和 f 分别为 long long 和 float 类型，编译器会先将 e 转换为 float 类型，然后做 float 类型的乘法，运算结果也为 float 类型。

当进行逗号(,)运算时：

包含 逗号(,)运算 的表达式 f,g 的返回值为 g。因此，逗号(,)运算 的结果类型与其第二个运算对象相同。注意，逗号(,)运算 的优先级低于 + 与 *。

为了方便，我们只给出表达式中每个变量的类型，而不涉及其变量名称。特别地，long long 用不带空格的 longlong 表示。

数据范围：表达式中数据类型的个数≤100000。

#### 关于输入

本题有多组数据，第一行一个正整数 T，表示数据组数。

对于每组数据，一行一个字符串 s，表示给定的表达式。

#### 关于输出

对于每组数据，一行一个字符串，表示给定的表达式的运算结果的类型（类似地，若运算结果的类型为 long long，输出不带空格的 longlong）。

#### 例子输入

样例 1 输入：
5
char
int+bool
float*int+longlong
int+char*bool+double
float+bool*double,int*longlong+char

#### 例子输出

样例 1 输出：
char
int
float
double
longlong

#### 提示信息

数据范围：1≤T≤10，表达式中数据类型的个数≤100000。



### 递归写法

```cpp
#include <iostream>
#include <string>
using namespace std;

string s;
int pos;

// 返回类型名的精度等级，用于合并
// char/bool 先视为 int 级别之前，单独处理
int rankOf(const string& t) {
    if (t == "char" || t == "bool") return 0; // 待提升为 int
    if (t == "int")      return 1;
    if (t == "longlong") return 2;
    if (t == "float")    return 3;
    if (t == "double")   return 4;
    return -1;
}

string typeOfRank(int r) {
    if (r == 1) return "int";
    if (r == 2) return "longlong";
    if (r == 3) return "float";
    if (r == 4) return "double";
    return "int";
}

// 提升 char/bool 为 int
string promote(const string& t) {
    if (t == "char" || t == "bool") return "int";
    return t;
}

// + 和 * 共用的类型合并规则
string mergeType(const string& l, const string& r) {
    string a = promote(l);
    string b = promote(r);
    int ra = rankOf(a), rb = rankOf(b);
    // 整型与浮点混合时，浮点 rank 都大于整型 rank，
    // 取 rank 大者正好满足“整数转浮点、浮点取高精度”
    return typeOfRank(max(ra, rb));
}

// 读一个类型名
string parseAtom() {
    // 六种类型名首字母不同，但 bool 与 double 需注意：
    // 这里按最长匹配逐字符读，读到非字母为止
    int start = pos;
    while (pos < (int)s.size() && isalpha(s[pos])) pos++;
    return s.substr(start, pos - start);
}

// 乘法层：atom ('*' atom)*
string parseMul() {
    string left = parseAtom();
    while (pos < (int)s.size() && s[pos] == '*') {
        pos++; // 跳过 '*'
        string right = parseAtom();
        left = mergeType(left, right);
    }
    return left;
}

// 加法层：mul ('+' mul)*
string parseAdd() {
    string left = parseMul();
    while (pos < (int)s.size() && s[pos] == '+') {
        pos++; // 跳过 '+'
        string right = parseMul();
        left = mergeType(left, right);
    }
    return left;
}

// 逗号层：add (',' add)*，结果取最后一个
string parseComma() {
    string left = parseAdd();
    while (pos < (int)s.size() && s[pos] == ',') {
        pos++; // 跳过 ','
        string right = parseAdd();
        left = right; // 逗号返回第二个操作数
    }
    return left;
}

int main() {
    int T;
    cin >> T;
    while (T--) {
        cin >> s;
        pos = 0;
        cout << parseComma() << "\n";
    }
    return 0;
}
```
