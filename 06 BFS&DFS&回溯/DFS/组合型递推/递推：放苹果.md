# [题目: 放苹果问题](https://programming.pku.edu.cn/probset/7854ebcf1a8e4dbb98b3c87b684492a2/144e5b3d40e744799bbb7bcf2cae2e59/)

#### 题目描述

把M个同样的苹果放在N个同样的盘子里，允许有的盘子空着不放，问共有多少种不同的分法（用K表示）？注意：5，1，1和1，5，1是同一种分发。

#### 关于输入

第一行是测试数据的数目t（0<= t <= 20）,其后的t行均包含两个整数M和N，以空格分开。
1<= M <= 25;
1<= N <= 10;

#### 关于输出

对输入的每组数据M和N，用一行输出相应的K

#### 例子输入

```
1
7 3
```

#### 例子输出

```
8
```

#### 提示信息

采用递归思想解题。

```c
#include <stdio.h>

int f(int m, int n) {
    if (m == 0) return 1;      // 没有苹果：1 种放法（全空）
    if (n == 0) return 0;      // 没有盘子：放不了
    if (n > m)  return f(m, m); // 盘子比苹果多，多出的盘子必空
    return f(m, n - 1) + f(m - n, n); // 有空盘 + 无空盘
}

int main(void) {
    int t, m, n;
    scanf("%d", &t);
    while (t--) {
        scanf("%d %d", &m, &n);
        printf("%d\n", f(m, n));
    }
    return 0;
}
```
