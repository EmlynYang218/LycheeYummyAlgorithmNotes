# 题目 [左手定则](https://programming.pku.edu.cn/probset/7854ebcf1a8e4dbb98b3c87b684492a2/0f6a59058e6644cdafa28492352c317d/)

来源：*BNUOJ*

#### 题目描述

玩过RPG（尤其是国产RPG）的童鞋都应该对迷宫这种神棍的设定深恶痛绝，尤其是当你转了半小时之后发现回到了原地，这种感觉真是无比的痛苦。。。万一游戏还中途崩溃了那真是连掀桌子、砸键盘、摔鼠标的心都有了……  
经过无数次的TRIAL AND ERROR之后，玩家终于下定决心认定迷宫存在的意义就是延长游戏时间，SO，他决定借鉴著名的左手定则（就是在每一个路口，我们都选择最左边的方向，左转的优先级最高，其次为向前，最后为右转，如果实在走进了一个死胡同，那就连续右转两次，回头向后走。稍微研究一下这种走迷宫的方法，我们就发现在这个过程中，事实上我们的左手可以始终放在墙上。）对迷宫进行探索。  
但是呢，左手定则并不能保证遍历到迷宫中的每一个点。悲剧的是，某项重要的通关道具被放在了这个迷宫中……幸运的是，游戏迷宫的地图可以绘制出来，现在请求你的帮助。对于一个给定的地图，他想知道是不是能够通过左手定则取得这件道具。  

#### 关于输入

多组数据。  
对于每组数据，第一行有两个整数N,M代表接下来有n行字符串，每行m个字符，其中0 < n <= 100, 0 < m <= 100，表示一个n × m的迷宫。  
其中‘#’表示墙，‘S’表示起点，‘T’表示道具，‘.’表示空地。  
接下来是一个方向（NSWE），表示起始面向的方向。  
数据保证最外一圈都是墙。  

#### 关于输出

对于每组数据输出一行。‘YES’表示可以到达，‘NO’表示无法到达。

```cpp
#include <bits/stdc++.h>
using namespace std;

static int dir2idx[128];

// 4个朝向分别对应前后左右，各有2偏移量
// N W S E，每次下标+1都相当于左转，再取模
static int moves[4][2] = {
    {-1, 0}, {0, -1}, {1, 0}, {0, 1}};

/*
DFS模拟走迷宫，由于迷宫的构造保证不会原地转圈，总会回到起点
但在能取到道具的路径中，起点也是可能被反复经过的。

  →y
↓
x

  N
  ↑
W← →E
  ↓
  S

*/
//记忆化：如果重复到达相同的状态，会陷入死循环
bool dfs(vector<vector<vector<bool>>> &visited, vector<vector<char>> &matrix, int x, int y, int idx)
{
    if (visited[x][y][idx] == true || matrix[x][y] == '#')
    {
        return false;
    }
    visited[x][y][idx] = true;
    if (matrix[x][y] == 'T')
    {
        return true;
    }
    //左转的优先级最高
    int *left_turn = moves[(idx + 1) % 4];
    if (matrix[x + left_turn[0]][y + left_turn[1]] != '#')
    {
        return dfs(visited,matrix, x + left_turn[0], y + left_turn[1], (idx + 1) % 4);
    }
    //其次为向前
    int *forward = moves[idx % 4];
    if (matrix[x + forward[0]][y + forward[1]] != '#')
    {
        return dfs(visited,matrix, x + forward[0], y + forward[1], idx % 4);
    }
    //最后为右转
    int *right_turn = moves[(idx + 3) % 4];
    if (matrix[x + right_turn[0]][y + right_turn[1]] != '#')
    {
        return dfs(visited,matrix, x + right_turn[0], y + right_turn[1], (idx + 3) % 4);
    }
    //如果实在走进了一个死胡同，那就连续右转两次，回头向后走
    int *backward = moves[(idx + 2) % 4];
    return dfs(visited,matrix, x + backward[0], y + backward[1], (idx + 2) % 4);
}
int main()
{
    dir2idx['N'] = 0;
    dir2idx['W'] = 1;
    dir2idx['S'] = 2;
    dir2idx['E'] = 3;

    int n, m, sx, sy;
    char dir;
    while (cin >> n >> m)
    {
        vector<vector<char>> matrix(n, vector<char>(m, ' '));
        vector<vector<vector<bool>>> visited(n, vector<vector<bool>>(m, vector<bool>(4, false)));
        for (int i = 0; i < n; i++)
        {
            for (int j = 0; j < m; j++)
            {
                cin >> matrix[i][j];
                if (matrix[i][j] == 'S')
                {
                    sx = i;
                    sy = j;
                }
            }
        }
        cin >> dir;

        if (dfs(visited,matrix, sx, sy, dir2idx[dir]))
        {
            cout << "YES\n";
        }
        else
        {
            cout << "NO\n";
        }
    }
}
```



#### Insight 1：

本题和dfs模板的区别在于，dfs模板的精髓在于“回溯”，也就是“钻到底再返回“

而本题的模拟过程是”优先选择一个方向走下去”的确定规则下，模拟路径，而没有回溯的过程。

#### Insight 2：

visited状态数组的设计，用来判断路径中是否存在环。
