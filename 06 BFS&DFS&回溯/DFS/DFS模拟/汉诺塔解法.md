# 例题(15.3) [汉诺塔](https://programming.pku.edu.cn/probset/7854ebcf1a8e4dbb98b3c87b684492a2/0c597d3b24c3432fba616e6cd7a05b3e/)

来源：*chg*

#### 题目描述

汉诺塔是约19世纪末，在欧州的商店中出售一种智力玩具。它的结构如下图所示：  
![](https://programming.pku.edu.cn/probset/7854ebcf1a8e4dbb98b3c87b684492a2/0c597d3b24c3432fba616e6cd7a05b3e/hanoi)  
在一个平板上立有三根铁针，分别记为A, B, C。开始时，铁针 A 上依次叠放着从大到小 n 个圆盘，游戏的目标就是将 A 上的 n 个圆盘全部转移到 C 上，要求每次只能移动某根铁针最上层一个圆盘，圆盘不得放在这三根铁针以外的任何地方，而且永远只能将小的圆盘叠放在大的圆盘之上。

例如，下面就是示例输出中（n = 3）移动方案的图示：

![](https://programming.pku.edu.cn/probset/7854ebcf1a8e4dbb98b3c87b684492a2/0c597d3b24c3432fba616e6cd7a05b3e/hanoi3)

这是一个著名的问题，几乎所有的教材上都有这个问题。由于条件是一次只能移动一个盘，且不允许大盘放在小盘上面，所以 64 个盘的移动次数是：  
18,446,744,073,709,551,615  
这是一个天文数字，若每一微秒可能做一次移动，那么也需要几乎一百万年。我们仅能找出问题的解决方法并解决较小 n 值时的汉诺塔，但很难用计算机解决64层的汉诺塔。  

#### 关于输入

输入数据只有一个正整数 n (n <= 16) ， 表示开始时铁针 A 上的圆盘数

#### 关于输出

要求输出步数最少的搬动方案，方案是由若干个步骤构成的，输出的每行就表示一个移动步骤，例如，“A->B”就表示把铁针 A 最上层的一个圆盘移动到 B 上。

#### 例子输入

```
3
```

#### 例子输出

```
A->C
A->B
C->B
A->C
B->A
B->C
A->C
```

```cpp
#include <bits/stdc++.h>
using namespace std;
/*n>=2层汉诺塔，
    1）解n-1层汉诺塔
    2）转移最大圆环
    3）解n-1层汉诺塔
*/
static constexpr char sticks[3] = {'A','B','C'};

/*
n==1
A->C

n==2
解1层汉诺塔，A->B
move(1,A,C)
移动最大环   A->C
1
解1层汉诺塔  B->C
move(1,B,C)

n==3
解2层汉诺塔  A移动2层到B
move(2,A,B)
    move(1,A,C)
    move(1,C,B)
移动最大环   
A->C
解2层汉诺塔  B移动2层到C
move(2,B,C)
    move(1,B,A)
    move(1,A,C)


n==4
解3层汉诺塔 A移动3层到B
move(3,A,B)
    move(2,A,C)
    A->B
    move(2,C,B)
移动最大环 A->C
1
解3层汉诺塔 B移动3层到C
move(3,B,C)
    move(2,B,A)
    B->C
    move(2,A,C)

从而得到n阶的递归方案
move(n-1,A,B)
    //每次找上面没出现的那个字母，比如A，B没出现的是C
    move(n-2,A,C)
    A->B
    move(n-2,C,B)
A->C
move(n-1,B,C)
*/

void move(int n,char from, char to){
    if(n==1){
        cout<<from<<"->"<<to<<'\n';
        return;
    }

    char missing;
    for(int i = 0; i < 3; i ++){
        if(sticks[i]!=from&&sticks[i]!=to){
            missing = sticks[i];
            break;
        }
    }

    move(n-1,from,missing);
    move(1,from,to);
    move(n-1,missing,to);

}
int main()
{

    int n;
    cin >> n;
    move(n,'A','C');

    return 0;
}
```
