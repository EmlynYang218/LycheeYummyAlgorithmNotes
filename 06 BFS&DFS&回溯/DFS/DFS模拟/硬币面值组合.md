# [题目: 习题(15-2) 硬币面值组合](https://programming.pku.edu.cn/probset/5c26f2630c724b359120a8452eb4cbf8/802209a27bab488fbdb50c87852f5140/)

#### 题目描述

使用1角、2角、5角硬币组成 n 角钱。  
设1角、2角、5角的硬币各用了a、b、c个，列出所有可能的a, b, c组合。  
输出顺序为，按c的值从小到大，c相同的按b的值从小到大输出。  
要求必须使用递归。

#### 关于输入

输入只有一个整数n（1 <= n <= 100)，代表需要组成的钱的角数。

#### 关于输出

输出有若干行，每行的形式为：  
i           a           b           c

第1列i代表当前行数（行数从001开始，固定3个字符宽度，宽度不足3的用0填充），  
后面3列a, b, c分别代表1角、2角、5角硬币的个数（每个数字固定12个字符宽度，宽度不足的在左边填充空格）

#### 例子输入

10

#### 例子输出

001          10           0           0
002           8           1           0
003           6           2           0
004           4           3           0
005           2           4           0
006           0           5           0
007           5           0           1
008           3           1           1
009           1           2           1
010           0           0           2

#### 提示信息

cout << setfill('0')可以设置填充字符为'0'；  
设完之后记得调用setfill(' ')设回空格，否则会影响后续输出。

```c
#include <stdio.h>

int count = 0;

void solve(int n, int c, int b) {
    int remaining = n - 5 * c - 2 * b;
    if (remaining < 0) return;

    count++;
    printf("%03d%12d%12d%12d\n", count, remaining, b, c);

    if (remaining >= 2)
        solve(n, c, b + 1);
}

void solve_c(int n, int c) {
    if (5 * c > n) return;
    solve(n, c, 0);
    solve_c(n, c + 1);
}

int main() {
    int n;
    scanf("%d", &n);
    solve_c(n, 0);
    return 0;
}
```
