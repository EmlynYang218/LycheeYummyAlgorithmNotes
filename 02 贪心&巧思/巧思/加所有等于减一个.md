# 453. 最小操作次数使数组元素相等

## 题干

长度 n 的整数数组，每次操作让 n-1 个元素同时 +1。
求让所有元素相等的最小操作次数。

例：[1,2,3] → 3 次。

## 关键转化

"n-1 个元素 +1" 等价于 "1 个元素 -1"（相对大小关系不变，题目不关心最终绝对值）。

于是问题变成：把所有元素减到数组最小值 min(nums)。
每个元素需减 nums[i] - min(nums) 次。

答案 = Σ(nums[i] - min(nums))

## 代码

```cpp
class Solution {
public:
    int minMoves(vector<int>& nums) {
        int mn = *min_element(nums.begin(), nums.end());
        long long ans = 0;
        for (int v : nums) ans += v - mn;
        return (int)ans;
    }
};
```











## 正确性证明



证明分三步：**等价性**（原操作 ⇔ 减一操作）、**下界**（至少需要这么多步）、**可达性**（这么多步确实够）。三者合起来就证明了"答案 = Σ(nums[i] - min)"。

---

## 一、等价性：两种操作描述同一件事

**命题**：对数组做一次"选 n-1 个元素各 +1"，与做一次"选 1 个元素 -1"，得到的数组**相对大小关系相同**（相差一个整体平移）。

设当前数组为 `a`，选中的"没被加"的那个下标为 `k`。

- 原操作：`a[i] += 1 (i ≠ k)`，`a[k]` 不变 → 新数组 `b`，其中 `b[i] - b[k] = a[i] - a[k] + 1 (i≠k)`，`b[k]-b[k]=0`。

- 减一操作：`a[k] -= 1`，其余不变 → 新数组 `c`，其中 `c[i] - c[k] = a[i] - (a[k]-1) = a[i] - a[k] + 1 (i≠k)`，`c[k]-c[k]=0`。

两者**所有元素与 `a[k]` 的差值完全相同**。而"所有元素相等"是一个只依赖**差值**的性质（`a[i]=a[j]` ⇔ `a[i]-a[j]=0`），整体平移不改变它。

所以：**用哪种操作描述，达到"全相等"所需的最少步数相同**。这就是可以把"n-1 个 +1"换成"1 个 -1"的合法性来源。

> 关键点：题目只问"步数"，不问"最终值"。若题目问"最终值是多少"，两种描述就**不等价**了（加操作终值会更高），不能替换。本题恰好只问步数，所以成立。

---

## 二、下界：至少需要 Σ(nums[i] - min) 步

在"减一"模型下，**每次操作只能让一个元素减小 1，没有任何元素会增大**。

设初始最小值 `mn = min(nums)`，其下标为 `p`。

- 元素 `nums[p]` 在减一模型下**永远不会被减小**吗？不一定——它也可能被选中减 1。但一旦它被减，新的最小值就更小，所有元素最终要相等，就得继续往下追。

- 更干净的说法：**最终相等的值 `T` 必须 ≤ mn**。因为所有元素只能减不能增，`nums[p]` 最终值 ≤ `nums[p] = mn`，而所有元素最终都等于 `T`，故 `T ≤ mn`。

- 每个元素 `nums[i]` 从 `nums[i]` 降到 `T`，**至少**要 `nums[i] - T` 次操作（每次至多减 1）。

- 总步数 ≥ `Σ(nums[i] - T) ≥ Σ(nums[i] - mn)`（因为 `T ≤ mn`，`nums[i]-T ≥ nums[i]-mn`）。

所以 **任何方案都至少需要 Σ(nums[i] - mn) 步**。这是下界。

---

## 三、可达性：Σ(nums[i] - min) 步确实能做到

构造方案：对每个元素 `nums[i]`，把它单独减 `nums[i] - mn` 次（在减一模型下，就是"每次选中它减 1"，共 `nums[i]-mn` 次）。

- 每个元素最终都变成 `mn`，全部相等 ✓

- 总步数 = `Σ(nums[i] - mn)` ✓

在减一模型下这一步操作是合法的（每次选 1 个元素减 1），由**等价性**，它在原模型下也对应合法操作序列（每次让其余 n-1 个 +1，效果相同）。

所以 **Σ(nums[i] - mn) 步是可达的**。

---

## 四、结论

- 下界：≥ Σ(nums[i] - mn)

- 可达：= Σ(nums[i] - mn)

两者夹逼，**最小操作次数 = Σ(nums[i] - mn)**。∎
