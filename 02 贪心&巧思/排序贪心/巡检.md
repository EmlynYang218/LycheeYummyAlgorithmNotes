#### 题目描述

xx 要安排机器人完成 n 项巡检工作，顺序可以任意调整。第 i 项工作开始时，机器人至少要有 ai 单位电量，完成后消耗 bi 单位电量。每项工作都要完成一次，途中不能充电。

请问机器人出发时至少需要多少单位电量，才能完成全部工作？

数据范围：1≤n≤100，1≤bi≤ai≤1000。

#### 关于输入

第一行包含一个整数 n。

接下来 n 行，每行包含两个整数 ai,bi，分别表示开始该项工作所需的最低电量和完成该项工作消耗的电量。

#### 关于输出

输出一行，包含机器人出发时需要的最少电量。

#### 例子输入

样例 1 输入：
3
9 6
8 2
4 3
样例 2 输入：
1
10 3
样例 3 输入：
3
5 5
2 2
4 4

#### 例子输出

样例 1 输出：
12
样例 2 输出：
10
样例 3 输出：
11

#### 提示信息

数据范围：1≤n≤100，1≤bi≤ai≤1000。

样例 1 说明：按第 2、1、3 项的顺序工作，电量依次从 12 变为 10、4、1，各项工作开始时的电量都足够。若出发时只有 11 单位电量，总消耗也是 11，所以最后一项工作需要恰好用完剩余电量，但三项工作的最低电量都大于其消耗，无法完成。

样例 2 说明：虽然只消耗 3 单位电量，开始时仍需至少 10 单位。

样例 3 说明：可以恰好用完电量。





```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;
    vector<pair<int,int>> steps = vector<pair<int,int>>(n,{0,0});
    for(int i = 0; i < n; i++){
        cin >> steps[i].first >> steps[i].second;
    }
    sort(steps.begin(),steps.end(),[](const pair<int,int>& a, const pair<int,int>& b){
        return a.first-a.second > b.first-b.second;
    });
    //把开始电量看成若干充电之和，那么充电之和最少则总电量最少
    //充电少的办法是最大化利用“上次剩的电”
    //排序，按剩的多->剩的少排
    int hp = 0;
    int ans = 0;
    for(int i = 0; i < n; i ++){
        //判断是否需要加血
        if(steps[i].first>hp){
            ans += steps[i].first-hp;
            hp = steps[i].first-steps[i].second;
        }else{
            hp -= steps[i].second;
        }
        
    }
    cout<<ans<<endl;
    
    return 0;
}
```
