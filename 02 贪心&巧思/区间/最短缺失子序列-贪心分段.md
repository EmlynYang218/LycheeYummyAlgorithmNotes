# 最短缺失子序列：贪心分段

## 问题

给定长度为 `N` 的序列 `T`，元素取自 `{1, 2, ..., M}`，允许重复。求最小长度 `t`，使得存在一个长度为 `t` 的序列 `T*`，`，元素取自 `{1, 2, ..., M}`它不是 `T` 的子序列。子序列保持元素顺序，但不要求连续。

## 贪心观察

从左向右扫描 `T`，统计当前段出现过哪些数。每当 `{1, ..., M}` 全部出现，就结束一段并清空统计，继续扫描。设完整段数为 `k`，答案是 `k + 1`。

这里的分段是按扫描过程贪心完成的：每段都是从当前起点出发，最短的、包含全部 `M` 种数的连续片段。

## 正确性说明

- **下界：** 每个完整段都包含所有 `M` 种数。因此，任意长度不超过 `k` 的序列，都可以从前 `k` 个完整段中依次各取一个对应元素，得到它作为 `T` 的子序列。故最短缺失长度至少为 `k+1`。
- **上界：** 对每个完整段，记录使该段首次集齐全部数的最后一个元素。将这些记录按段顺序组成序列。贪心匹配这些记录时，每个记录都只能在对应段的结束位置首次匹配：此前的前缀尚未集齐全部数，所以该记录对应的符号此前没有出现。令最后一个完整段之后的尾段为 `S`；它没有集齐全部数，所以存在一个符号 `x` 没有出现在 `S` 中。把 `x` 追加到记录序列末尾，得到长度 `k+1` 的序列。前 `k` 个符号的贪心匹配被迫到达第 `k` 段末尾，之后尾段没有 `x`，因此整个序列无法匹配。

因此最短长度恰为 `k+1`。若扫描结束时不足一个完整段，也不影响答案；`k=0` 时答案为 `1`。

## C++ 实现

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    cin >> N >> M;

    vector<bool> seen(M + 1, false);
    int distinct = 0;
    int completed = 0;

    for (int i = 0, x; i < N; ++i) {
        cin >> x;
        if (!seen[x]) {
            seen[x] = true;
            ++distinct;
        }
        if (distinct == M) {
            ++completed;
            fill(seen.begin(), seen.end(), false);
            distinct = 0;
        }
    }

    cout << completed + 1 << '\n';
}
```

时间复杂度：`O(N + kM)`（每次切段清空标记数组）。每个完整段至少包含 `M` 个元素，因此 `kM <= N`，总时间仍为 `O(N)`；空间复杂度：`O(M)`。若希望清空操作为 `O(1)`，可改用时间戳数组。

## 实现注意

- 原代码的 `int nums[N]` 是变长数组，不属于标准 C++；本题可直接边读边处理。
- 用 `unordered_set` 也能记录当前段的不同元素，但数组或时间戳数组更简单、开销更可控。
- 答案要从 `1` 开始计数：若连一个完整段都没有，所有长度为 `1` 的数未必都出现，答案就是 `1`。

附：原题描述

[题目: 愉悦的旋律](https://programming.pku.edu.cn/probset/fb79e9e1d0274ae38442414fb338b0e4/252467a965124b098450def9476bcaed/)

#### 题目描述

在去年的计概期末，大家知道了P大富哥李哥，而李哥有个好朋友陈哥。

与李哥不同，陈哥喜欢钻研音乐，他创造了一种特殊的音乐，这种音乐可以包含 M种 不同的音符(1<=M<=10000)，因此，每个音符都可以唯一编码为1到10000之间的一个整数。陈哥创作的每首乐曲都可以看做由 N个 (1<=N<=100000)这种音符所组成的音符序列。

例如，可以利用3种音符组成如下的音符序列：1,2,2,3,2,3,3,1

根据陈哥敏感的音乐细胞，他发现，针对每首给定的音符序列，有些子序列（不一定连续）会出现在该序列中，而有些子序列则不会出现在该序列中。

例如，对于上面例子中的音符序列，子序列"1,2,2,1"就出现在该序列中，而子序列“2,1,3”就没有出现在该序列中。

热心的陈哥告诉你：正如子序列"1,2,2,1"一样，子序列中的数不需要在原始音符序列中“连续出现”，只要其遵循原本在音符序列中的先后次序，即使子序列的各个数之间穿插有其他数字，也可认为这个子序列出现于音符序列中。

现在，给定一首已经创作完成的包含 N个 音符的音符序列，陈哥想用 M种 不同的音符构造一个子序列，使之“不出现”在给定的乐曲序列中。李哥想将其称为“崭新的旋律”，但陈哥还是喜欢称为“愉悦的旋律”，请问这个“愉悦的旋律”的最短长度是多少？

#### 关于输入

第1行输入两个整数 N 和 M ，接下来 N 行输入音符序列。

#### 关于输出

输出一行，包含一个整数，代表最短的“愉悦的旋律”的长度。

14 5
1
5
3
2
5
1
3
4
4
2
5
1
2
3

#### 例子输出

3

#### 提示信息

样例解释：

所有长度为1和2的可能的子序列都出现了，但长度为3的子序列"2,2,4"却没有出现。
