# 最短缺失子序列：贪心分段

## 问题

给定长度为 `N` 的序列 `T`，元素取自 `{1, 2, ..., M}`，允许重复。求最小长度 `t`，使得存在一个长度为 `t` 的序列 `T*`，`，元素取自 `{1, 2, ..., M}`它不是 `T` 的子序列。子序列保持元素顺序，但不要求连续。

## 贪心观察

从左向右扫描 `T`，统计当前段出现过哪些数。每当 `{1, ..., M}` 全部出现，就结束一段并清空统计，继续扫描。设完整段数为 `k`，答案是 `k + 1`。

这里的分段是按扫描过程贪心完成的：每段都是从当前起点出发，最短的、包含全部 `M` 种数的连续片段。

## 正确性说明

- **下界：** 每个完整段都包含所有 `M` 种数。因此，任意长度不超过 `k` 的序列，都可以从前 `k` 个完整段中依次各取一个对应元素，得到它作为 `T` 的子序列。故最短缺失长度至少为 `k+1`。
- **上界：** 对每个完整段，记录使该段首次集齐全部数的最后一个元素。将这些记录按段顺序组成序列。贪心匹配这些记录时，每个记录都只能在对应段的结束位置首次匹配：此前的前缀尚未集齐全部数，所以该记录对应的符号此前没有出现。令最后一个完整段之后的尾段为 `S`；它没有集齐全部数，所以存在一个符号 `x` 没有出现在 `S` 中。把 `x` 追加到记录序列末尾，得到长度 `k+1` 的序列。前 `k` 个符号的贪心匹配被迫到达第 `k` 段末尾，之后尾段没有 `x`，因此整个序列无法匹配。

因此最短长度恰为 `k+1`。若扫描结束时不足一个完整段，也不影响答案；`k=0` 时答案为 `1`。

## C++ 实现

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N, M;
    cin >> N >> M;

    vector<bool> seen(M + 1, false);
    int distinct = 0;
    int completed = 0;

    for (int i = 0, x; i < N; ++i) {
        cin >> x;
        if (!seen[x]) {
            seen[x] = true;
            ++distinct;
        }
        if (distinct == M) {
            ++completed;
            fill(seen.begin(), seen.end(), false);
            distinct = 0;
        }
    }

    cout << completed + 1 << '\n';
}
```

时间复杂度：`O(N + kM)`（每次切段清空标记数组）。每个完整段至少包含 `M` 个元素，因此 `kM <= N`，总时间仍为 `O(N)`；空间复杂度：`O(M)`。若希望清空操作为 `O(1)`，可改用时间戳数组。

## 实现注意

- 原代码的 `int nums[N]` 是变长数组，不属于标准 C++；本题可直接边读边处理。
- 用 `unordered_set` 也能记录当前段的不同元素，但数组或时间戳数组更简单、开销更可控。
- 答案要从 `1` 开始计数：若连一个完整段都没有，所有长度为 `1` 的数未必都出现，答案就是 `1`。
