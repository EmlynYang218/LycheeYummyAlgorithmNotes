# [题目: 竹竿](https://programming.pku.edu.cn/probset/7d229bb5254143a9a8287a90a8950281/f7000b6bad9c4a4ba0a67a83ff44f35a/)

#### 题目描述

有 n 根竹竿，第 i 根竹竿的长度为 ai，在距离一端的 bi 长度处有一个标记。

现要将所有竹竿捆在一起放入竹筒，要求每根竹竿的标记必须重合（会在此处捆上），但每根竹竿的方向可以调换。

请问竹筒需要有多长，才能确保无论每根竹竿是什么方向，捆起来的竹竿都能完全被放进竹筒中。

数据范围：2≤n≤100000，1≤ai≤1,000,000,000，0≤bi≤ai。

#### 关于输入

第一行，一个正整数 n，表示竹竿的数量。

接下来 n 行，第 i 行包含两个整数 ai,bi，描述第 i 根竹竿。

#### 关于输出

一行一个正整数，表示答案。

#### 例子输入

样例 1 输入：
2
5 2
4 3
样例 2 输入：
4
5 1
5 2
5 3
5 4

#### 例子输出

样例 1 输出：
6
样例 2 输出：
8

#### 提示信息

数据范围：2≤n≤100000，1≤ai≤1,000,000,000，0≤bi≤ai。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    //每根竹竿最长部分，取这里面最大的两个加和与最长竹竿比较
    long long sticks1[n] = {0};
    long long max1 = 0, pos1=0, max2=0,max3=0;
    for(int i = 0; i < n; i++){
        long long ai,bi;
        cin >> ai >> bi;
        sticks1[i]=max(ai-bi,bi);
        max3 = max(max3,ai);
    }
    for(int i = 0; i < n; i++){
        if(sticks1[i]>max1){
            max1 = sticks1[i];
            pos1 = i;
        }
    }
    for(int i = 0; i < n; i++){
        if(i==pos1){
            continue;
        }
        if(sticks1[i]>max2){
            max2 = sticks1[i];
        }
    }
    cout<<max(max3,max1+max2);
    return 0;
}

/*
4 1
3 2
2 3
1 4

3 2
3 1
*/
```
