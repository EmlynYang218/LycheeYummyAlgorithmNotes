# [题目: 最大拼接数字](https://programming.pku.edu.cn/probset/fb79e9e1d0274ae38442414fb338b0e4/86834a8f69e144b89bb8159cb4c98672/)

#### 题目描述

给定一系列的数字（正整数），将这些数字调换顺序后拼接起来可以得到一个新的数字，不同的调换顺序得到的数字不一样。

例子：  
  输入：32 33 42 43

  调换顺序-方式1： 42 33 43 32  
  拼接数字： 42334332

  调换顺序-方式2： 33 32 42 43  
  拼接数字：33324243

那么如何调换顺序可以将最后的拼接数字最大化呢？

#### 关于输入

第1行包括一个数字n，代表数字的个数，1<=n<=100

接下来n行每一行包括一个数字,每个数字的范围是[1,9999]

#### 关于输出

输出最大拼接数字

#### 例子输入

4
32
33
42
43

#### 例子输出

43423332

#### 提示信息

最后拼接得到的数字会很大，可能会超过int、long long的范围

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

bool cmp(const string& a, const string& b){
    //通过分析样例得到的一种贪心策略，每两个加和比较
    return(stoi(a+b)>stoi(b+a));
}
int main() {
    int n = 0;
    cin >> n;
    vector<string> nums(n);

    for(int i = 0; i < n; i++){
        cin >> nums[i];
    }
    sort(nums.begin(),nums.end(),cmp);
    for(const auto& s : nums){
        cout<<s;
    }
    return 0;

}
