# [题目: 操作](https://programming.pku.edu.cn/probset/7d229bb5254143a9a8287a90a8950281/5b5c28f99a1a4b1587e0cdab39dee44f/)

#### 题目描述

有两个正整数 a 和 b，每次可以选择以下操作之一：

1. a←a×2。  
2. b←b−1。  
3. b←b+1。

求使得 a=b 的最小操作次数。

数据范围：1≤a,b≤1,000,000,000。

#### 关于输入

一行两个正整数 a,b。

#### 关于输出

一行一个非负整数，表示最少操作次数。

#### 例子输入

样例 1 输入：
1 5
样例 2 输入：
114514 1919810

#### 例子输出

样例 1 输出：
3
样例 2 输出：
87590

#### 提示信息

数据范围：1≤a,b≤1,000,000,000。

```cpp
#include <iostream>
using namespace std;

int main() {
    int cnt = 0;          // 记录从 a 开始连续乘 2 的次数
    long long a, b;
    cin >> a >> b;

    if (a == b) {
        // a 已经等于 b，不需要任何操作
        cout << 0;
    } else if (a < b) {
        // 情况一：a < b，有两种策略：
        //   策略1：先把 a 不断乘 2 逼近 b，再逐次加 1 补到 b
        //   策略2：先把 a 乘 2 超过 b，再从超过的值逐次减 1 回到 b
        // 注意：这里只考虑了"先乘 2 再补"和"乘 2 后减回来"两种，
        // 并没有枚举"加 1 后再乘 2"等更优的混合操作，因此可能漏解。
        int val1, val2;

        // 先贪心地把 a 乘 2，直到再乘一次就会 >= b
        // 循环结束后满足：a * 2 >= b，即 a 已尽可能接近 b 但不超过 b
        while (a * 2 < b) {
            a *= 2;
            cnt++;
        }

        // 策略1：此时 a < b，用 b - a 次加 1 补齐
        //        总代价 = 乘 2 次数 + 加 1 次数
        val1 = cnt + b - a;

        // 策略2：再乘一次 2 使 a 超过 b（变成 2a），
        //        然后用 2a - b 次减 1 回到 b
        //        总代价 = 乘 2 次数 + 1（多乘一次）+ 减 1 次数
        // 这里 2*a - b 用的是当前的 a（未再乘 2 的 a），
        // 表达式含义是"再乘一次后超出 b 的量"
        val2 = cnt + 1 + 2 * a - b;

        // 取两种策略中代价较小的
        if (val1 >= val2) {
            cout << val2;
        } else {
            cout << val1;
        }
    } else {
        // 情况二：a > b，只能通过减 1 逼近 b（乘 2 只会让 a 更大）
        cout << a - b;
    }

    return 0;
}
/*
WA case:
121517265 430930001
期望输出：55139061（实际程序输出与之不符）

问题分析：
1. 该解法只比较了"乘到不超过 b 再补"和"乘到超过 b 再减"两种固定策略，
   没有考虑"先加 1 再乘 2"、多次交替乘 2/加减等混合操作，贪心不保证最优。
2. val2 的计算依赖循环结束时的 a，而循环条件 a*2 < b 使 a 停在
   b/2 附近，2*a - b 可能为负或不是最优的超调量。
3. 当 a 与 b 数量级较大时，中间量 cnt + 2*a - b 仍在 long long 范围内，
   但策略本身不完备，导致大数用例 WA。
建议改为对"乘 2 次数 k"枚举，或在 a、b 范围内做 BFS/最短路，
每次操作代价为 1，求 a 到 b 的最少操作数。
*/
```
