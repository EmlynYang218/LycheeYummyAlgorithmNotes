# 数组右旋：三次反转

数组右移 `k` 位时，先令 `k %= n`，整体反转，再分别反转前 `k` 个元素和剩余部分。时间 `O(n)`，额外空间 `O(1)`。

```cpp
void rotateRight(vector<int>& a, int k) {
    if (a.empty()) return;
    k %= a.size();
    reverse(a.begin(), a.end());
    reverse(a.begin(), a.begin() + k);
    reverse(a.begin() + k, a.end());
}
```

边界：空数组需先处理，避免对 0 取模；`k` 大于数组长度时由取模化简。
