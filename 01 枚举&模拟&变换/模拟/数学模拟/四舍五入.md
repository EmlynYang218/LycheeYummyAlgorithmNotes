#### 题目描述

xx 为 DeepSeek Harness 编写缓存命中率的显示功能。给定缓存访问总次数 y 和命中次数 x，命中率为 (100×x/y)%。

除非实际命中率为 100%，否则不应显示成 100%，以免产生误解。实际命中率等于 100% 时，直接输出 100%。

其余情况，首先对原始命中率四舍五入到整数。如果得到 100%，就改为四舍五入到一位小数；如果得到 100.0%，则再多保留一位小数，如此继续，直到显示结果不再是 100.0...0%。输出首次满足要求的结果，末尾紧接 %。每次四舍五入都以原始命中率为准。

数据范围：1≤T≤10，1≤x≤y≤1,000,000。

#### 关于输入

第一行包含一个正整数 T，表示数据组数。

接下来 T 行，每行包含两个正整数 x,y，分别表示该组的缓存命中次数和访问总次数。

#### 关于输出

输出 T 行，每行包含对应组按上述规则表示的百分比，末尾紧接 %。

#### 例子输入

样例 1 输入：
3
997 1000
100 100
999998 999999

#### 例子输出

样例 1 输出：
99.7%
100%
99.9999%

#### 提示信息

数据范围：1≤T≤10，1≤x≤y≤1,000,000。

样例 1 的第一组，四舍五入到整数得到 100%，改为保留一位小数得到 99.7%。

第二组的实际命中率恰为 100%，直接输出。

第三组的实际命中率是循环小数，约为 99.9998999999%。保留到三位小数时仍显示 100.000%，保留四位小数后得到 99.9999%。


```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int MAX_DIGIT = 5; 
/*
 如果因为精度问题WA，可以调整这个数,我多次提交得到只需要达到5即可AC，这个数也可以由数学推导得到
 题目数据范围：y <= 1e6 且 x < y，所以 100*x/y <= 100 - 100/y <= 100 - 1e-4。
 四舍五入到 k 位小数时，只要 10^{-k}/2 < 1e-4（即 k >= 5），就必然不再是 100.0...0%。
 因此 k 的数学上界是 5，与浮点精度无关。
 */

//本题反映了一个深刻的问题：浮点数误差影响的位数可能比我们想象的更靠前，尤其是对于999949/999999这种除数和被除数相当接近的例子
//因而在Guass消元的过程中，往往选择绝对值最大的元素作分母，尽量减小浮点数误差

// 高精度除法：a / b，整数部分 + digits 位小数（截断）模拟容易的原因在于除数不大于1e6
string high_precision_div(long long a, long long b, int digits)
{
    string res;
    long long int_part = a / b;
    long long rem = a % b;
    res += to_string(int_part);
    res += '.';
    for (int i = 0; i < digits; i++)
    {
        rem *= 10;
        res += char('0' + rem / b);
        rem %= b;
    }
    return res;
}

// x<=y
string cache_hit_rate(int x, int y)
{
    if (x == y)
    {
        return "100%";
    }
    // 只改这一处：用高精度除法生成 rate 字符串
    string rate = high_precision_div(100LL * x, y, MAX_DIGIT);
    int start_pos = rate.find('.');

    rate = rate.substr(0, start_pos) + rate.substr(start_pos + 1);
    int n = rate.size();
    // 开始四舍五入
    for (int i = start_pos; i < n; i++)
    {
        // 需要“五入”才会产生100%
        if (rate[i] >= '5')
        {
            // 若这一位前面全都是9，产生100%，valid = false，只要有一位非9，就不会产生100%
            bool valid = false;
            for (int j = 0; j < i; j++)
            {
                if (rate[j] != '9')
                {
                    valid = true;
                }
            }
            if (valid)
            {
                // 需要对这一位前面的字符串+1，剩下的舍去，再补全小数点
                rate = rate.substr(0, i);
                unsigned long long temp_rate = stoull(rate);
                temp_rate++;
                rate = to_string(temp_rate);
                for (int p = rate.size(); p > start_pos && rate.back() == '0'; p--)
                {
                    rate.pop_back();
                }
                if (i == start_pos)
                {
                    return rate + '%';
                }
                return rate.substr(0, start_pos) + '.' + rate.substr(start_pos) + '%';
            }
        }
        else
        {
            // 不需要“五入”可以直接输出
            rate = rate.substr(0, i);
            for (int p = rate.size(); p > start_pos && rate.back() == '0'; p--)
            {
                rate.pop_back();
            }
            if (i == start_pos)
            {
                return rate.substr(0, start_pos) + '%';
            }
            return rate.substr(0, start_pos) + '.' + rate.substr(start_pos) + '%';
        }
    }

    return ""; // 防编译警告
}

int main()
{
    int T = 0, x, y;
    cin >> T;
    while (T--)
    {
        cin >> x >> y;
        cout << cache_hit_rate(x, y) << '\n';
    }
    return 0;
}
```
