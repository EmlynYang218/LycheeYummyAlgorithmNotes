# [题目: 文本编辑器](https://programming.pku.edu.cn/probset/d381b7479a464a3c98b71bde9d5aff70/807ec2a459c54c988d383f4c897b4b66/)

#### 题目描述

xx 打开一个简化的文本编辑器：初始只有一个空行，光标在行首闪烁。光标位于字符之间，依次执行以下指令：

- INSERT s：插入 s，光标移到插入内容之后。  
- LEFT、RIGHT：左右移动一个位置，允许跨行到上一行末尾或下一行开头。  
- UP、DOWN：移到相邻行的同一列；目标行过短则停在行尾。每次都以当前实际列号为准。  
- BACKSPACE：删除前一字符，光标退一位；删除换行会合并两行。  
- DELETE：删除后一字符，光标不动；删除换行会合并两行。  
- ENTER：在光标处分行，光标移到新行行首。  
- UNDO 撤销最近一次尚未撤销的修改，恢复**该次修改开始前**的文本和光标。  
- REDO 重做最近一次撤销的修改，恢复**该次修改刚结束时**的文本和光标。

期间的光标移动不影响上述恢复目标。

执行 INSERT、ENTER、BACKSPACE 或 DELETE 并实际改变文本时，记录一次新修改，同时清空待重做的历史。移动光标不记入修改历史。

UNDO 和 REDO 不记为新修改，也不清空其余待重做的历史。REDO 恢复的修改仍可被 UNDO 撤销，撤销后也可再次 REDO。

越界移动、无效删除及没有对应历史的撤销或重做，均忽略。

数据范围：1≤N≤1,000；所有 INSERT 指令插入的总字符数不超过 10,000。

#### 关于输入

第一行包含一个整数 N。

接下来 N 行，每行包含一条指令。INSERT 后恰有一个分隔空格，此后的所有字符组成非空字符串 s；s 只含英文字母和空格，可包含前导或末尾空格。

#### 关于输出

第一行输出三个整数 M,R,C，依次为最终行数、光标行号和列号。行号从 1 开始，列号是该行中光标左侧的字符数，从 0 开始。

随后 M 行分别输出文本，每行放在方括号中，空格改用下划线表示。例如 a b 输出 [a_b]，空行输出 []。

#### 提示信息

数据范围：1≤N≤1,000；所有 INSERT 指令插入的总字符数不超过 10,000。

样例 1 说明：在 ab 和 cd 之间分行并插入 X 后，RIGHT 将光标移到 c 后。随后撤销再重做，恢复插入 X 刚结束时的文本和光标，光标回到 X 后。最终两行分别为 ab、Xcd，光标在第 2 行第 1 列。

样例 2 说明：第三条指令中，分隔空格后的字符串由一个空格、X 和一个空格组成。撤销第二行的插入后，行尾的 DELETE 无效，仍可 REDO 恢复这三个字符。之后 BACKSPACE 删除末尾空格，撤销再重做后，第二行只剩一个前导空格和 X，输出为 [_X]。最终光标在第 2 行第 2 列。

样例 3 说明：第一次 UP 从第 3 行第 5 列移到只有一个字符的第 2 行，实际列号变为 1。第二次 UP 使用当前实际列号，停在第 1 行第 1 列，三行文本均不改变。

样例 4 说明：插入两行后，前两次 LEFT 移到第 2 行行首，第三次 LEFT 跨过换行，停在第 1 行末尾。DELETE 删除光标后的换行，将两行合为 abcd；UNDO 恢复两行文本以及第 1 行末尾的光标。最后 RIGHT 跨过换行，停在第 2 行第 0 列。



```cpp
#include <bits/stdc++.h>
using namespace std;

struct Snapshot {
    vector<string> lines;
    int row, col;
};

struct Edit {
    Snapshot before, after;
};

int main() {
    int N;
    cin >> N;
    cin.ignore();  // 吃掉换行

    vector<string> lines(1, "");  // 初始一个空行
    int row = 0, col = 0;         // 光标在行首

    vector<Edit> undoStack, redoStack;

    auto takeSnapshot = [&]() -> Snapshot {
        return {lines, row, col};
    };

    auto restoreSnapshot = [&](const Snapshot& s) {
        lines = s.lines;
        row = s.row;
        col = s.col;
    };

    for (int i = 0; i < N; i++) {
        string cmd;
        getline(cin, cmd);

        // 解析指令
        string op = cmd;
        string arg;
        if (cmd.substr(0, 6) == "INSERT") {
            op = "INSERT";
            arg = cmd.substr(7);  // 跳过 "INSERT "
        }

        if (op == "INSERT") {
            Snapshot before = takeSnapshot();
            lines[row].insert(col, arg);
            col += arg.size();
            Snapshot after = takeSnapshot();
            // INSERT 一定改变文本（arg 非空）
            undoStack.push_back({before, after});
            redoStack.clear();
        }
        else if (op == "LEFT") {
            if (col > 0) col--;
            else if (row > 0) { row--; col = lines[row].size(); }
        }
        else if (op == "RIGHT") {
            if (col < (int)lines[row].size()) col++;
            else if (row < (int)lines.size() - 1) { row++; col = 0; }
        }
        else if (op == "UP") {
            if (row > 0) { row--; col = min(col, (int)lines[row].size()); }
        }
        else if (op == "DOWN") {
            if (row < (int)lines.size() - 1) { row++; col = min(col, (int)lines[row].size()); }
        }
        else if (op == "BACKSPACE") {
            Snapshot before = takeSnapshot();
            bool changed = false;
            if (col > 0) {
                lines[row].erase(col - 1, 1);
                col--;
                changed = true;
            } else if (row > 0) {
                // 合并到上一行末尾
                col = lines[row - 1].size();
                lines[row - 1] += lines[row];
                lines.erase(lines.begin() + row);
                row--;
                changed = true;
            }
            if (changed) {
                Snapshot after = takeSnapshot();
                undoStack.push_back({before, after});
                redoStack.clear();
            }
        }
        else if (op == "DELETE") {
            Snapshot before = takeSnapshot();
            bool changed = false;
            if (col < (int)lines[row].size()) {
                lines[row].erase(col, 1);
                changed = true;
            } else if (row < (int)lines.size() - 1) {
                // 合并下一行到当前行末尾
                lines[row] += lines[row + 1];
                lines.erase(lines.begin() + row + 1);
                changed = true;
            }
            if (changed) {
                Snapshot after = takeSnapshot();
                undoStack.push_back({before, after});
                redoStack.clear();
            }
        }
        else if (op == "ENTER") {
            Snapshot before = takeSnapshot();
            string tail = lines[row].substr(col);
            lines[row] = lines[row].substr(0, col);
            lines.insert(lines.begin() + row + 1, tail);
            row++;
            col = 0;
            Snapshot after = takeSnapshot();
            undoStack.push_back({before, after});
            redoStack.clear();
        }
        else if (op == "UNDO") {
            if (!undoStack.empty()) {
                Edit e = undoStack.back();
                undoStack.pop_back();
                // 当前状态压入 redoStack（作为 after 快照）
                redoStack.push_back({takeSnapshot(), e.after});
                restoreSnapshot(e.before);
            }
        }
        else if (op == "REDO") {
            if (!redoStack.empty()) {
                Edit e = redoStack.back();
                redoStack.pop_back();
                // 当前状态压入 undoStack（作为 before 快照）
                undoStack.push_back({takeSnapshot(), e.after});
                restoreSnapshot(e.after);
            }
        }
    }

    // 输出
    cout << lines.size() << " " << row + 1 << " " << col << "\n";
    for (auto& line : lines) {
        cout << "[";
        for (char c : line) {
            cout << (c == ' ' ? '_' : c);
        }
        cout << "]\n";
    }

    return 0;

}
```
