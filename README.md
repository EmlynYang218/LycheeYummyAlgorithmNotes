# LycheeYummyAlgorithmNotes

This repository gathers my Markdown notes on algorithm practice — started in my freshman year, and built to grow alongside the algorithm courses ahead: 计概A so far, with 程设实习 and 数算A to come. Problems come from Programming Grid, POJ, BNUOJ, LeetCode, 洛谷, Codeforces, and beyond. I hope these notes may offer a little help to anyone who happens to find their way here.

The notes are organized with the following priority in mind:

**Mindset / Methodology > Data Structures > Specific Tricks**

In other words, I care most about how to approach a problem, then about the data structures that support the solution, and only last about the particular tricks that make an implementation work.
