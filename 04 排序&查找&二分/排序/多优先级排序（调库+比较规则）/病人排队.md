#### 题目描述

将登记的病人按照以下原则排出看病的先后顺序：

1. 老年人（年龄 ≥60 岁）比非老年人优先看病。  
2. 老年人按年龄从大到小的顺序看病，年龄相同的按登记的先后顺序排序。  
3. 非老年人按登记的先后顺序看病。

数据范围：病人的个数不超过 100。

#### 关于输入

第一行一个正整数 n，表示病人的个数；

接下来 n 行，按照病人登记的先后顺序提供病人的信息，包括：一个长度 ≤10 的字符串表示病人的 ID（每个病人的 ID 各不相同且只含数字和字母），一个整数表示病人的年龄，中间用单个空格隔开。

#### 关于输出

按排好的看病顺序输出病人的 ID，每行一个。

#### 例子输入

样例 1 输入：
5
021075 40
004003 15
010158 67
021033 75
102012 30

#### 例子输出

样例 1 输出：
021033
010158
021075
004003
102012

#### 提示信息

数据范围：1≤n≤100。

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

struct person{
    int age;
    string id;
    int sequence;

    person(int temp_sequence,string temp_id,int temp_age){
        sequence = temp_sequence;
        id = temp_id;
        age = temp_age;
    }
};


//返回true表示在排序中优先
bool cmp(const person& a, const person& b){
    if(a.age>=60){
        if(b.age<60){
            return true;
        }
        if(b.age>=60){
            if(a.age!=b.age){
                return a.age > b.age;
            }
            return a.sequence < b.sequence;
        }
    }
    if(b.age>=60){
        return false;
    }
    return a.sequence<b.sequence;

}

int main() {
    int n = 0;
    cin >> n;
    vector<person> p;
    for(int i = 0; i < n; i++){
        string temp_id;
        int temp_age;
        cin>>temp_id>>temp_age;
        p.push_back(person(i,temp_id,temp_age));
    }
    sort(p.begin(),p.end(),cmp);
    for(auto k : p){
        cout<<k.id<<'\n';
    }
    return 0;
}
```
