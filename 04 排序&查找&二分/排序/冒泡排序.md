# 冒泡排序

## 思路

反复比较相邻元素。升序排序时，从右向左交换逆序对，使当前未排序区间的最小值移动到前端。一轮没有交换即可提前结束。

## 实现

```cpp
void bubbleSort(vector<int>& a) {
    for (int i = 0; i + 1 < (int)a.size(); ++i) {
        bool changed = false;
        for (int j = (int)a.size() - 1; j > i; --j) {
            if (a[j] < a[j - 1]) {
                swap(a[j], a[j - 1]);
                changed = true;
            }
        }
        if (!changed) break;
    }
}
```

## 复杂度与性质

- 最坏、平均时间：`O(n^2)`；已有序时最好为 `O(n)`。
- 额外空间：`O(1)`。
- 稳定：只交换严格逆序的相邻元素。
