# 选择排序

## 思路

维护已排序前缀。每一轮从未排序区间找最小值，与区间首元素交换。

## 实现

```cpp
void selectionSort(vector<int>& a) {
    for (int i = 0; i + 1 < (int)a.size(); ++i) {
        int p = i;
        for (int j = i + 1; j < (int)a.size(); ++j)
            if (a[j] < a[p]) p = j;
        swap(a[i], a[p]);
    }
}
```

## 复杂度与性质

- 时间：最好、平均、最坏均为 `O(n^2)`。
- 额外空间：`O(1)`。
- 通常不稳定：交换可能改变相同元素的相对顺序。
