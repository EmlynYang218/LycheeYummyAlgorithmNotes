给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

算法的时间复杂度应该为 `O(log (m+n))` 。

**示例 1：**

**输入：**nums1 = [1,3], nums2 = [2]
**输出：**2.00000
**解释：**合并数组 = [1,2,3] ，中位数 2

**示例 2：**

**输入：**nums1 = [1,2], nums2 = [3,4]
**输出：**2.50000
**解释：**合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5

**提示：**

- `nums1.length == m`
- `nums2.length == n`
- `0 <= m <= 1000`
- `0 <= n <= 1000`
- `1 <= m + n <= 2000`
- `-106 <= nums1[i], nums2[i] <= 106`





注意中位数的定义

对于合并后长度为m+n的数组，

①若m+n为偶数，则中位数两端各有$\frac{m+n}{2}$个数

②若m+n为奇数，则左侧有$\lfloor(m+n)/2\rfloor$个数，右侧多一个中位数位置

③左半部分的最大值小于右半部分的最小值（中位数的“划分”）功能

考虑C++中/的向下取整特性，认为中位数两端各有$l=\frac{m+n}{2}$个数

注意两个数组均为正序，其中元素单调递增；加上题目要求的对数复杂度，应考虑二分查找。



“二分”是一种思想，结合刚才的分析，我们最好对个数二分而非对下标二分。



则我们可以在nums1拿出i个放入左侧，自动计算出$j=\frac{m+n+1}{2}-i$个放入右侧

左半部分最大值为p = max(nums1[i-1],nums2[j-1])

右半部分最小值为q = min(nums1[i],nums2[j])



先等一下，别忘了边界检查：
i等于0说明左边不贡献元素，则它不会参与到“左半部分最大值”，用INT_MIN占位

i等于m说明拿出了左边全部元素，则它不会参与到“右半部分最小值”，用INT_MAX占位

以下同理



只要p＜=q，分m+n奇偶性讨论：若偶数，中位数的值为$\frac{p+q}{2.0}$，若奇数，为左半最大值



如果p大于q，则要考虑较大的值出现在nums1中，还是nums2中，

如果出现在nums1中，则需要左移i，少纳入一些nums1中的最大值，如果出现在nums2中，则需要左移j，少纳入一些nums2中的最大值，这相当于增大i

因此，我们只需要对num1和nums2中较短的数组进行二分查找

不妨假设nums1.size()<=nums2.size()。

在正序数组中对较短数组的切分位置进行二分查找，时间复杂度为 $O(\log\min(m,n))$。
