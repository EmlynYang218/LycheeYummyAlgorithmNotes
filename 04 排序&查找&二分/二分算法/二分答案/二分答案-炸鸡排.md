# 二分答案：炸鸡排

## 题目模型

有 `n` 块鸡排，第 `i` 块鸡排需要 `t[i]` 秒炸熟。炸锅中始终必须有恰好 `k` 块鸡排，已经炸熟的鸡排不能继续留在锅中，但可以随时更换未熟的鸡排。求最多可以持续炸锅工作的时间。

例如，三块鸡排的熟制时间都是 `1`，而锅中必须放 `2` 块时，可以分三个阶段，每阶段 `0.5` 秒，总持续时间为 `1.5` 秒。

## 输入输出

- 输入：第一行 `n, k`；第二行给出 `n` 个正整数 `t[i]`。
- 约束：`n <= 1000`，`0 < t[i] <= 1000000`，`k <= n`。
- 输出：最多持续时间，保留三位小数。

样例：

```text
输入：
4 2
5 1 1 2

输出：
4.000
```

## 关键观察：二分答案

这是一个连续答案二分问题。设尝试的持续时间为 `T`，每块鸡排最多能贡献 `min(T, t[i])` 秒的炸锅时间，因此所有鸡排能提供的总时间为：

```text
sum(min(T, t[i]))
```

因为每个时刻需要 `k` 块鸡排，持续 `T` 秒至少需要 `kT` 的总炸制时间。于是 `T` 可行当且仅当：

```text
sum(min(T, t[i])) >= k * T
```

若某个 `T` 可行，那么更小的时间也一定可行；若某个 `T` 不可行，那么更大的时间也一定不可行。这种单调性允许二分答案。

答案范围：

- 下界为 `0`。
- 上界为所有鸡排所需时间总和除以 `k`。

## C++ 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

static constexpr int TRY_TIME = 1000;

bool valid(double candidate, int k, const vector<int>& chickens) {
    double total = 0;
    for (int cookingTime : chickens)
        total += min(candidate, (double)cookingTime);
    return total >= candidate * k;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;

    vector<int> chickens(n);
    double totalTime = 0;
    for (int& cookingTime : chickens) {
        cin >> cookingTime;
        totalTime += cookingTime;
    }

    double left = 0;
    double right = totalTime / k;

    for (int step = 0; step < TRY_TIME; ++step) {
        double mid = (left + right) / 2;
        if (valid(mid, k, chickens))
            left = mid;
        else
            right = mid;
    }

    cout << fixed << setprecision(3) << left << '\n';
    return 0;
}
```

## 复杂度与边界

每次检查需要 `O(n)`，二分固定进行 1000 次，因此总复杂度为 `O(1000n)`，额外空间为 `O(n)`。需要注意 `totalTime` 和计算中的乘法使用浮点或足够大的整数类型，避免总和溢出。

## 解题模式

遇到“求最大/最小值”，并且可以判断“给定答案是否可行”时，应主动检查可行性是否具有单调性。连续答案通常通过固定迭代次数或误差阈值逼近。
